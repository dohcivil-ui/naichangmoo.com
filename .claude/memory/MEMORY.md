# MEMORY — สารบัญความจำของโปรเจกต์นายช่างหมู

**ไฟล์นี้เป็นสารบัญ ไม่ใช่ที่เก็บเนื้อหา** ทุกบรรทัดชี้ไปยังไฟล์ต้นทางที่มีอยู่แล้ว
ห้ามคัดเนื้อหาจากต้นทางมาไว้ที่นี่ เพราะจะกลายเป็นข้อมูลสองชุดที่แก้ไม่พร้อมกัน

**ความจำหลักอยู่ที่อื่น** — สารบัญที่ระบบโหลดให้เองทุก session คือ
`~/.claude/projects/d--AIProject-naichangmoo/memory/MEMORY.md` ไฟล์นั้นเป็นตัวหลัก
ไฟล์นี้เป็นตัวเสริมที่ commit ขึ้น git เพื่อให้ตรวจย้อนได้และคนอื่นเห็นด้วย
ถ้าสองไฟล์ขัดกันเมื่อไหร่ ให้ถามเจ้าของงาน อย่าเลือกเอง

## กฎการใช้ความจำ

- เรื่องที่ต้องใช้ซ้ำหลาย session ให้เก็บลงไฟล์ ไม่พึ่งบทสนทนาอย่างเดียว
- ถ้าเจ้าของงานต้องบอกเรื่องเดิมเป็นครั้งที่สอง ให้เสนอทันทีว่าควรบันทึกไว้ที่ไหน
- ห้ามบันทึกเรื่องชั่วคราวเป็นกฎถาวร
- ข้อมูลใหม่ขัดกับของเดิมเมื่อไหร่ **ให้ถามก่อน** ห้ามเขียนทับเงียบ ๆ
- ของเก่าที่เลิกใช้ให้แก้ให้ตรงหรือย้ายออก ห้ามปล่อยความจำที่ขัดกันค้างไว้
- **ห้ามสร้างแหล่งข้อมูลคู่ขนาน** — การตัดสินใจอยู่ที่ `docs/adr/` สถานะส่งต่องานอยู่ที่ `docs/handoff/`
  ไม่มีสำเนาที่สองในโฟลเดอร์นี้
