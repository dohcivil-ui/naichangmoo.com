# สเปกงานพิมพ์เอกสารราชการ — A4

เอกสารนี้เป็นค่ามาตรฐานที่ทุกเอกสารพิมพ์ของแพลตฟอร์มต้องยึด ค่าทุกตัวมีที่มาระบุไว้
ถ้าจะแก้ค่าไหน ให้แก้ที่นี่ก่อน แล้วโค้ดตามมา ไม่ใช่แก้ที่โค้ดแล้วเอกสารนี้ตามไม่ทัน

**สถานะ:** ร่างจากคำสั่งของเจ้าของงานเมื่อ 2026-08-26 และจากไฟล์ต้นแบบที่เจ้าของงานชี้ให้ดู
รอเจ้าของงานแก้ทับ

**บังคับใช้จริงที่:** `src/app/document-print.css` และ `src/lib/paper-pagination.ts`

---

## หนึ่ง — แหล่งที่มาของค่า

ค่าหน้ากระดาษและตัวอักษรถอดจากไฟล์ `km/แบบฟอร์มเซ็นรับส่งมอบงาน.docx` โดยอ่าน
`word/document.xml` ตรง ๆ ไม่ได้วัดจากภาพหน้าจอ

```xml
<w:pgSz w:w="11906" w:h="16838"/>
<w:pgMar w:top="1418" w:right="849" w:bottom="851" w:left="1418"
         w:header="709" w:footer="709" w:gutter="0"/>
<w:sz w:val="32"/>      <!-- 343 จาก 344 จุดในเอกสาร -->
<w:spacing w:after="40"/>    <!-- 22 จุด -->
<w:spacing w:before="120"/>  <!-- 3 จุด -->
```

หน่วยของ Word เป็น twip คือหนึ่งในยี่สิบของพอยต์ และ 1440 twip เท่ากับหนึ่งนิ้ว
ส่วน `w:sz` เป็นครึ่งพอยต์ `32` จึงเท่ากับ 16 พอยต์

| ค่าในไฟล์ | twip | แปลงแล้ว |
|---|---|---|
| ความกว้างกระดาษ | 11906 | 210.0 มม. |
| ความสูงกระดาษ | 16838 | 297.0 มม. |
| ขอบบน | 1418 | 25 มม. |
| ขอบขวา | 849 | 15 มม. |
| ขอบล่าง | 851 | 15 มม. |
| ขอบซ้าย | 1418 | 25 มม. |
| ระยะหลังย่อหน้า | 40 | 2 มม. |
| ระยะก่อนหัวข้อ | 120 | 6 มม. |

**ข้อที่จงใจไม่ทำตามไฟล์ต้นแบบ** ไฟล์ต้นแบบใช้ **Browallia New** แต่ระเบียบสำนักนายกรัฐมนตรี
ว่าด้วยงานสารบรรณกำหนด **TH Sarabun New** และเจ้าของงานสั่งให้ใช้ TH Sarabun New
ซึ่งวัดแล้วให้ขนาดใกล้เคียงกันมาก จึงไม่กระทบสัดส่วนของหน้า

## สอง — หน้ากระดาษ

| รายการ | ค่า | หมายเหตุ |
|---|---|---|
| ขนาด | 210 × 297 มม. | A4 แนวตั้ง ประกาศเป็นมิลลิเมตร ห้ามใช้พิกเซล |
| ความสูง | **คงที่** ไม่ใช่ `min-height` | `min-height` ทำให้แผ่นยืดตามเนื้อหาจนได้กระดาษที่ไม่มีอยู่จริง |
| ขอบ | บน 25 · ขวา 15 · ล่าง 15 · ซ้าย 25 มม. | เป็น `padding` ของแผ่น ไม่ใช่ `margin` ของ `@page` |
| `@page` | `size: A4 portrait; margin: 0` | ขอบอยู่ที่แผ่น เพื่อให้ตำแหน่งบนจอกับใน PDF ตรงกันทุกจุด |
| `box-sizing` | `border-box` | ขอบกินเข้าไปในขนาดกระดาษ ไม่ใช่บวกเพิ่มออกมา |
| พื้นที่พิมพ์ | 170 × 257 มม. | 210−25−15 และ 297−25−15 |

## สาม — ตัวอักษร

| รายการ | ค่า |
|---|---|
| ตระกูล | `TH Sarabun New` ตัวจริง เสิร์ฟจาก `public/fonts/` ห้ามถอยไปฟอนต์อื่น |
| น้ำหนักที่มี | 400 และ 700 (ไม่ใส่ตัวเอียง เอกสารราชการไม่ใช้) |
| `font-display` | `block` เพราะเอกสารที่พิมพ์ด้วยฟอนต์สำรองไปแล้วแก้ทีหลังไม่ได้ |
| ขนาด | **16 พอยต์ทั้งฉบับ** ไม่มีข้อยกเว้น |
| ลำดับชั้น | มาจากความหนา การจัดกึ่งกลาง เส้นกรอบ พื้นเทาหัวตาราง และระยะเยื้อง ไม่ใช่จากขนาด |
| `line-height` | 1.15 |
| ระยะหลังย่อหน้า | 2 มม. |
| ระยะก่อนหัวข้อ | 6 มม. · หัวข้อของบล็อกแรกในหน้าเป็น 0 |
| ระยะหลังหัวข้อ | 2 มม. |

**ทำไมเรื่องฟอนต์สำคัญกว่าที่คิด** วัดข้อความชุดเดียวกันที่ 16 พอยต์เท่ากัน

| ฟอนต์ | ความกว้าง | เทียบ Browallia New |
|---|---|---|
| Browallia New | 261 px | ฐาน |
| TH Sarabun New | 250 px | แคบกว่า 4% |
| Sarabun ของ Google | 380 px | **กว้างกว่า 46%** |

เอกสารเคยดูใหญ่เกินต้นแบบราว 15–25% เพราะโหลด Sarabun ของ Google มาใช้ ไม่ใช่เพราะเลขพอยต์ผิด

## สี่ — ตาราง

| รายการ | ค่า |
|---|---|
| ความกว้าง | เต็มพื้นที่พิมพ์ |
| `table-layout` | `fixed` พร้อม `colgroup` ระบุความกว้างทุกคอลัมน์ |
| เส้น | 1px ทึบสีดำ ทุกด้านของทุกช่อง |
| ระยะในช่อง | 1 มม. บนล่าง · 2 มม. ซ้ายขวา |
| หัวตาราง | พื้น `#ececec` ตัวหนา จัดกึ่งกลาง |
| ตัวเลข | ชิดขวา `font-variant-numeric: tabular-nums` |

ความกว้างคอลัมน์ต้องคงที่ทุกชิ้นส่วน เพราะตารางแตกข้ามหน้าได้ ถ้าปล่อยให้เบราว์เซอร์
คิดใหม่จากเนื้อหาของแต่ละชิ้น จะได้คอลัมน์คนละความกว้างในหน้าคนละหน้า

## ห้า — การแบ่งหน้า

การแบ่งหน้าไม่ได้ปล่อยให้เบราว์เซอร์ทำเอง แต่วัดความสูงจริงของทุกบล็อกก่อน แล้วคำนวณว่า
อะไรอยู่หน้าไหน เหตุผลคือตัวอย่างบนหน้าจอกับ PDF ต้องเป็นสิ่งเดียวกัน ถ้าปล่อยให้เบราว์เซอร์
จัดหน้าเองตอนพิมพ์ สองอย่างนั้นจะเลื่อนกัน

| กฎ | รายละเอียด |
|---|---|
| ลำดับ | จากบนลงล่างเสมอ ห้ามสลับเพื่อให้หน้าดูเต็ม |
| ตาราง | แตกข้ามหน้าได้ทีละแถว ห้ามตัดกลางแถว |
| หัวตาราง | ซ้ำทุกหน้าที่ตารางไปโผล่ |
| ท้ายตาราง | ถ้าไม่พอในหน้าสุดท้าย ยกไปหน้าถัดไปพร้อมหัวตาราง |
| หัวข้อ | ห้ามค้างท้ายหน้าโดยเนื้อหาไปอยู่หน้าถัดไป ต้องยกไปด้วยกัน |
| กล่องหมายเหตุ และช่องลงนาม | ห้ามแตกข้ามหน้า |
| เลขหน้า | อยู่ที่ขอบล่างของพื้นที่พิมพ์ เอกสารหน้าเดียวไม่ต้องมี |
| ของที่สูงเกินหนึ่งหน้า | ไม่ถูกตัดทิ้งเงียบ ๆ แต่ขึ้นคำเตือนให้ผู้ใช้เห็น |

## หก — การพิมพ์และการส่งออก PDF

| กฎ | เหตุผล |
|---|---|
| รอ `document.fonts.ready` ก่อนเรียก `window.print()` | ถ้าฟอนต์ยังไม่มา จะได้ PDF ที่ตัวอักษรไม่ใช่ TH Sarabun New |
| ถอด `transform` ทั้งหมดตอนพิมพ์ | ขนาดที่พิมพ์ต้องไม่ขึ้นกับการย่อบนหน้าจอ |
| ซ่อนแถบเครื่องมือและแผงตั้งค่า | ของบนหน้าจอไม่ใช่ของบนกระดาษ |
| พิมพ์ที่ 100% | ผู้ใช้ต้องไม่ต้องตั้ง scale เองในกล่องพิมพ์ |
| MediaBox ของ PDF ต้องเป็น A4 | ตรวจได้จากขนาดหน้าในโปรแกรมอ่าน PDF |

**ห้ามใช้ `transform: scale` หรือ `zoom` เพื่อบีบเนื้อหาให้ลงหน้า** เนื้อหาที่ยาวเกินต้องขึ้น
หน้าใหม่ ไม่ใช่ถูกย่อ การย่อด้วย transform ใช้ได้ทางเดียวคือโหมดพอดีหน้าจอสำหรับดูภาพรวม
ซึ่งไม่มีผลกับสิ่งที่พิมพ์ออกมา

## เจ็ด — โหมดบนหน้าจอ

| โหมด | พฤติกรรม |
|---|---|
| พอดีหน้าจอ | ย่อทั้งกองด้วย `transform: scale` เพื่อเห็นทั้งแผ่น คิดจากทั้งความกว้างและความสูง |
| ขนาดจริง | แสดงตามขนาด CSS จริง ไม่มี responsive reflow |

การย่อขยายของเบราว์เซอร์หรือ DPI ของ Windows ต้องไม่เปลี่ยนขนาด PDF เพราะขนาดกระดาษ
ประกาศเป็นมิลลิเมตรซึ่งเป็นหน่วยจริง ไม่ใช่พิกเซลซึ่งขึ้นกับการย่อขยาย

## แปด — สิ่งที่ยังไม่ได้ทำ และข้อจำกัดที่รู้อยู่

- **ยังไม่ได้ตรวจ MediaBox ของ PDF ที่ออกมาจริง** ต้องสั่งพิมพ์เป็น PDF จากเบราว์เซอร์แล้วเปิดดู
  คุณสมบัติของไฟล์ ซึ่งเป็นขั้นที่ต้องมีคนทำ เครื่องมืออัตโนมัติในที่นี้เปิดกล่องพิมพ์ของ Windows ไม่ได้
- **ไม่ได้ฝังตัวเอียงของ TH Sarabun New** เอกสารราชการไทยไม่ใช้ ถ้าวันหนึ่งต้องใช้
  ให้เพิ่ม `THSarabunNew Italic.ttf` และ `THSarabunNew BoldItalic.ttf`
- **บัญชีงวดงานฉบับปัจจุบันยาว 287.9 มม. จึงเป็นเอกสารสองหน้า** พื้นที่พิมพ์ต่อหน้ามี 257 มม.
  เจ้าของงานเลือกให้คงระยะตามไฟล์ต้นแบบไว้และยอมให้เป็นสองหน้า แทนการบีบ line-height
  กับระยะหัวข้อลงเพื่อให้ลงหน้าเดียว
