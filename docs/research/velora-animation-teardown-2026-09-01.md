# แกะเทคนิคอนิเมชันของ velora.colorlib.com

อ่านค่าจากเบราว์เซอร์จริงเมื่อ 2026-09-01 · ไม่ได้เดาจากการดูตาเปล่า

เว็บนี้คือ **Velora UI — ชุดคอมโพเนนต์ React ที่มีอนิเมชัน แจกฟรี** สร้างด้วย Next.js
กับ Tailwind รุ่นสี่ หน้าสูง 8,020 px มีสิบส่วน

## วิธีที่ใช้แกะ

อ่านจากเบราว์เซอร์โดยตรงสี่ทาง — ไล่ `@keyframes` ทุกอันในสไตล์ชีต · ไล่ทุก element
เพื่อดูว่าอันไหนมี `animation` หรือ `transition` ทำงานอยู่ · จับ inline style ก่อนและหลังเลื่อนหน้า
เพื่อดูว่าอะไรผูกกับการเลื่อน · และตรวจว่าเคารพ `prefers-reduced-motion` หรือไม่

**สิ่งที่แกะไม่ได้และต้องพูดตามตรง** โค้ด JavaScript ถูกรวมเป็นก้อนของ Next.js
จึงบอกไม่ได้ว่าใช้ไลบรารีตัวไหนขับ (framer-motion หรือเขียนเอง) ไม่มีตัวแปรไลบรารีค้างบน
`window` เลย · และ canvas ที่พบหนึ่งอันสุ่มอ่านพิกเซลแล้วยังว่าง จึงยังไม่รู้ว่ามันวาดอะไร

## หนึ่ง — อนิเมชันพื้นหลังที่วิ่งตลอดเวลา

### ออโรรา สามชั้นซ้อนกัน

หัวใจของบรรยากาศทั้งหน้า เป็นก้อนเบลอสามก้อนที่ขยับคนละจังหวะ ทำให้พื้นหลังไม่นิ่งแต่ไม่กวน

```css
@keyframes aurora-1 { 0%{transform:translate(-10%,-12%) scale(1)} 50%{transform:translate(12%,8%) scale(1.25)} 100%{transform:translate(-6%,14%) scale(.95)} }
@keyframes aurora-2 { 0%{transform:translate(12%,10%) scale(1.1)} 50%{transform:translate(-14%,-6%) scale(.9)} 100%{transform:translate(8%,-12%) scale(1.2)} }
@keyframes aurora-3 { 0%{transform:translateY(16%) scale(.95)} 50%{transform:translate(10%,-10%) scale(1.15)} 100%{transform:translate(-12%,4%) scale(1)} }
```

**ความยาวไม่เท่ากันคือหัวใจ** 14 วินาที · 18 วินาที · 22 วินาที ด้วย `ease-in-out` วนไม่จบ
เลขที่หารกันไม่ลงตัวทำให้สามก้อนไม่กลับมาซ้อนท่าเดิม คนดูจึงไม่จับจังหวะได้
ถ้าใช้เวลาเท่ากันทั้งสามก้อนจะกลายเป็นลูปที่เห็นรอยต่อทันที

### ดาวตก

```css
@keyframes meteor {
  0%   { transform: rotate(var(--meteor-angle,215deg)) translateX(0); opacity: 1; }
  70%  { opacity: 1; }
  100% { transform: rotate(var(--meteor-angle,215deg)) translateX(-600px); opacity: 0; }
}
```

หมุนแกนก่อนแล้วค่อยเลื่อนตามแกน X ทำให้ได้เส้นทแยงโดยไม่ต้องคำนวณ x กับ y แยกกัน
**จับได้สิบเส้นที่ตั้งเวลาไม่ซ้ำกันเลย** 4.0 · 4.5 · 5.1 · 5.6 · 5.7 · 6.2 · 6.3 · 6.8 · 6.9 · 7.4 วินาที
มุมส่งผ่านตัวแปร CSS ต่อชิ้น จึงใช้คลาสเดียวกันได้ทั้งหมด

### ตารางเรโทรที่ไหลขึ้น

```css
@keyframes retro-grid { 0%{transform:translateY(-50%)} 100%{transform:translateY(0)} }
```

ท่าเดียวกับแถบวิ่ง คือวาดของสองชุดต่อกันแล้วเลื่อนครึ่งหนึ่ง พอถึงจุดจบก็เหมือนเริ่มใหม่พอดี

### วงโคจร

```css
@keyframes orbit {
  0%   { transform: rotate(calc(var(--angle)*1deg)) translateY(calc(var(--radius)*-1px)) rotate(calc(var(--angle)*-1deg)); }
  100% { transform: rotate(calc(var(--angle)*1deg + 360deg)) translateY(calc(var(--radius)*-1px)) rotate(calc((var(--angle)*1deg + 360deg)*-1)); }
}
```

**ท่าหมุนสวนกลับ** หมุนแกน แล้วดันออกไปตามรัศมี แล้วหมุนกลับเท่าเดิม
ผลคือไอคอนวิ่งเป็นวงกลมโดย**ตัวมันเองไม่หมุนตาม** ระยะกับมุมเริ่มต้นส่งผ่านตัวแปร CSS
ใช้เวลา 24 วินาที เจอสามจุดบนหน้า

---

## สอง — แถบวิ่งและประกาย

```css
@keyframes marquee          { 0%{transform:translate(0)} 100%{transform:translateX(calc(-100% - var(--gap)))} }
@keyframes marquee-vertical { 0%{transform:translateY(0)} 100%{transform:translateY(calc(-100% - var(--gap)))} }
@keyframes shimmer          { 0%{background-position:200% 0} 100%{background-position:-200% 0} }
@keyframes gradient         { 0%,100%{background-position:0% center} 50%{background-position:100% center} }
```

แถบวิ่งใช้ท่าเดียวกับที่เราเคยมี แต่ **บวก `var(--gap)` เข้าไปในระยะ** ทำให้ช่องไฟระหว่างชุด
เท่ากันตอนวน ของเราเดิมไม่ได้บวกช่องไฟ จึงเห็นรอยต่อ · แนวตั้งใช้ท่าเดียวกันแค่เปลี่ยนแกน

`shimmer` กับ `gradient` **ไม่ได้ขยับตัวอักษร แต่ขยับตำแหน่งพื้นหลังของไล่สี**
ได้แสงวิ่งผ่านตัวหนังสือหรือปุ่มโดยไม่กระทบการจัดหน้าเลย

---

## สาม — ลำแสงวิ่งรอบขอบการ์ด

จับได้สามจุดที่ใช้ `offset-path` ซึ่งเป็นความสามารถใหม่ของ CSS

```
offset-path: rect(0px auto auto 0px round 96px);
```

บอกเส้นทางเป็นสี่เหลี่ยมมุมมนแล้วให้จุดแสงวิ่งไปตามเส้นนั้นด้วย `offset-distance`
**ไม่ต้องใช้ SVG และไม่ต้องคำนวณพิกัดเอง** สีของลำแสงส่งผ่านตัวแปร `--beam-from` และ `--beam-to`

---

## สี่ — การปรากฏตอนเลื่อนถึง

ทุกบล็อกเนื้อหาเริ่มต้นด้วย inline style แบบนี้

```
opacity: 0; filter: blur(6px); transform: translateY(32px);
```

แล้วเปลี่ยนเป็น

```
opacity: 1; filter: blur(0px); transform: none;
```

**จุดที่ต่างจากที่เราทำ คือมี `blur` ร่วมด้วย** ไม่ใช่แค่จางกับเลื่อนขึ้น
ความเบลอ 6px ที่คลายออกทำให้รู้สึกเหมือนของค่อย ๆ เข้าโฟกัส ไม่ใช่แค่โผล่

พาดหัวถูกซอยเป็น `<span class="inline-block will-change-transform">` ทีละคำ
แล้วปล่อยทีละอันไล่กัน — จับได้ว่ามี `will-change: transform` อยู่ 16 จุดทั้งหน้า
เป็นการบอกเบราว์เซอร์ล่วงหน้าให้เตรียมชั้นวาดไว้ ไม่ได้ใส่มั่ว

---

## ห้า — แถบความคืบหน้าบนสุด

```
div.fixed inset-x-0 top-0 z-[60] h-0.75 origin-left  →  transform: scaleX(0)
```

เลื่อนหน้าไป 2,200 px แล้ววัดได้ `scaleX(0.299826)` ตรงกับสัดส่วนที่เลื่อนไปพอดี

**ใช้ `scaleX` ไม่ใช่ `width`** ซึ่งสำคัญมาก เพราะ `width` บังคับให้เบราว์เซอร์คำนวณผังใหม่ทุกเฟรม
ส่วน `scaleX` ทำที่การ์ดจอ ได้ 60 เฟรมต่อวินาทีโดยไม่กินซีพียู

---

## หก — พาดหัวพิมพ์ดีดที่ไม่ทำให้หน้ากระตุก

พาดหัวสลับคำว่า alive. → unforgettable. → effortless. โดยพิมพ์ทีละตัวอักษร
ปัญหาปกติของเอฟเฟกต์นี้คือความกว้างเปลี่ยนทุกตัวอักษร ทำให้ข้อความรอบข้างขยับตาม
เขาแก้ด้วยการซ้อนสามชั้นในช่องกริดเดียวกัน

| ชั้น | คลาส | หน้าที่ |
|---|---|---|
| 1 | `sr-only` | ข้อความจริงสำหรับโปรแกรมอ่านหน้าจอ ไม่แสดงผล |
| 2 | `invisible col-start-1 row-start-1` | คำที่ยาวที่สุด ไม่แสดงแต่กินที่ไว้ ทำให้ความกว้างนิ่ง |
| 3 | `col-start-1 row-start-1` | คำที่กำลังพิมพ์ ทับอยู่บนสุด |

เคอร์เซอร์เป็นตัว `|` ที่ใส่คลาส `animate-pulse` · ตัวห่อนอกสุดเป็น `inline-grid`

**นี่คือชิ้นที่ฉลาดที่สุดในหน้านี้** เพราะแก้ทั้งเรื่องหน้ากระตุกและเรื่องโปรแกรมอ่านหน้าจอ
พร้อมกันด้วยโครงเดียว

## เจ็ด — เคารพคนที่ปิดอนิเมชัน

พบกฎ `@media (prefers-reduced-motion)` และมันปิดของจริงทั้งหมด

```css
.animate-meteor, .animate-retro-grid, .animate-marquee, .animate-marquee-vertical,
.animate-shimmer, .animate-gradient, .animate-orbit, .animate-aurora… { animation: none }
.shimmer { -webkit-text-fill-color: currentcolor; background-image: none; animation: none }
```

สังเกตบรรทัดที่สอง — ไม่ได้แค่หยุดอนิเมชัน แต่**คืนสีตัวอักษรให้ทึบด้วย**
เพราะเอฟเฟกต์ประกายทำงานด้วยการทำตัวอักษรโปร่งแล้วให้เห็นไล่สีข้างหลัง
ถ้าหยุดเฉย ๆ ตัวหนังสือจะหายไปเลย **เป็นรายละเอียดที่คนทำส่วนใหญ่ลืม**

## แปด — ค่าที่ใช้กับการเปลี่ยนสถานะ

| ใช้กับอะไร | คุณสมบัติ | เวลา | เส้นโค้ง | จำนวนที่พบ |
|---|---|---|---|---|
| สีทุกชนิด | color, background-color, border-color, fill, stroke | 0.15s | cubic-bezier(.4,0,.2,1) | 56 จุด |
| เงา | box-shadow | 0.3s | cubic-bezier(.4,0,.2,1) | 4 จุด |
| การขยับ | transform, translate, scale, rotate | 0.5s | cubic-bezier(0,0,.2,1) | 4 จุด |
| การขยับ | transform, translate, scale, rotate | 0.3s | cubic-bezier(0,0,.2,1) | 4 จุด |
| ความจาง | opacity | 0.3s | cubic-bezier(.4,0,.2,1) | 3 จุด |

**สีเปลี่ยนเร็วกว่าการขยับเสมอ** 0.15 วินาทีสำหรับสี เทียบกับ 0.3-0.5 สำหรับการขยับ
และการขยับใช้เส้นโค้งที่ออกตัวเร็วแล้วค่อยผ่อน `cubic-bezier(0,0,.2,1)` ไม่ใช่เส้นตรง

## เก้า — สิ่งที่ควรหยิบมาใช้กับเว็บเรา และสิ่งที่ไม่ควร

### ควรหยิบ

1. **ใส่ `blur` เข้าไปในการปรากฏตอนเลื่อนถึง** ของเรามีแค่จางกับเลื่อน เพิ่มบรรทัดเดียวได้ผลเยอะ
2. **แถบความคืบหน้าด้วย `scaleX`** เหมาะกับหน้ายาวอย่างหน้าแอปทั้งหมดและหน้าราคา
3. **ท่าซ้อนกริดสามชั้นของพาดหัวพิมพ์ดีด** ถ้าจะทำพาดหัวสลับคำ ต้องใช้ท่านี้เท่านั้น
4. **บวก `var(--gap)` ในระยะของแถบวิ่ง** ถ้าวันหนึ่งเอาแถบวิ่งกลับมา
5. **คืนสีตัวอักษรตอน reduced-motion** ถ้าเราทำเอฟเฟกต์ไล่สีบนตัวอักษรเมื่อไหร่
6. **ตั้งเวลาลูปให้หารกันไม่ลงตัว** เมื่อมีของวิ่งพร้อมกันหลายชิ้น

### ไม่ควรหยิบ

- **ออโรรา ดาวตก และวงโคจร** เว็บเราขายความน่าเชื่อถือของตัวเลขให้วิศวกรและผู้รับเหมา
  พื้นหลังที่วิ่งตลอดเวลาทำให้ดูเป็นเว็บขายเทมเพลต ไม่ใช่เครื่องมือทำงาน
  และขัดกับที่เจ้าของงานเพิ่งบอกว่าอยากได้ความทันสมัยที่อ่านง่าย
- **ตารางเรโทร** เป็นสไตล์ยุค 80 ไม่เข้ากับงานราชการ
