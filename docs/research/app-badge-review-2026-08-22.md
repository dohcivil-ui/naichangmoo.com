# App Badge Review — 2026-08-22

## Objective

Replace generic-looking app icon treatments with a cohesive set of original civil-engineering product badges. The user requested a stronger graphic presence similar in product clarity to the reference catalog, without copying its artwork or UI.

## Visual Grammar

Each badge uses a square off-white engineering board with a single high-recognition civil subject, navy structure, teal technical guides, orange annotation accents and modest three-dimensional depth. App cards add a consistent technical-grid frame and a narrow accent bar, so the badge remains recognizable at small sizes without adding copy inside the image.

## Lightweight Review

| Badge | Subject clarity | Outcome |
|---|---|---|
| ESTIMETR | Building frame, plan sheet, quantity grid and measuring ruler form an estimating/takeoff composition | Approved for product-card use |
| Retaining Wall Cantilever | Concrete cantilever wall, soil layers, drainage and force/optimization guides form a clear structural section | Approved for product-card use |

The remaining badges follow the same fixed visual brief and will be routed through the same public asset proxy. The card frame is deliberately restrained so it supports the visual rather than simulating a dashboard.
