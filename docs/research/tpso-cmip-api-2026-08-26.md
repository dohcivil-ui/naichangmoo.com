# ราคาวัสดุก่อสร้างรายจังหวัดของ สนค. — เส้นทางข้อมูลจริง

**วันที่:** 2026-08-26
**คำถามของเจ้าของงาน:** แอปราคาวัสดุและค่าแรงของคู่แข่งดึงข้อมูลมาจากไหน และเราดึงเองได้ไหม
**วิธีตรวจ:** อ่าน `app.js` ของหน้า `/price-live/` ของคู่แข่งโดยตรง แล้วไล่ย้อนไปถึงต้นทางจริง และเรียกต้นทางนั้นเอง

## 1. คู่แข่งดึงจากไหน

หน้า `/price-live/` เป็น HTML static + `app.js` ไฟล์เดียว 215 KB ไม่มี framework ข้อมูลมาสองทาง

| ทาง | ที่อยู่ | เนื้อ |
|---|---|---|
| ไฟล์นิ่งในเว็บตัวเอง | `data/seed.json`, `data/obec-2569.json`, `data/cgd-2560.json`, `data/cgd-2569.json`, `data/tpso-cmi.json`, `data/transport-cost.json`, `data/lgu-pho-2563.json`, `data/rcp-2567.json`, `data/road-2567.json`, `data/bb-2557.json`, `data/doh-drr-2567.json`, `data/rid-cgd-2560.json`, `data/stats-2568.json` | ชุดข้อมูลที่พิมพ์ไว้ล่วงหน้า |
| API ผ่าน proxy ของตัวเอง | `GET /api/eb/tpso?endpoint=masterdata` และ `POST /api/eb/tpso` `{year, month, type}` · `GET /api/eb/tpso-history?type=<codes>&months=24` | ราคาวัสดุรายจังหวัดของ **สนค. (TPSO)** |

`/api/eb/*` เป็น Cloudflare Pages Functions ของเขาเอง ทำหน้าที่บังหน้า API ต้นทางและแคชไว้ใน KV
comment ในโค้ดเขาเขียนไว้เองว่า *"TPSO จำกัดอัตราเรียก · server จะบอก retry_after มาเอง"*

**ต้นทางจริงคือ สนค. ไม่ใช่ของเขา** สิ่งที่เป็นของเขามีอย่างเดียวคือชั้นแคชกับชั้นเก็บเงิน

## 2. ต้นทางจริง — เรียกเองได้ ไม่ต้องผ่านใคร

สำนักงานนโยบายและยุทธศาสตร์การค้า (สนค.) กระทรวงพาณิชย์ เปิด API ของระบบ
"ราคาวัสดุก่อสร้างรายจังหวัด" ไว้สาธารณะที่ `https://index.tpso.go.th`
**ไม่มี API key ไม่มี token ไม่มี login** ตรวจแล้วเรียกได้จริงเมื่อ 2026-08-26

### 2.1 `GET /api/cmip/master`

คืนโครงทั้งระบบในคำขอเดียว

```
headCategories  21 หมวด   01 วัสดุเทหล่อกับที่ … 21 เครื่องสุขภัณฑ์
types           74 รายการ  รหัสจังหวัด + ชื่อ (10 = ส่วนกลาง คือ กทม.+ปริมณฑล รวมกันแล้ว)
period          { start: {year:2545, month:1}, end: {year:2569, month:7} }
lastUpdated     2026-08-12T15:17:21Z
```

### 2.2 `POST /api/cmip/filter` — ตัวหลักที่ต้องใช้

**ชื่อคีย์เป็น PascalCase ทั้งหมด** ส่ง camelCase จะได้ `[]` กลับมาแบบไม่มี error
เสียเวลาไปหลายรอบกับเรื่องนี้ บันทึกไว้กันคนถัดไปเจอซ้ำ

```json
{
  "YearBase": 2558,
  "Categories": [],
  "Search": "",
  "Types": ["10"],
  "HeadCategories": ["01"],
  "TimeOption": true,
  "Period": { "StartYear": 2568, "StartMonth": 8, "EndYear": 2569, "EndMonth": 7 }
}
```

โหมดยาว ใช้ `"TimeOption": false` แล้วส่ง `"SpecificTimes": [[2569,7],[2569,6], …]` แทน `Period`

คำตอบเป็น array ของสินค้า แต่ละตัวมีประวัติรายเดือนมาให้พร้อมในคำขอเดียว

```json
{
  "unitName": "ลบ.ม.",
  "headCategory": "01",
  "headCategoryName": "วัสดุเทหล่อกับที่",
  "commodityCode": "0101010107200000",
  "commodityNameTH": "คอนกรีตผสมเสร็จรูปลูกบาศก์ 300 กก./ตร.ซม. …  ตราซีแพค",
  "years": [
    { "year": 2568, "months": [ { "month": 9, "priceCur": 2543.4, "priceVAT": 2721.44, "type": "10", "typeName": "ส่วนกลาง" } ] }
  ]
}
```

`priceCur` = ราคาก่อน VAT · `priceVAT` = ราคารวม VAT แล้ว ทั้งคู่ผูกกับจังหวัดและเดือนเสมอ

### 2.3 `POST /api/cmip/search` `{ "Keyword": " " }`

คืนบัญชีรายชื่อสินค้าทั้งหมด (`commodityCode` + `commodityNameTH`) ใช้ทำ autocomplete

### 2.4 ข้อจำกัดที่วัดได้จริง

| เรื่อง | ค่า |
|---|---|
| อัตราเรียก | **40 ครั้ง ต่อ 10 วินาที** เกินแล้วตอบ `429 API calls quota exceeded!` |
| ข้อมูลย้อนหลัง | ถึง **มกราคม 2545** — ยาวกว่า 24 เดือนที่คู่แข่งโฆษณามาก |
| การยืนยันตัวตน | ไม่มี |
| เดือนที่ขาด | มีจริง ตัวอย่างที่เจอ สินค้าตัวหนึ่งของส่วนกลางไม่มีเดือน 3–6/2569 ต้องออกแบบให้ช่องว่างเป็นช่องว่าง ห้ามลากเส้นทับ |
| ลำดับเดือน | ไม่เรียงมาให้ ต้อง sort เอง |

## 3. ข้อค้นพบที่เปลี่ยนการออกแบบ — "เรียลไทม์" ของเขาไม่มีอยู่จริง

`lastUpdated` ของ สนค. คือ `2026-08-12` สำหรับข้อมูล **เดือน 7/2569** และช่วงเวลาที่ระบบรองรับ
เป็น `periodType: month` ทั้งชุด แปลว่า **ต้นทางขยับเดือนละครั้ง**

โค้ดของคู่แข่งตั้ง `getTpsoCacheTtl()` ไว้ที่ 15 นาที และตั้งตัวจับเวลาให้ยิงซ้ำทุก 15 นาที
พร้อม comment ว่า *"เรียลไทม์ = แท็บที่เปิดค้างต้องขยับเอง"* ผลคือยิง API ราชการ 96 ครั้งต่อวัน
ต่อผู้ใช้ที่เปิดแท็บค้าง เพื่อรอตัวเลขที่เปลี่ยนเดือนละครั้ง และแถบ "อัปเดตวันนี้" ที่ผู้ใช้เห็น
ไม่ได้แปลว่าราคาขยับวันนี้ แปลว่าเครื่องไปถามมาวันนี้เท่านั้น

**มติของเจ้าของงาน 2026-08-26:** ของเราเช็คทุก 1 ชั่วโมงพอ
ซึ่งยังถี่กว่าที่ข้อมูลขยับจริงประมาณ 720 เท่า จึงเหลือเฟือแน่นอน

### สิ่งที่เราจะพูดบนหน้าจอแทนคำว่าเรียลไทม์

`CONTEXT.md` ห้ามคำว่า ราคาปัจจุบัน ราคาเรียลไทม์ ราคาตลาด กับข้อมูลชุดนี้ไว้ก่อนหน้านี้แล้ว
และตอนนี้มีหลักฐานเชิงตัวเลขรองรับข้อห้ามนั้น หน้าจอของเราจะบอกสามอย่างที่เขาไม่บอก

1. ราคานี้เป็นของ **เดือนไหน** ไม่ใช่ "วันนี้"
2. สนค. **ประกาศเมื่อวันที่เท่าไร** (`lastUpdated`)
3. เครื่องเราไปอ่านมาล่าสุดเมื่อไร — แยกจากสองข้อบนอย่างชัดเจน

## 5. ของแถมสำหรับแอปอื่น

`https://index-api.tpso.go.th/OpenApi/K/Month/MasterData` เป็น API เปิดอีกตัวของ สนค.
คืน **ดัชนีราคาที่ใช้ในสูตรค่า K** โดยตรง (`S` เหล็ก, `G` เหล็กแผ่นเรียบ, `E` เครื่องจักรกล,
`I` ดัชนีผู้บริโภค, `PVC` ท่อ PVC, `PE` ท่อ HDPE, `AC` ท่อซีเมนต์ใยหิน, `W` …)
พร้อม `yearBase` และช่วงเวลาที่มีข้อมูลของแต่ละตัว

แอป ESCALATION K ในทะเบียนต้องใช้ดัชนีชุดนี้ทุกงวด และนี่คือที่มาที่อ้างอิงได้ของมัน
เอกสาร API อยู่ที่ `https://index.tpso.go.th/document/k/get-month`

## 7. สรุปสำหรับการออกแบบ

1. ดึงจาก สนค. เองโดยตรง ไม่แตะ proxy ของคู่แข่ง ไม่ลอกไฟล์ `data/*.json` ของเขา
2. เก็บของที่ดึงมาเป็น snapshot รายเดือนของเราเอง แล้วหน้าเว็บอ่านจาก snapshot
   ไม่ใช่ให้เบราว์เซอร์ผู้ใช้ยิง สนค. เอง — เพดาน 40 ครั้ง/10 วินาที เป็นของทั้งไอพี
3. รอบตรวจของใหม่ ทุก 1 ชั่วโมง ตามมติเจ้าของงาน และเพราะต้นทางขยับเดือนละครั้ง
   รอบนี้จะไม่เจอของใหม่เกือบทุกครั้ง ซึ่งถูกต้องแล้ว
4. ราคาวัสดุมาจาก สนค. · ค่าแรงมาจากบัญชีกรมบัญชีกลาง · ค่าวัสดุ+ค่าแรงต่อหน่วยงานมาจาก สพฐ.
   สามแหล่งนี้ตอบคนละคำถาม ห้ามรวมเป็นตัวเลขเดียวโดยไม่บอกที่มา

   และเปลี่ยนตามโปรโมชัน เอามาเฉลี่ยรวมกันไม่ได้ ต้องแยกแถบและติดป้ายเอง ซึ่งเพิ่มความซับซ้อน
   ให้หน้าจอโดยที่คนประมาณราคาเอาไปขึ้น ปร.4 ไม่ได้อยู่ดี
2. หน้าเว็บทั้งสามเจ้าเป็น SPA ที่ต้องมี session ทดสอบเมื่อ 2026-08-26 คำขอตรงไปหน้าค้นหา
   ของไทวัสดุได้ `307` กลับมา ไม่ใช่ HTML ที่มีราคา การดึงอัตโนมัติจึงต้องรันเบราว์เซอร์จริง
   และพังทุกครั้งที่เขาปรับหน้าเว็บ
3. เงื่อนไขการใช้เว็บเป็นของแต่ละเจ้า การดึงเป็นระบบต้องขออนุญาตก่อน
4. คู่แข่งเองก็ยังทำไม่ได้ ข้อมูลร้านค้าทั้งสามเจ้าบนแอปเขาเป็นชุดตัวอย่างนิ่ง ๆ ที่ไม่เคยอัปเดต
   ทั้งที่ติดป้ายว่าเป็นแหล่งข้อมูลเหมือนแหล่งอื่น

**แหล่งอื่นในรายการของคู่แข่งอีกยี่สิบกว่าแหล่ง** ไม่เอา เพราะส่วนใหญ่เป็นเอกสารเก่าตั้งแต่ปี 2556–2560
ที่ถูกฉบับใหม่ยกเลิกไปแล้ว เช่นเขายังใช้บัญชีค่าแรง ว480 ซึ่ง ว809 ยกเลิกไปตั้งแต่ 14 พ.ย. 2568
