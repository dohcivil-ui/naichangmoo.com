# ฟอนต์ไทยของเรา เทียบกับช่างคิด และตัวเลือกที่มี

ศึกษาเมื่อ 2026-09-01 · อ่านค่าจากเบราว์เซอร์จริงทั้งสองเว็บ ไม่ได้เดาจากโค้ด

หน้าทดลองที่กดสลับค่าดูด้วยตาได้ `.design/typography/font-bakeoff-2026-09-01.html`

## ข้อค้นพบหลัก — เราใช้ฟอนต์ตัวเดียวกับคู่แข่ง

| ค่าที่วัดได้ | นายช่างหมู | ช่างคิด |
|---|---|---|
| ฟอนต์ที่ประกาศ | `Prompt, Noto Sans Thai, Arial` | `Prompt, Sarabun, -apple-system` |
| ตัวหลัก | **Prompt** | **Prompt** |
| ขนาดพาดหัว | 72 px | 32 px |
| น้ำหนักพาดหัว | 600 | 700 |
| ระยะห่างตัวอักษรพาดหัว | **-0.05em** | ปกติ |
| ความสูงบรรทัดพาดหัว | **1.06 เท่า** | 1.55 เท่า |
| ขนาดตัวเนื้อความ | 17.9 px | 13 px |

Prompt เป็นฟอนต์ของโรงหล่อไทย **คัดสรร ดีมาก (Cadson Demak)** ปล่อยเป็น SIL OFL
ใช้เชิงพาณิชย์ได้ฟรีทั้งคู่ ไม่มีปัญหาลิขสิทธิ์

## ทำไมของเราดูไม่สมูท ทั้งที่ฟอนต์เดียวกัน

สาเหตุอยู่ที่**การตั้งค่า** ไม่ใช่ตัวฟอนต์

1. **ระยะห่างตัวอักษรติดลบ 0.05em** ที่ขนาด 72px คิดเป็นการดึงตัวอักษรเข้าหากัน 3.6px ต่อตัว
   ภาษาไทยมีสระบน สระล่าง และวรรณยุกต์ที่กินที่ด้านข้างด้วย การบีบจึงทำให้เกยกัน
2. **ความสูงบรรทัด 1.06 เท่า** ไม่พอสำหรับภาษาไทย ซึ่งต้องการที่ว่างเหนือและใต้ตัวอักษร
3. `.h1-line` ตั้ง `overflow: hidden` ไว้เพื่อทำอนิเมชันตัวอักษรเลื่อนขึ้น เมื่อรวมกับข้อ 2
   มีโอกาสตัดวรรณยุกต์ของบรรทัดแรกทิ้ง

เทียบกับช่างคิดที่ไม่บีบระยะเลยและให้บรรทัด 1.55 เท่า

## ข้อจำกัดของ Prompt ที่เจอมาก่อนแล้ว

Prompt ไม่มีฟีเจอร์ `tnum` และเลข 0-9 กว้างต่างกันถึง 30.9% ตัวเลขในตารางจึงเรียงหลักไม่ตรง
แก้ไปแล้วโดยให้เฉพาะช่องตัวเลขใช้ IBM Plex Sans Thai และมีเทสต์เฝ้าที่
`src/numeric-font-fence.test.ts` — รายละเอียดอยู่ในคอมเมนต์ของ `src/app/layout.tsx`

### ความเห็น

ฟอนต์ฟรีในตารางก่อนหน้าหลายตัวเป็นของคัดสรร ดีมาก ซึ่งเป็นโรงหล่อไทยระดับบนอยู่แล้ว
**การจ่ายเงินจึงไม่ได้แปลว่าได้ฝีมือดีกว่าอัตโนมัติ** เหตุผลที่ควรจ่ายมีสองข้อ
คือต้องการหน้าตาที่ช่างคิดใช้ไม่ได้ เพราะเขาใช้ Prompt อยู่ กับต้องการฟอนต์ที่ไทยและละติน
ออกแบบมาคู่กันจริงในทุกน้ำหนัก ซึ่ง Aktiv Grotesk Thai กับ Forma DJR Thai ทำได้ดีที่สุดในรายการนี้

## ข้อเสนอ เรียงตามผลที่ได้ต่อแรงที่ลง

1. **แก้ค่าจัดตัวอักษรก่อน** ระยะห่างจาก -0.05em เป็นราว -0.005em และความสูงบรรทัดจาก 1.06
   เป็นราว 1.28 เท่า · แตะ `globals.css` อย่างเดียว เห็นผลทันที ไม่ต้องเปลี่ยนฟอนต์
2. **เปลี่ยนตัวเนื้อความเป็นฟอนต์ที่ทำมาเพื่ออ่าน** Anuphan หรือ IBM Plex Sans Thai
   ส่วนพาดหัวจะคง Prompt ไว้ก็ได้
3. **เปลี่ยนฟอนต์พาดหัวให้ไม่ซ้ำช่างคิด** ถ้าต้องการเอกลักษณ์จริงจังค่อยพิจารณาซื้อ

## ข้อจำกัดที่ต้องเคาะก่อนลงมือ

คอมเมนต์ใน `src/app/layout.tsx` บันทึกไว้ว่าเจ้าของงานสั่งเมื่อ 2026-08-28 ว่า
**ห้ามเปลี่ยนฟอนต์ทั้งระบบ** ให้คง Prompt ไว้ · การทำข้อ 2 หรือ 3 จึงต้องให้เจ้าของงาน
ยกเลิกคำสั่งเดิมก่อน ส่วนข้อ 1 เป็นการแก้ค่าจัดตัวอักษร ไม่ใช่การเปลี่ยนฟอนต์
