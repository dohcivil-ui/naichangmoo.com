## ปร.5(ก) — แบบสรุปค่าก่อสร้าง

คอลัมน์: `ลำดับที่ | รายการ | ค่างานต้นทุน (บาท) | FACTOR F | ค่าก่อสร้าง (บาท) | หมายเหตุ`

เงื่อนไขที่พิมพ์ไว้ในช่องหมายเหตุ:

```
FACTOR F
เงินล่วงหน้าจ่าย         = 0 %
เงินประกันผลงานหัก      = 0 %
ดอกเบี้ยเงินกู้            = 5 %
ภาษีมูลค่าเพิ่ม (VAT)      = 7 %
```

**Factor F เลือกครั้งเดียวจากค่างานต้นทุนรวมของหมวด แล้วใช้ค่าเดียวกันทุกบรรทัด**
ทั้ง 21 บรรทัดใช้ 1.2957 เท่ากันหมด ทั้งที่ค่างานต่อบรรทัดต่างกันตั้งแต่ 25,885.00 ถึง 1,532,372.20
การเปิดตาราง Factor F ตามค่างานของแต่ละบรรทัดจะให้ราคากลางผิดทั้งใบ

```
รวมค่างานต้นทุน   7,358,914.87
x Factor F        1.2957
                = 9,534,945.997059  ->  ปัดสองตำแหน่ง  9,534,946.00   ตรงกับที่ใบพิมพ์
```

ตรวจทีละบรรทัดแล้วตรงทั้ง 21 บรรทัด แต่ละบรรทัดคือ `ค่างานต้นทุน x 1.2957` ปัดสองตำแหน่ง
**ใบนี้ไม่มีบรรทัดยอดสุทธิและไม่ตัดเศษ** ตัวเลขเดินทางพร้อมสตางค์ไปจนถึง ปร.6 ซึ่งเป็นจุดเดียวที่ตัด

ลำดับชั้นภายในใบ: `หมวด 1` → `ส่วนที่ 1/2/3` (ทำเครื่องหมาย A, B, C ในคอลัมน์ลำดับที่) → รายการที่มีเลข 1..19

## ปร.4 (ก) — แบบแสดงรายการ ปริมาณงาน และราคา

หัวใบ `แบบ ปร.4 (ก1) แผ่นที่ 1/3` — ปร.4 ของงานก่อสร้างแยกใบตามกลุ่มงาน แล้วใส่เลขกำกับ ก1, ก2, …
และแบ่งหน้าภายในกลุ่มงานนั้นเอง

หัวใบมีช่องที่ schema ปัจจุบันยังไม่มีที่เก็บ:

```
กลุ่มงาน :            1. งานปรับปรุงห้องอเนกประสงค์ชั้น 2
แบบเลขที่/แผ่นที่ :    P16 - P37          <- ช่วงแผ่นแบบที่กลุ่มงานนี้อ้างถึง
```

คอลัมน์: `ลำดับที่ | รายการ | จำนวน | หน่วย | ค่าวัสดุ (ราคาต่อหน่วย, จำนวนเงิน) | ค่าแรงงาน (ราคาต่อหน่วย, จำนวนเงิน) | รวมค่าวัสดุและแรงงาน | หมายเหตุ`

ลำดับชั้น: `หมวด 1 หมวดงานอาคาร` → `ส่วนที่ 1 : งานปรับปรุงอาคารสำนักงาน` → `1. งานปรับปรุงห้องอเนกประสงค์ชั้น 2` → `ลำดับที่ 1 งานฐานราก F1` → บรรทัดวัสดุที่ขึ้นต้นด้วย `-` และไม่มีลำดับที่

ตัวอย่างบรรทัดที่ตรวจแล้ว

```
งานคอนกรีตโครงสร้าง 240 ksc.   1.65 ลบ.ม.  วัสดุ 1,651.00 -> 2,724.15   แรง 485.00 -> 800.25   รวม 3,524.40
เหล็กข้ออ้อย ขนาด 16 มม. SD 40  62.00 กก.   วัสดุ    25.00 -> 1,550.00   แรง   3.30 -> 204.60   รวม 1,754.60
เหล็กเส้นกลม ขนาด 9 มม. SR 24   25.00 กก.   วัสดุ    25.24 ->   631.00   แรง   4.10 -> 102.50   รวม   733.50
```

ข้อสังเกตที่มีผลต่อ schema

- **วัสดุกับค่าแรงบางรายการถูกแยกเป็นคนละบรรทัด** ไม่ใช่แค่คนละคอลัมน์ เช่น `ค่าแรงงานไม้แบบ` 6.50 ตร.ม.
  มีเฉพาะฝั่งค่าแรง ส่วน `ค่าวัสดุไม้แบบ` 5.20 ตร.ม. มีเฉพาะฝั่งวัสดุ และปริมาณของสองบรรทัดนี้ไม่เท่ากัน
- **ฝั่งที่ไม่มีค่าเขียนเป็นขีด `-` ไม่ใช่ศูนย์** ซึ่งอ่านได้ว่า "ไม่มีรายการนี้" ไม่ใช่ "ราคาเป็นศูนย์"
- **สเปกเหล็กอยู่ในข้อความอิสระ** — ชนิด (ข้ออ้อย/เส้นกลม), ขนาด (16 มม./9 มม.) และชั้นคุณภาพ (SD 40/SR 24)
  ปนอยู่ในคอลัมน์รายการทั้งหมด ตราบใดที่ยังเป็นแบบนี้ ปร.2 ที่แยกคอลัมน์เหล็กตามขนาดเส้นจะสร้างไม่ได้

## สิ่งที่ชุดนี้ยังตอบไม่ได้

- **ชุดนี้เทียบช่วงหรือไม่ ยังตรวจไม่ได้** ต้องใช้ตาราง Factor F ของดอกเบี้ย 5% ประกบ ซึ่งไม่มีในมือ
  แต่ไม่กระทบการตัดสินใจ เพราะ ว481 เขียนกฎไว้เองในหมายเหตุท้ายตารางทุกหน้าว่า
  "กรณีค่างานอยู่ระหว่างช่วงของค่างานต้นทุนที่กำหนด ให้เทียบอัตราส่วนเพื่อหาค่า Factor F"
  ดู ADR 0008 ข้อ 9
- **อัตราดอกเบี้ย 5% มาจากหนังสือเวียนฉบับไหน** ยังไม่รู้ แต่รู้แล้วว่า**ไม่ต้องรู้เพื่อใช้งาน**
  ว481 ระบุเองว่าตาราง 6% ใช้ "จนกว่าจะมีประกาศเปลี่ยนแปลง" และประกาศคณะกรรมการราคากลางฯ
  ข้อ 13 กำหนดว่าออกตารางใหม่เมื่ออัตราเฉลี่ยเปลี่ยนถึงร้อยละ 1 ซึ่งอธิบายระยะห่าง 5% → 6% → 7%
  **ชุด สตง. นี้จึงใช้เป็นแบบของรูปเอกสารได้ แต่ค่า Factor F 1.2957 ในนั้นใช้คำนวณงานใหม่ไม่ได้**
- **ค่าใช้จ่ายพิเศษเสียภาษีเมื่อไร** ใบนี้ไม่มีคอลัมน์ภาษี แต่แบบฟอร์มเปล่าใน `km/ตย ปร1-6 ราชมงคล..xlsx`
  มีชีต "รายละเอียดค่าใช้จ่ายพิเศษ" ที่เขียนว่า "รายการใดต้องชำระภาษีมูลค่าเพิ่ม ให้รวมค่าภาษีมูลค่าเพิ่มด้วย"
  ชุด สตง. อาจเป็นกรณีที่ไม่มีรายการใดต้องเสียภาษี ไม่ใช่กรณีที่ฟอร์มไม่รองรับ
