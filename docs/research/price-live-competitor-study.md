## 2. Information architecture — ทางเดินจาก "อยากได้ราคา" ถึง "ได้ตัวเลข"

โครงหน้าเดียวจากบนลงล่าง: topbar (ปุ่มกลับ + ชื่อแอป + badge สถานะสด) → แถบค้นหา + dropdown 3 ตัว
(ภูมิภาค / จังหวัด (TPSO) / เรียงตาม) → แถวชิป 5 แถว (ประเภท / ประเภทงาน / หมวดงาน / แหล่งข้อมูล / หมวด)
→ แถบสรุปผล + ปุ่ม 3 ปุ่ม (เครื่องคำนวณค่าขนส่ง / Export CSV / Plot PDF) → การ์ดราคา (infinite scroll ครั้งละชุด
มี IntersectionObserver โหลดเพิ่ม) → footer อธิบายสัญลักษณ์ความน่าเชื่อถือ + รายชื่อแหล่งทั้งหมด

**จำนวน control ที่ผู้ใช้เจอก่อนถึงราคาแรก (นับจริง):**

### Hands-on: การ์ดผลลัพธ์ + การล็อกราคา

การ์ด 1 ใบ: ชิปหมวด + ชิปประเภท + ชิป verification (`🔗 ตรวจสอบได้` / `📄 เอกสารราชการ` / `⚠ ตัวอย่าง`) + รหัส
+ badge แนวโน้ม (`+3.5% / 24 เดือน` หรือ `8 เดือนก่อน` ถ้าไม่มี series) + ชื่อ + spec + ราคาใหญ่/หน่วย
+ `ต่ำสุด ฿x · สูงสุด ฿y` + range bar (canvas) + pill แหล่งที่มา + ดาว favorite

การล็อก 2 ชั้นที่เจอจริง: ไม่ login → เห็นราคาแค่ **"100 รายการแรก (สุ่ม)"** ที่เหลือเบลอราคา + ปุ่ม
`เข้าสู่ระบบเพื่อดูราคา` ทับ / login แล้วแต่หมดโควตา → เบลอแบบ `price-locked` (config `locked_visible_pct:20`)
**บั๊กที่เจอสด ๆ:** บัญชีที่ signed-in + entitled อยู่ ยังเจอการ์ด 119/120 ใบขึ้น `เข้าสู่ระบบเพื่อดูราคา`
และคลิกแล้วเปิด modal ชวน login ทั้งที่ล็อกอินอยู่ (สถานะ auth มาถึงช้ากว่า render แล้วไม่มีการ re-render)
ที่แย่กว่านั้น: การ์ดที่เบลอราคารวม **แต่บรรทัด `วัสดุ ฿95.00 + ค่าแรง ฿80.00` โชว์ชัดเต็มตา** — paywall รั่วเอง

### Hands-on: detail modal 4 แหล่ง

เปิดจริง 4 รายการ ทุกใบมีโครงเดียวกัน: ชื่อ+รหัส+กลุ่ม → ปุ่ม `เพิ่มเป็นรายการโปรด` → tile 4 ใบ

### Hands-on: สลับภูมิภาค/จังหวัด

- กรุงเทพ → ภาคเหนือ: banner `กำลังอัปเดตราคา … กรุณารอสักครู่ · ระบบกำลังดึงราคาสดจาก TPSO ~3-5 วินาที · อย่าเพิ่งกดอะไร`

  ครั้งละ ≥6s) — จังหวัดเย็นอาจรอกราฟหลายนาที
- ภูมิภาค/จังหวัดที่เลือกถูกจำข้ามการเปิดใหม่ (localStorage) — เปิดมาอีกทีอยู่เชียงใหม่ต่อ

## 3. The data itself

**ประเภท 3 ค่า:** `วัสดุ` (price) · `ค่าแรง` (labor_thb) · `งานสำเร็จ` (มีทั้งคู่/เหมารวม)
**โครง item:** `id · code · category · group · name · spec · unit · weight_kg · applies_to[] · disciplines[] · sources[]`
**โครง source ต่อแถวราคา:** `source · price | labor_thb · date · url · product_code · aggregation{type,n,scope} · note`
**โครง "แหล่ง" (source registry):** `id · label · agency · color · kind(index/official/retail/industry) · freq(monthly/biannual/annual/weekly/irregular) · verification(official_doc/manufacturer/sample) · document_url · scope{vat, transport, profit, factor_f, note}` — ชั้น scope ต่อแหล่งนี้คือความคิดที่ดีที่สุดของเขา (ตอบ "ราคานี้รวมอะไรแล้วบ้าง" ต่อทุกตัวเลข)

**ปริมาณข้อมูลตามแหล่ง (ตัวเลขบนชิปจริง):** TPSO Live กรุงเทพ/ปริมณฑล 5,802 · สพฐ. 2569 = 979
· HomePro 184 · ไทยวัสดุ 174 · ค่าแรง CGD ว480 = 151 · TPSO legacy sample 100 · BB 2557 = 77
· ราคากลาง กรมบัญชีกลาง 62 · ชลประทาน CGD+RID 40 · BB ครุภัณฑ์ 2567 = 29 · ที่เหลือย่อย ๆ อีก 16 แหล่ง

## 8. UX weaknesses — จัดอันดับ 8 ข้อที่เราต้องชนะ

1. **Paywall โกหกสถานะตัวเอง** — ผู้ใช้ login + มีสิทธิ์ ยังเจอ 119/120 การ์ดเบลอ + ปุ่ม "เข้าสู่ระบบเพื่อดูราคา"
   และ modal ชวน login ซ้ำ ขณะ header อวด `✨ ไม่จำกัด` กับ `ADMIN · auto-unlocked` (ทั้งที่ API ตอบ `admin:false`)
   — สถานะสามที่ไม่คุยกัน
2. **ราคาเบลอแต่เฉลยตัวเอง** — การ์ดล็อกโชว์ `วัสดุ ฿95 + ค่าแรง ฿80` ชัด ๆ ใต้ราคาที่เบลอ
3. **กำแพง filter ~120 control / 5 แถวชิป / 66 หมวด** — มือถือกินพื้นที่ **1.4 หน้าจอเต็ม** ก่อนเห็นการ์ดแรก
   (การ์ดแรก y≈1794px ที่ viewport สูง 1263px) ราคาแรกอยู่ ~1.55 หน้าจอ
4. **"เรียลไทม์" จริงแค่บางส่วน** — ร้านวัสดุทั้งสามและราคากลางฝั่งวัสดุเป็น sample นิ่ง ค่าแรงเด่น ๆ (ช่างไฟ ฿800)
   เป็น sample + แนวโน้ม "+5.1%" ที่คำนวณจากราคา 2 แหล่งคนละเดือน · กราฟ 24 เดือนมีจริงเฉพาะ TPSO Live
5. **ตัวคูณภูมิภาคเหมาเข่ง** คูณทับราคาจริงรายจังหวัดและค่าแรงราชการทั่วประเทศ — เลขบนจอไม่ตรงเอกสารที่ตัวเองลิงก์
6. **ค้นหาอ่อน** — substring เท่านั้น `ช่างไฟ` เจอ 1/265 · ไม่มีคำพ้อง/หน่วยงาน/รหัสไขว้ · ผลค้นเปลี่ยนตามจังหวัดแบบเงียบ ๆ
   (166 → 19 โดยไม่บอกเหตุ)
7. **ทุกอย่างจบใน modal ที่แชร์ไม่ได้** — ไม่มี URL ต่อรายการ ส่งลิงก์ราคาให้เพื่อนร่วมทีมไม่ได้ · Export ผูกกับ
   "รายการโปรด" เท่านั้น ไม่ใช่ผลกรอง
8. **Modal มือถือล้นจอ** — ตาราง "ราคารายแหล่ง" คอลัมน์วันที่โดนตัด, tile สถิติโดนตัดขอบขวา, badge แนวโน้มบนการ์ด
   หลุดขอบ, แกน Y ซ้ำเลข `฿14 ฿14 ฿13 ฿13`

รอง ๆ: แถบ trial + ปุ่มแชท ลอยทับเนื้อหาล่างซ้าย-ขวาตลอดเวลา · banner "อย่าเพิ่งกดอะไร" สั่งห้ามผู้ใช้แทนที่จะ

## 11. สิ่งที่เขาทำดี (ต้องเสมอหรือดีกว่า ไม่ใช่แค่ด่า)
