## สอง — คำวินิจฉัยของเจ้าของงานที่ผูกงานถัดไป

1. **ทะเบียน:** ทุกแอป "ประกาศแล้ว + กำลังเตรียมระบบ" — เจ้าของงานหยุดที่สวิตช์เปิดใช้ ESTIMETR เอง
   ("ยังไม่มีงานไหนเสร็จ 100%") การเปิดใช้คือ **IP-179** รอเกณฑ์เดโมระดับ A · ผู้ดูแลคือ doh.civil@gmail.com
2. **ทิศทางหกเฟส (DIRECTION.md):** เดโมครบ 7 แอปตามเกณฑ์ A/B/C → สมาชิก+เอกสารกฎหมาย →
   deploy Hostinger VPS หลังเฟส 3 แล้ว soak → เปิดรับสมาชิก+จ่ายเงิน → Hermes 24/7 ท้ายสุด
3. **ราคา:** ต้องสูงกว่าคู่แข่งเพราะมีผู้ช่วย AI (DIRECTION.md เฟส 5) และ **คำแถลง "แอปนี้มีผู้ช่วย AI"
   เป็นรายแอปในทะเบียน (IP-190)** — พาดหัวชุด D "ทุกแอปมี AI" เก็บไว้ใช้วันเดโมครบเจ็ดแอป
4. **Hermes 24/7 = ธุรกิจบริการ setup ตาม request** — use case แรกอยู่ในเอกสารลับ ช่องบนหน้าแรก
   พูดได้แค่ประโยคแนะนำ + ปุ่มส่ง use case (ชี้ /enterprise) · หน้า request เฉพาะ = IP-178
5. **หน้าลูกค้าโชว์ตัวเลขลูกค้า** — ห้ามเอาบัญชีงานภายใน (โรดแมปนับรายการ) ขึ้นหน้าขาย
   (บันทึกเป็น memory แล้ว) และเลขทุกตัวต้องนับสดจากข้อมูลจริง ห้ามพิมพ์ตาย
6. **ผู้ช่วย AI:** สถาปัตยกรรมอนุมัติแล้วทั้งชุด (ai-assistant-design.md) — รอยต่อ 7 จังหวะ ·
   กฎเหล็ก schema ห้ามมีช่องเงิน · นับโควตาเป็นครั้ง · สมาชิกหมดอายุใช้ไม่ได้ · failover
   OpenAI→DeepSeek ก่อน deploy · land-acquisition ไม่ทำในรีโปนี้
