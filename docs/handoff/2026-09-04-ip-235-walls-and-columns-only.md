### ค่ำ — ห้องน้ำ (commit ล่าสุด)
เจ้าของงานส่งภาพห้องน้ำที่พื้นเป็นตารางกระเบื้อง มีโถ อ่าง สัญลักษณ์ เต็มห้อง แล้วสั่งว่า
"ให้คิดว่ามันคือพื้นที่หนึ่ง ไม่ต้องสนใจลายเส้นต่าง ๆ ให้ยึดเสา กับเส้นผนัง แนวประตู เหมือนห้องปกติ
มันก็แค่กว้างคูณยาว" และ "หาวิธีไหนก็ได้ที่จะทำให้การเลือกของเราเห็นเป็นพื้นที่ใหญ่วิ่งรอบเสาจริง
หรือเสาเอ็น แนวผนัง แนวประตู"

**ของเดิมทำกลับด้าน** ถือว่าทุกเส้นกั้นแล้วค่อยคัดสัญลักษณ์ออกทีละชนิด ซึ่งไม่มีวันครบ · คลิกในห้องน้ำ
ได้ "จุดอยู่บนเส้น" เพราะช่องกระเบื้อง 0.28 ม. (132 ช่อง) ขนาดพอดีเกณฑ์เสา พื้นทั้งห้องถูกถมดำ

**ของใหม่** `structuralMask` ใน `src/lib/region-fill.ts` เขียนใหม่ทั้งตัว ถามว่า *อะไรคือผนัง*
| สิ่งที่ยอมรับ | เกณฑ์ |
|---|---|
| ผนังแบบคู่เส้น | เส้นตรงยาว ≥ 1 ม. มัธยฐานหนา ≥ 2 px มีเส้นยาวอีกเส้นขนานห่าง 3–11 px และช่องระหว่างเป็นลายผนัง (หมึก ≥ 15%) หรือสะอาด (≤ 2%) · ตัดสินทั้งเส้น เก็บจากจุดคู่แรกถึงจุดคู่สุดท้าย |
| ผนังทึบ / แถบหน้าต่าง | แถบหนา ≥ 3 px ที่ยาว ≥ 1 ม. **ในตัวเอง** (ไม่ยืมความยาวจากผนังที่ชน) |
| ทั้งคู่ต้อง | อยู่ในก้อนหมึกใหญ่ ≥ 4 ม. **นับบนหมึกทั้งหมด** (ลายอิฐร้อยผนังคนละท่อนเข้าด้วยกัน) |
| เสาแบบกรอบ | ช่องปิดสนิทบนหมึกจาง (≤ 200) ขนาดเท่าเสา เต็มกรอบ ≥ 85% ด้านยาว ≤ 2 เท่าด้านสั้น ล้อมด้วยเส้น ≥ 90% ครบสี่ด้าน ชิดผนัง รอบนอก 2–6 px รก ≤ 30% (ไม่นับเนื้อผนัง) · ช่องที่ติดกันและขนาดใกล้กันรวมเป็นก้อนเดียวก่อน (กากบาท) |
| เสาทึบ | ก้อนหนา ≥ 3 px ขนาดเท่าเสา เต็ม ≥ 70% ชิดผนัง |
| **ที่เหลือมองข้ามหมด** | กระเบื้อง สุขภัณฑ์ ตัวอักษร กรอบป้าย สามเหลี่ยม เส้นตัดหน้าตัด |

ค่าใหม่: `WALL_THICKNESS_METRES = 0.25` (ส่งเข้า `wallThicknessPixels`) · `COLUMN_SYMBOL_THRESHOLD = 200`
ค่าคงที่ย่อยอยู่ในไฟล์พร้อมเหตุผลทุกตัว · ท้ายท่อส่งเพิ่ม `removeJogs(…, column.min)` ยุบขั้นเดี่ยว
ที่แคบกว่าเสา · `traceRectilinearOutline` แก้บั๊กมุมที่มีสองทางออก (เคยปิดวงด้วยเส้นเฉียง)

**เทสต์** fixture `pageWithRoom` วาดผนังเป็นเส้นคู่หนา 2 px ช่องสะอาด 1 px งอกออกนอกกรอบ
เนื้อในเท่าเดิม ตัวเลขในเทสต์เดิมจึงไม่ขยับ · ทั้งชุด **1,143 ผ่าน**
