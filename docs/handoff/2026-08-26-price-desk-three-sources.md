| บัญชีราคา สพฐ. 2569 | ค่าวัสดุ + ค่าแรง ต่อหน่วยงาน 1,949 รายการ | อ่านครบทั้งเล่ม |

### สามอย่างที่จับได้ระหว่างทาง และจะเสียเวลาซ้ำถ้าไม่รู้

1. **`backdrop-filter` ถูกตัวแปลง CSS ทิ้งทั้งไฟล์** ถ้าเขียนคู่กับ `-webkit-backdrop-filter`
   มันเก็บแต่ตัวมีคำนำหน้าแล้วทิ้งตัวมาตรฐาน ผลคือกระจกไม่เบลอเลยโดยไม่มี error
   **ให้เขียน `backdrop-filter` ตัวเดียว** และห้ามส่งค่าผ่าน `var()` เพราะจะถูกทิ้งเหมือนกัน
2. **`grid-auto-rows: 1fr` กับกริดที่มีหัวกลุ่มปนอยู่** จะยืดแถวหัวกลุ่มให้สูงเท่าแถวการ์ด
   กลายเป็นช่องว่างยักษ์ใต้ตัวหนังสือ ความสูงการ์ดเท่ากันได้จากการล็อกแถวภายในการ์ดแทน
3. **`grid-template-columns` ปริยายคือ `min-width: auto`** ข้อความยาวจะดันเนื้อหาทะลุกรอบ
   วัดได้จริง 105px ต้องใส่ `minmax(0, 1fr)` แล้วให้ ellipsis จัดการ

## สาม — งานถัดไป และข้อจำกัดที่ต้องตัดสินใจก่อนเขียนโค้ด

### IP-157 · PRICEMETR ยังใช้แถบนำทางที่เขียนเอง

เซสชันนี้เขียนแถบชื่อ `gl-platbar` ไว้ใน `price-workspace.tsx` เพราะต้นแบบอยู่นอก `/apps`
จึงไม่ได้เปลือกกลาง **แต่นี่เป็นทางแก้ชั่วคราวที่ต้องถอด** ตามที่ `app-shell` skill เขียนไว้

**ข้อจำกัดที่ต้องตัดสินก่อน** ADR 0014 กำหนดว่าแอปเป็น "ประกาศแล้ว" เพราะผู้ดูแลกดประกาศ
การย้ายต้นแบบเข้า `/apps` เพื่อให้ได้เปลือกจึงเป็นทางแก้ที่ผิด วิธีที่ถูกคือแยกเปลือกออกมาให้
ต้นแบบใส่ได้โดยแถบบริบทไม่แสดงป้ายสิทธิ์ ซึ่งต้องแก้ `AppShell` ไม่ใช่เขียนอันที่สอง

สิ่งที่แถบปัจจุบันให้ และของใหม่ต้องไม่ทำหาย

- ทางออกไปหน้ารวมแพลตฟอร์ม เห็นตลอดเวลา ล็อกติดขอบบน
- ป้ายใช้คำว่า `HOME CENTER` กับไอคอนบ้าน **ห้ามกลับไปใช้ "ลูกศรซ้าย + ชื่อแบรนด์"**
  เพราะเป็นลายเซ็นของคู่แข่ง เจ้าของงานสั่งเปลี่ยนเมื่อ 2026-08-26
- ทางกลับหน้าหลักของแอปเอง และทางถอยหนึ่งชั้น เป็นคนละปุ่มกัน

### งานที่เหลือของแอปนี้ เรียงตามที่ควรทำก่อน

| รายการ | เรื่อง |

| IP-162 | ราคายังอยู่ในหน่วยความจำเซิร์ฟเวอร์ รีสตาร์ตแล้วหาย ต้องลงฐานข้อมูล |
| IP-163 | รายการที่หยิบไว้ยังอยู่ในหน้า ต้องเก็บข้ามเครื่องและส่งต่อเข้า ESTIMETR |

### เรื่องที่เจ้าของงานยังไม่ได้เคาะ

1. **ชื่อแอป** เซสชันนี้ตั้ง PRICEMETR ไว้ให้เข้าชุดกับ ESTIMETR และเลี่ยงคำว่าเรียลไทม์
   ที่ `CONTEXT.md` ห้ามไว้กับข้อมูลชุดนี้ ยังไม่ได้ยืนยัน
2. **ราคาและรอบเก็บเงิน** ยังไม่กำหนด คู่แข่งตั้งไว้ 69 บาทต่อเดือน และตลอดชีพ 299 บาท
3. **จำนวนบรรทัดสูงสุดของรายการที่หยิบไว้** สำหรับสมาชิกฟรี
