**รุ่น** v0.91.1 The Floating Menu Is Opaque Again · **งาน** IP-211 IP-212
**ขั้นตอนที่ข้าม** ข้าม `/grill-with-docs` เพราะเป็นการแก้บั๊กของรุ่นก่อนหน้าที่ระบุสาเหตุได้ชัด

## หนึ่ง — เจ้าของงานเห็นก่อน ไม่ใช่ผมเจอเอง

เจ้าของงานส่งภาพหน้าจอมาถามว่า "ทำไมเพี้ยน" ในภาพคือแถบนำทางของหน้า `/market/estimeter`
มี**วงรีสีเขียวอ่อนสูงราวครึ่งจอ**คาอยู่รอบปุ่มบัญชี และเมนูที่เปิดออกมามีภาพประกอบทะลุขึ้นมาทับ

**เกิดจากรุ่น v0.91.0 ที่ผมเพิ่งปล่อยไปเมื่อครู่**

## สอง — สาเหตุ

รุ่นก่อนตั้ง `position: relative` **รวดเดียวให้ทุกใบในชุดการ์ดกระจก** ซึ่งในรายการนั้นมีสองใบ
ที่มีตำแหน่งเป็นของตัวเองอยู่แล้ว

| ใบ | ตำแหน่งเดิม | ผลเมื่อถูกทับ |
|---|---|---|
| `.account-panel` เมนูบัญชี | `absolute` | เลิกลอย ตกลงมาอยู่ในสายเนื้อหา ดันปุ่มทรงแคปซูลให้ยืดเป็นวงรี |
| `.estimation-evidence` แผงหลักฐาน | `sticky` | เลิกเกาะขอบบน (ไม่เห็นผลจริงเพราะไม่มีหน้าไหนเรนเดอร์คลาสนี้ เป็น CSS ตาย) |

**เรื่องที่สองที่เจอตามมา** เมนูบัญชีเป็นกระจกโปร่ง ของที่อยู่ข้างหลังจึงทะลุขึ้นมา
กรณีนี้คือภาพประกอบของหน้าตลาด ทำให้อ่านรายการในเมนูไม่ออก

## สาม — ทำไมรุ่นก่อนตรวจแปดหน้าแล้วยังหลุด

ผมตรวจการ์ดครบทุกหน้าและวัดคอนทราสต์ทุกข้อความ **แต่ไม่เคยกดเปิดเมนูบัญชีเลยสักหน้า**
ตัวตรวจของผมไล่เฉพาะของที่แสดงอยู่ตอนโหลดหน้า ส่วนเมนูนี้ต้องกดถึงจะโผล่

**บทเรียน: ของที่ต้องกดถึงจะเห็น ต้องกดเปิดตอนตรวจ** เมนู ป็อปโอเวอร์ กล่องโต้ตอบ
แถบแจ้งเตือน และสถานะที่เกิดหลังผู้ใช้ทำอะไรบางอย่าง ไม่มีทางเจอจากการโหลดหน้าเปล่า ๆ

## สี่ — สิ่งที่แก้

1. **ตั้งตำแหน่งให้เฉพาะใบที่ยังไม่มีตำแหน่งของตัวเอง** ไม่ใส่รวดเดียวทั้งรายการ
   พร้อมคอมเมนต์กำกับว่าสองใบไหนห้ามทับและทับแล้วพังอย่างไร
2. **ถอดเมนูบัญชีออกจากชุดการ์ดกระจก** คืนพื้นทึบให้มัน
   พร้อมกฎที่เขียนไว้ในโค้ด: **กระจกใช้กับการ์ดที่นั่งอยู่บนพื้นของหน้า ไม่ใช้กับของที่ลอยทับของอื่น**
3. **แก้คำศัพท์ต้องห้าม** ที่รุ่น v0.91.0 ใช้ผิดทั้งรุ่น (ดูหัวข้อห้า)

## ห้า — คำศัพท์ที่ผมใช้ผิดทั้งรุ่น

เจ้าของงานทักว่า "เรื่องคำศัพท์ ผมว่าเราแก้แล้วไม่ใช่เหรอ แก้เยอะด้วย" — ถูกต้อง
กฎอยู่ใน `~/.claude/CLAUDE.md` ระดับเครื่อง ตั้งไว้ตั้งแต่ 2026-08-28 ว่าคำเปรียบเทียบที่ประดิษฐ์เอง
ห้ามใช้เป็นศัพท์หลักในเอกสาร ใช้ได้เฉพาะตอนอธิบายให้ฟังเท่านั้น

ผมใช้คำต้องห้ามไป **7 จุดในรุ่นเดียว** ทั้งในคอมเมนต์โค้ด บันทึกส่งงาน บัญชีบันทึก และ CHANGELOG
รวมถึงใช้ในบทสนทนากับเจ้าของงานตลอดทั้งรุ่น

| ที่ใช้ผิด | ที่ถูกตามตาราง |
|---|---|
| คำเปรียบเทียบเรื่องครัว | **SSOT (แหล่งอ้างอิงหลัก)** |
| คำเปรียบเทียบเรื่องเปลือก | **App Shell (โครงหลักของแอป)** |

แก้ครบทุกจุดที่เซสชันนี้เขียนแล้ว · **เอกสารเก่าก่อนหน้านี้ยังมีคำเก่าค้างอยู่ ไม่ได้แตะ**
เพราะเป็นบันทึกประวัติของรุ่นที่ปิดไปแล้ว ถ้าเจ้าของงานอยากให้กวาดทั้งรีโปด้วย สั่งได้

## หก — การตรวจ

- `pnpm lint` · `pnpm typecheck` · `pnpm test` ผ่าน 777 ตัว ไม่มีตัวแดง
- เปิดเมนูบัญชีที่ `/market/estimeter` ด้วย Microsoft Edge จริง หลังแก้ได้ปุ่มสูง **41px**
  แถบนำทาง **85px** เมนูลอยอยู่ใต้ปุ่มด้วย `absolute` กว้าง **324px** ตามที่ออกแบบไว้
  และเมนูทึบจนอ่านออกทุกบรรทัด
- ไล่ดูทีละคลาสในชุดการ์ดว่าเดิมเป็น static, relative, sticky หรือ absolute
  เพื่อยืนยันว่าไม่มีใบไหนถูกทับตำแหน่งอีก
- ค้นคำต้องห้ามในทุกไฟล์ที่เซสชันนี้เขียน เหลือศูนย์จุด
