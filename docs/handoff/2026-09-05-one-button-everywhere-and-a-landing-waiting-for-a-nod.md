## สี่ — บั๊กที่เจอและแก้ไปแล้ว เก้าตัว

1. **ปุ่มลอยของแผงผู้ช่วยตัดคำสามบรรทัด** เพราะ `.assistant-dock` ไม่ได้ตั้งความกว้าง
2. **เส้นอ้างอิงที่เลือกไว้ค้างข้ามหน้า** กด Delete แล้วลบของบนหน้าที่มองไม่เห็น
3. **สเกลตั้งได้แต่เอาออกไม่ได้**
4. **ปุ่มทับตัวหนังสือที่อยู่เหนือมัน 13 พิกเซล** เพราะ `<a class="button">` เป็น inline
   และ padding บนล่างของกล่อง inline ไม่ดันอะไรเลย
5. **ปุ่มเต็มความกว้างบนมือถือ ตัวหนังสือชิดซ้ายมาตลอด** เจ็ดที่สั่ง `justify-content: center`
   ซึ่งไม่ทำงานกับ inline-block · CSS อ่านเหมือนถูกแล้ว แต่ผลไม่เป็นอย่างนั้น
6. **`@media (pointer: coarse)` ลบเงาแข็งใต้ปุ่มทิ้งบนแท็บเล็ต** ซึ่งเป็นเครื่องที่เจ้าของงานใช้จริง
7. **ปุ่มที่กดไม่ได้ใช้ `opacity .48`** ซึ่งกดคอนทราสต์ของตัวหนังสือลงไปด้วย
8. **ตัวหนังสือเขียวบนพื้นจางตกเกณฑ์ AA สิบสองจุด** วัดได้ 3.72 ถึง 4.30
   บันทึกใน globals.css เมื่อ 2026-08-30 รู้เรื่องนี้แล้วแต่แก้ไปแค่หน้าเดียว
9. **`micro-button` ติดอยู่ 71 จุดโดยไม่มีกฎ CSS สักบรรทัด** เป็นคลาสที่ไม่เคยทำอะไรเลย
