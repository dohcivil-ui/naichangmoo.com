# Handoff — `feature/escalation-factor-k: แกนคำนวณค่า K จาก ว 109`

> **ข้าม `/grill-with-docs`** เจ้าของงานสั่งให้ปิดงานของ session นี้ให้จบภายในรอบเดียวแล้ว commit และ push การตัดสินใจทั้งหมดของรอบนี้ถูกซักและตกลงกันสด ๆ ในบทสนทนา และบันทึกไว้ครบในแผนงานกับเอกสารฉบับนี้ คำศัพท์ใหม่ที่เกิดขึ้นยังไม่ได้ลง `CONTEXT.md` เป็นงานค้างที่ระบุไว้ในหัวข้อ Next action

## Description

รอบนี้ยังไม่มีหน้าจอ ยังไม่มีเส้นทาง และยังคำนวณจริงไม่ได้โดยตั้งใจ สิ่งที่ลงไปคือ **ชุดข้อมูลของ ว 109 ทั้ง 35 รายการที่ตามรอยกลับไปหาไฟล์ต้นฉบับได้ และแกนคำนวณที่เดินบนจำนวนเต็มล้วน** พร้อมเทสต์ที่จับกฎซึ่งเอกสารกำหนดไว้เองสามข้อ คือตัดทศนิยมทิ้งไม่ปัดเศษ ทำเลขสัมพันธ์ให้เสร็จก่อนคูณสัมประสิทธิ์ และเกณฑ์ส่วนต่างเป็นส่วนที่ไม่คิดให้ ไม่ใช่แค่ด่านผ่าน

ทุกหมวดยังตั้ง `reviewedBy: null` ไว้ แปลว่า `computeK()` ปฏิเสธทุกการเรียกในวันนี้ นั่นคือพฤติกรรมที่ต้องการ ไม่ใช่งานที่ทำไม่เสร็จ ตัวเลขที่ออกจากสูตรซึ่งยังไม่มีใครตรวจ จะดูเหมือนตัวเลขที่ตรวจแล้วทุกประการเมื่อไปอยู่ในเอกสารที่ผูกกับสัญญาราชการ

## สามสิ่งที่วัดได้และเปลี่ยนรูปงาน

**ทศนิยมลอยตัวกินหลักสุดท้าย** `Math.trunc((1.045 - 0.04) * 1000)` ให้ 1004 ไม่ใช่ 1005 เพราะ `1.045 - 0.04` คือ 1.0049999999999999 ถ้าปล่อยไว้ เงินชดเชยงวดหนึ่งจะเพี้ยนจาก 320,600 เป็น 256,480 บาทโดยที่โค้ดอ่านแล้วดูถูกทุกบรรทัด ทั้งโมดูลจึงเดินบนจำนวนเต็ม และมีเทสต์ที่ยืนยันว่าการเขียนแบบผิดให้ 1004 จริง เพื่อไม่ให้ใครเผลอเขียนกลับมา

**เกณฑ์ส่วนต่างไม่ใช่ค่าคงที่** มาตรการชั่วคราวปี 2569 ลดเกณฑ์จาก ±4% เหลือ ±2% สำหรับงวดที่ส่งมอบระหว่าง 28 ก.พ. ถึง 30 ก.ย. 2569 และเปลี่ยนเดือนฐานสำหรับสัญญาที่ลงนามในช่วงเดียวกัน **สองข้อนี้ใช้วันคนละตัวเป็นตัวตัดสิน** ข้อแรกดูวันส่งมอบงวด ข้อหลังดูวันลงนามสัญญา สัญญาเดียวจึงเข้าข้อหนึ่งแต่ไม่เข้าอีกข้อได้ และงวดต่างกันในสัญญาเดียวใช้เกณฑ์ต่างกันได้ เกณฑ์จึงเป็นข้อมูลที่มีช่วงบังคับใช้ ไม่ใช่ตัวเลขในโค้ด

**แหล่งดัชนีที่ถูกต้องไม่ใช่ชุดที่วางแผนไว้ตอนแรก** แผนเดิมจะต่อ `data.moc.go.th` ซึ่งผิด เพราะชุดนั้นไม่มีหมวดวัสดุก่อสร้างที่ตัดเหล็กและซีเมนต์ออกอย่างที่ตัวแปร M ต้องการ ใช้แทนกันจะกลายเป็นนับเหล็กกับซีเมนต์ซ้ำกับพจน์ของมันเอง ตัวจริงคือ `POST https://index-api.tpso.go.th/OpenApi/K/Month` ซึ่งเรียกจริงแล้วคืนครบ 13 รหัสตรงกับตัวอักษรตัวแปรของ ว 109 พอดีทุกตัว และคืน `yearBase: 2530` ตรงกับที่เอกสารกำหนด จึงไม่ต้องมีตารางแมป และหมดข้อกังวลเรื่องปีฐานที่ค้างไว้ตั้งแต่ต้น

- `pnpm lint` ผ่าน เหลือ warning เดิมหนึ่งข้อใน `src/lib/thai-baht.test.ts` ซึ่งไม่ใช่ของรอบนี้

- ตรวจสัมประสิทธิ์ของทั้ง 34 สูตรด้วยเทสต์ว่าบวกได้ 1.000 พอดีทุกสูตร ซึ่งเป็นตัวจับความผิดพลาดของการถอดจากภาพสแกน
- **ยังไม่ได้เปิดดูในเบราว์เซอร์** รอบนี้ไม่มีหน้าจอให้เปิด และ MCP ที่รันอยู่ยังชี้ไปที่ Chrome ทั้งที่ config เปลี่ยนเป็น Edge แล้วแต่ยังไม่ได้ restart

## Security and data impact

ไม่มีการเปลี่ยนสิทธิ์ ความลับ ข้อมูลส่วนบุคคล การชำระเงิน หรือ migration ชุดข้อมูลที่เพิ่มเป็นเอกสารสาธารณะของทางราชการ แกนคำนวณเป็นฟังก์ชันบริสุทธิ์ ไม่แตะฐานข้อมูลและไม่ยิงเครือข่าย การเรียก API ของกระทรวงพาณิชย์ในรอบนี้เป็นการตรวจสอบด้วยมือ ยังไม่มีโค้ดใดในโปรเจกต์ที่เรียกออกไป
