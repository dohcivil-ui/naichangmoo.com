### กฎที่ห้ามละเมิด

| กฎ | เหตุผล |
|---|---|
| `canvas` ได้ `1fr` แผงข้างได้ค่าตายตัวเสมอ | พื้นที่แสดงแบบคือส่วนสำคัญ ถ้าโดนบีบจะประมาณราคาผิด |
| ทุกช่องในกริดใส่ `min-width:0` และ `min-height:0` | ค่าเริ่มต้น `min-width:auto` ทำให้เนื้อในดันกริดจนผังพัง |
| หน้าทั้งหน้าไม่เลื่อน แต่ละแผงเลื่อนในตัวเอง | เลื่อนดูตารางแล้วแบบต้องไม่หายจากจอ |
| ความกว้างแผงเก็บเป็น CSS custom property | เปลี่ยนจาก JavaScript บรรทัดเดียว ไม่ต้องแตะโครงสร้าง |
| ไม่มีปุ่มซูมแพน | เมาส์ทำแทนได้ ปุ่มกินพื้นที่เปล่า |
| ป้ายลอยมีที่เดียว ห้ามใส่ `title` ของเบราว์เซอร์ร่วม | ไม่งั้นขึ้นซ้อนกันสองชั้น เป็นบั๊กที่เจอในระบบเดิม |
| เครื่องมือใช้ `role="radiogroup"` การดูดจุดใช้ `aria-pressed` | ของที่ทำงานคนละแบบ ต้องดูไม่เหมือนกัน |
| ตัวชี้เปลี่ยนตามเครื่องมือ | บอกโหมดโดยไม่กินพิกเซล |

### สถานะสมาชิกมุมขวาบน

ป้ายสถานะ · อายุสมาชิกคงเหลือที่เดินจริงทุกวินาที · ปุ่มบัญชี
**นาฬิกาต้องคำนวณจากเวลาหมดอายุที่ตายตัวทุกครั้ง ห้ามนับถอยหลังทีละวินาที**
เพราะเบราว์เซอร์หน่วงตัวจับเวลาของแท็บที่ไม่ได้อยู่หน้าจอ เลขจะเพี้ยนสะสม
และนี่คือตัวเลขที่ผูกกับเงิน · เหลือน้อยกว่าสามวันเปลี่ยนเป็นสีเตือน
ของจริงต้องดึงจากทะเบียนสิทธิ์ตาม ADR 0015 ไม่ใช่ค่าคงที่แบบในต้นแบบ

### ที่ต้นแบบยังไม่มี และเป็นงานจริง

เครื่องมือทั้งเก้าตัวเลือกได้อย่างเดียว ยังวัดจริงไม่ได้ · ยังไม่รับไฟล์ PDF ·
ยังไม่มีการตั้งสเกลจริง · รายการในแผงขวาเป็นข้อมูลสมมติ

**ลำดับที่เสนอ** รับไฟล์ PDF มาแสดงก่อน แล้วทำ **ตั้งสเกล** เป็นเครื่องมือแรก
เพราะทุกการวัดใช้ไม่ได้เลยถ้าสเกลยังไม่ถูกตั้ง แล้วทำ **ระยะสองจุด** เป็นตัวพิสูจน์ว่าสเกลถูก
จากนั้นที่เหลือจะเร็วเพราะใช้โครงเดียวกัน

**ยังไม่มีใครเห็นต้นแบบทำงานผ่านเบราว์เซอร์ทดสอบของ AI** เพราะโปรไฟล์ถูกล็อกค้างทั้งเซสชัน
ตรวจได้แค่ไวยากรณ์ผ่าน เจ้าของงานเป็นคนเปิดดูเองทุกรอบ
