## หนึ่ง — เรื่องที่ต้องรู้ก่อนแตะอะไร

**มีอีกเซสชันทำงานบนสาขาเดียวกันพร้อมกัน** ระหว่างเซสชันนี้มี commit จากอีกเซสชันแทรกเข้ามาสามใบ
รวมถึง `9e63437` ที่แก้ไฟล์ชุดเดียวกับที่เซสชันนี้แก้ (`work-plan-document.tsx`, `globals.css`)

> **กฎที่ต้องยึด:** ก่อนพูดว่าอะไรยังไม่ถูก commit หรือก่อนแก้ไฟล์ในแอปแผนงาน
> ให้ `git log --oneline -5` และ `git status` ใหม่เสมอ ข้อเท็จจริงเรื่อง git ในบทสนทนาเก่าไปได้ภายในไม่กี่นาที

**อีกเซสชันแก้ทับงานของเซสชันนี้หนึ่งจุด และแก้ได้ถูกกว่า** เซสชันนี้เปลี่ยนขนาดตัวอักษรในเอกสาร
ให้ใช้หน่วย `em` เพื่อให้อิงขนาดกระดาษ แต่ `em` ซ้อนกันแล้วทบกัน ทำให้ `0.82em` ของ `0.95em` ของ 16pt
กลายเป็น 12.46pt โดยไม่มีใครตั้งใจ อีกเซสชันเปลี่ยนเป็นกำหนดเป็นพอยต์ตรง ๆ สามขนาด (20 / 18 / 16)
**อย่าเปลี่ยนกลับไปใช้ em ในเอกสารพิมพ์อีก**

## สอง — สิ่งที่ต้องทำก่อนอย่างอื่นเมื่อเปิดเซสชันใหม่

```bash
git log --oneline -5           # ดูว่าอีกเซสชันทำอะไรไปแล้วบ้าง
git status                     # ต้องสะอาด
node scripts/check-roadmap.mjs # แผนตรงกับสำเนาของแผน
node scripts/check-release.mjs # เลขรุ่นตรงกันทุกบันได
git describe --tags            # รุ่นล่าสุดที่ปิดแล้ว ต้องไม่มีเลขต่อท้าย
```

**ถ้า `git describe` มีเลขต่อท้าย** เช่น `v0.49.0-...-2-gabc1234` แปลว่ามี commit ที่ยังไม่ได้ปิดรุ่น
ให้ตรวจก่อนว่าเป็นงานของใคร ถ้าเป็นของอีกเซสชันที่ยังทำอยู่ **อย่าปิดรุ่นแทนเขา**
ถ้าเป็นงานที่ค้างจริงและไม่มีใครถือ ให้ปิดด้วย `pnpm release`

> ระหว่างเขียน handoff ฉบับนี้ roadmap อยู่ที่ 0.49.0 โดยยังไม่มีธงอยู่พักหนึ่ง
> แล้วอีกเซสชันปิดให้เองเป็น `v0.49.0-one-size-on-paper-size` ภายในไม่กี่นาที
> ซึ่งเป็นตัวอย่างตรง ๆ ว่าทำไมต้องตรวจใหม่ก่อนลงมือ ไม่ใช่เชื่อสิ่งที่เขียนไว้ในเอกสาร

4. ย้อนกลับด้วย `git checkout v<เลขรุ่น>-<ชื่องาน>` ซึ่งใช้ได้ก็ต่อเมื่อทุกรุ่นมีธง

## สี่ — คำสั่งยืนของเจ้าของงาน (ห้ามฝ่าฝืน)

1. **ใช้ Microsoft Edge เท่านั้น ห้าม Chrome** — เครื่องมือ MCP ชื่อ `chrome-devtools` แต่ตั้งเป็น Edge แล้ว
   ถ้าเชื่อมไม่ได้เพราะโปรไฟล์ถูกล็อก ให้ปิดเฉพาะโปรเซส Edge ที่มีคำว่า `chrome-devtools-mcp`
   ในบรรทัดคำสั่ง **ห้ามปิด Edge ส่วนตัวของเจ้าของงาน** (เกิดสองครั้งในเซสชันนี้)
2. **ห้าม emoji ทุกที่** ใช้ SVG จาก `src/components/icons/platform-icons.tsx`
3. **สีล็อกธีมเว็บ** ตัวแปรจาก `globals.css` ยกเว้นในกราฟที่อนุโลมเพิ่มสีได้
4. **ลอกฟีเจอร์และกลไกของคู่แข่งได้เต็มที่ ต้องต่อยอดให้ดีกว่า ไม่ใช่ทำให้เหมือน**
   แต่ไม่ยกไฟล์โค้ดของเขามาใช้ (เจ้าของงานปรับข้อนี้เมื่อ 2026-08-26)
5. **ตั้งชื่อเองใหม่** ไม่ใช้ชื่อเมนูหรือชื่อโครงการตัวอย่างของคู่แข่ง
6. **จบงานเป็นแท็บ · เรียบง่าย · ตัวเลขตรวจย้อนได้ · ห้าม AI slop**
7. **ทุกแอปต้องมี AI ที่ร่างจากไม่กี่ค่า ผู้ใช้ตรวจ แล้ว AI คำนวณใหม่ทั้งสาย**
8. **เงินเป็น BigInt satang เสมอ** ห้ามให้แบบจำลองคืนค่าเป็นบาท
9. **ทุกปุ่มทุกการกระทำต้องมีปฏิกิริยา** ทั้งตอนชี้และตอนกด ภายใต้ `prefers-reduced-motion`
10. **เจ้าของงานตัดโหมดมืดออกแล้ว** เหตุผลคือไปซ้ำกับคู่แข่งและไม่จำเป็นกับงานนี้
