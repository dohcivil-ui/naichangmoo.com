# v0.95.0 — ทุกบรรทัดอ่านออก

**วันที่** 2026-08-30 · **สาขา** `initial-project/nextjs-foundation` · **รายการ** IP-209, IP-210

---

## หนึ่ง — IP-209 ไม่ใช่บั๊ก และการวินิจฉัยเดิมผิด

บันทึก v0.91.0 เขียนไว้ว่าตัวแปลง CSS ย่อ `color-mix` ที่ผสมตัวแปรสองตัวให้เหลือแค่สีแรก
แล้วเปิด IP-209 ไว้ว่ายังเหลืออีกแปดจุดที่ต้องไล่แก้ **ตรวจแล้วไม่จริงทั้งข้อ**

**หลักฐานสามชั้น**

1. **CSS ที่ `next build` ปล่อยจริง** มีกฎคู่กันทุกจุด
   `.gl-tag{color:var(--orange)}` มาก่อน แล้ว `.gl-tag{color:color-mix(in srgb, var(--orange) 74%, var(--ink))}`
   ห่อใน `@supports` ตามหลัง ซึ่งชนะ cascade
2. **ค่าที่เรนเดอร์จริง** `.gl-tag` ได้ `rgb(182,101,43)` = orange 74% + ink 26% เป๊ะ ·
   `.gl-live__word` ได้ 78% ตรงสูตร · ขอบ `.gl-labour__open` ผสมแล้ว
3. **นับในไฟล์ production** `color-mix` ของแอปรอด **30 จาก 30 จุด**

สิ่งที่คนก่อนหน้าเห็นแล้วเข้าใจว่า "ถูกย่อทิ้ง" คือ **กฎ fallback** ที่ Lightning CSS ใส่ให้
เบราว์เซอร์เก่าตามแบบ progressive enhancement การอ่านเจอแต่กฎแรกจึงดูเหมือนถูกย่อทุกประการ

**ผมเกือบพลาดซ้ำรอยเดิม** รอบแรกผมก็อ่านข้อความในสไตล์ชีตแล้วสรุปว่าตายหมดเหมือนกัน
ต่อเมื่อวัดด้วย `getComputedStyle` บน element จริงถึงเห็นว่าตรงข้าม
**บทเรียน: อ่านข้อความในสไตล์ชีตไม่ใช่การวัด** สไตล์ชีตมี fallback มี `@supports` มีกฎซ้ำ
มีแต่ค่าที่คำนวณแล้วบน element เท่านั้นที่บอกว่าหน้าใช้อะไรจริง

**สิ่งที่ทำ** ปิด IP-209 เป็นไม่ใช่บั๊ก · แก้คอมเมนต์สามจุดในโค้ดที่อธิบายเหตุผลผิด ·
ถอนข้อห้ามออกจากบันทึกแผน · **คงค่าสีตายตัวที่เขียนไปแล้วไว้ตามคำสั่งเจ้าของงาน**
เพราะมันทำงานถูกอยู่ และการรื้อกลับมีความเสี่ยงโดยไม่ได้อะไรเพิ่ม

## สอง — IP-210 มีมากกว่าที่จดไว้ และมีจุดที่มองไม่เห็นทั้งบรรทัด

จดไว้สี่จุด ไล่วัดจริงแล้วเจอมากกว่านั้น รวมถึงจุดที่หนักที่สุดที่ไม่มีใครจดไว้เลย

**หัวข้อ "สิทธิ์ของคุณ" บนหน้าราคา หายไปทั้งบรรทัด** เป็นสี `--ink` บนพื้น `--ink`
อัตราส่วน **1.00 ต่อ 1** คือสีเดียวกันเป๊ะ บนจอเห็นเป็นช่องว่างเปล่าเหนืออีเมล
สาเหตุคือแผงตั้ง `color: white` ไว้ที่ตัวเอง แต่กฎรวมของหัวข้อตั้ง `color: var(--ink)`
ลงบนตัว `h2` โดยตรง ซึ่งชนะค่าที่สืบทอดลงมาเสมอ

| จุด | เดิม | หลังแก้ |
|---|---|---|
| หัวข้อ "สิทธิ์ของคุณ" หน้าราคา | **1.00** | **13.79** |
| ป้ายเลขส้มหน้าแรก | 2.80 | 5.70 |
| วันที่ประกาศของการ์ดแอป | 2.37 | 4.73 |
| คำใบ้ของตัวเลขหลังบ้าน | 2.37 | 4.73 |
| ป้าย "ยังไม่เปิด" แถบข้างหลังบ้าน | 2.33 | ผ่าน |
| แถบบริบทของเปลือกแอป | 4.43 | 6.90 |
| ลิงก์ teal ในแถบบริบท | 4.03 | 4.59 |
| ตัวเลขหมวดบนหน้าแรก | 4.06 | 4.63 |
| ปุ่มสลับรอบบิลหน้าราคา | 4.45 | 6.94 |

**ต้นตอจริงคือสีเทาจาง `#93a5ab` ที่ถูกเขียนซ้ำสิบจุด** และตกเกณฑ์ทุกจุดที่มันไปอยู่
แทนทั้งสิบด้วย `var(--muted)` ซึ่งวัดได้ 4.73 บนพื้นการ์ด

**โทเคนใหม่สองตัว** `--teal-text: #0c7878` และ `--orange-text: #a34f14`
ไม่ได้คิดสีใหม่ทั้งคู่ — teal เข้มลงราวห้าเปอร์เซ็นต์จนตาแทบแยกไม่ออก ส่วนส้มหยิบมาจาก
สีที่ไฟล์นี้ใช้อยู่แล้วกับปุ่มนำทางที่กำลังเปิด · ใช้เฉพาะกับตัวหนังสือ ปุ่มกับพื้นยังใช้ของเดิม

## สาม — เรื่องที่ควรจำจากรอบนี้

**ด่านตรวจจับคอมเมนต์ของตัวเอง** ตอนเพิ่มด่านห้าม `await import()` ในไฟล์ action
ด่านแดงเพราะคอมเมนต์ที่อธิบายว่าทำไมถึงห้ามมีข้อความนั้นอยู่ · แก้เป็นตัดคอมเมนต์ก่อนตรวจ
**ไม่ใช่ลบคำอธิบายทิ้งเพื่อให้เขียว** กฎที่ห้ามเขียนโค้ดแบบหนึ่งไม่ควรยิงใส่คำอธิบายว่าทำไมถึงห้าม

**ตัววัดคอนทราสต์อัตโนมัติโกหกได้** ข้อความสว่างบนพื้นเข้มโปร่งแสงหรือไล่สี ตัววัดจะคำนวณ
พื้นผิดแล้วรายงานว่าตก · ทุกจุดในตารางข้างบนถูกยืนยันด้วยการอ่านสีพื้นจริงทีละชั้น
ไม่ได้เชื่อผลกวาดดิบ ๆ

## สี่ — ตรวจของจริง

- วัดด้วย `getComputedStyle` บน element จริงทุกจุด ก่อนแก้และหลังแก้
- เปิดดูด้วยตา หัวข้อ "สิทธิ์ของคุณ" กลับมาอ่านได้ในภาพหน้าจอ
- `next build` จริงเพื่อพิสูจน์ IP-209 แล้วนับ `color-mix` ในไฟล์ที่ปล่อยออกมา
- ยืนยันลำดับกฎในไฟล์ production ว่า fallback มาก่อน ของจริงตามหลังใน `@supports`
- lint typecheck test ผ่านครบ
