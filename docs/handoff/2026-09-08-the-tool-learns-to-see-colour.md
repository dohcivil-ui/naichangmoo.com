## ห้า — สิ่งที่ลองแล้วไม่ได้ผล อย่าเดินซ้ำ

**นี่คือหัวข้อที่สำคัญที่สุดของไม้ต่อฉบับนี้** ทุกข้อเสียเวลาไปแล้วจริง

1. **เทียบสีด้วยการลบ** `Math.abs(NaN) > TOLERANCE` เป็นเท็จเสมอ แถวที่เฝ้าสีจะขึ้นว่า
   "ตรง" ตลอดกาล · **แย่กว่าไม่เฝ้าเลย เพราะมันขึ้นในรายงานว่าถูกเฝ้าอยู่** ·
   แก้แล้วด้วย `keyGap` ที่ตอบ `Infinity` เมื่อข้อความต่าง
2. **แยกกฎ CSS ด้วย regex `\{[^}]*\}`** `@keyframes` กับ `@media` ซ้อนชั้น regex จะตัดกลางก้อน ·
   และ regex ที่จับเฉพาะคลาสเดี่ยวมองไม่เห็น `:root` `body` `h1,h2,h3,h4,.hd` `a:hover`
   และกฎลูกหลาน · **รุ่นแรกนับได้ 22 จาก 36 แล้วรายงานว่า "ตรงกัน 22 จาก 22"**
