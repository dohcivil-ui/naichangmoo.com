## หนึ่ง — ทำไมมีรุ่นนี้

รุ่น v0.93.0 ปิดไปโดย**ผมจดไว้เองในบันทึกว่ายังไม่จบสองข้อ** คือฝั่ง ESTIMETR ยังไม่มีจอ
ที่แสดงชุดราคาที่รับมา และเส้นทางกดส่งเข้าโครงการยังไม่เคยถูกกดจริงในเบราว์เซอร์
แล้วผมก็ commit ไป

**เจ้าของงานทักว่า** "ทำงานต่อให้สำเร็จก่อนค่อยเข้ากฎ commit อันนี้หน้างานถึงไหนก็ยังไม่รู้เลย"
ถูกต้อง งานที่ปลายทางยังไม่มีจอ และเส้นทางยังไม่เคยถูกกด ไม่ใช่งานที่เสร็จ
รุ่นนี้ปิดสองข้อนั้นให้จบก่อนแตะ commit อีกครั้ง

**ยอดรวมคิดที่ฐานข้อมูลจากบรรทัดจริง** ปัดที่สตางค์ตอนคูณให้ตรงกับ `lineCost` ที่ PRICEMETR ใช้

แก้ตะกร้าที่ PRICEMETR แล้วส่งเข้ามาใหม่เป็นชุดถัดไป ไม่ใช่แก้ของที่ส่งมาแล้ว

## สาม — บั๊กที่เทสต์กับ typecheck มองไม่เห็นเลย

`listBasketTargetProjects` เขียนด้วย `await import()` เพื่อให้ไฟล์ action บาง
ผลคือ **คำขอค้างอยู่ฝั่งเซิร์ฟเวอร์ ไม่ตอบและไม่โยน** หน้าจอขึ้น "กำลังอ่านรายชื่อโครงการ"
ค้างตลอดกาล ไม่มี error ใน console ไม่มีบรรทัดของ action นั้นใน log ของเซิร์ฟเวอร์เลย
เพราะมันไม่เคยจบ และสุดท้ายลากให้ dev server ค้างทั้งตัวจนต้องรีสตาร์ต

lint เขียว typecheck เขียว เทสต์ 813 ตัวเขียวหมด **จับได้ตอนกดของจริงอย่างเดียว**
เป็นบั๊กตระกูล "ประกาศแล้วแต่เป็นหมัน" อีกตัว แต่คราวนี้ไม่ใช่ CSS
แก้เป็น import ปกติเหมือนไฟล์ action อื่น และเพิ่มด่านห้าม `await import()` ในไฟล์ action
พร้อมพิสูจน์แล้วว่าใส่กลับเข้าไปเทสต์แดงทันที

**ด่านนั้นจับคอมเมนต์ของตัวเองในรอบแรก** เพราะคำอธิบายว่าทำไมถึงห้ามมีข้อความนั้นอยู่
แก้เป็นตัดคอมเมนต์ก่อนตรวจ ไม่ใช่ลบคำอธิบายทิ้งเพื่อให้เทสต์เขียว

## สี่ — เดินเส้นทางจริงทั้งเส้น

ติดที่ `apps.enabled` ของ estimeter เป็น false ทั้งทะเบียน โครงการจึงสร้างไม่ได้
**ขออนุญาตเจ้าของงานก่อน** แล้วเปิดชั่วคราวผ่านหน้าหลังบ้านจริงพร้อมเหตุผลที่ลงบันทึกตรวจสอบ

1. สร้างโครงการผ่านฟอร์มจริง
2. เปิดหน้าโครงการ **แผงชุดราคาขึ้นสถานะว่าง** พร้อมทางไปหน้าราคา
3. ไปหยิบราคาสี่บรรทัด · รีโหลด · **รายการกลับมาครบ**
4. กดส่งเข้าโครงการ · ได้ข้อความว่าส่ง 4 บรรทัดแล้ว **และรายการยังอยู่ครบ**
5. เปิดหน้าโครงการ **ชุดราคาโผล่ครบสี่บรรทัด** พร้อมแหล่ง เดือน และรหัสสินค้ารายบรรทัด
6. **ยอดรวม 11,840 บาท ตรงกับที่ PRICEMETR แสดงก่อนส่งทุกบาท**
7. **พิสูจน์ว่านิ่งจริง** กลับไปแก้ปริมาณในตะกร้าเป็น 99 ตะกร้าขึ้นเป็น 293,100 บาท
   แต่ชุดราคาของโครงการยังเป็น 11,840 ปริมาณยังเป็น 1 ทุกบรรทัด

## ห้า — จุดที่เจอตอนเปิดดูด้วยตา

- ชื่อโครงการเชื่อมกับประโยคถัดไปจนอ่านเป็น `PRICEMETRการนำไป` — JSX ไม่ใส่เว้นวรรคให้
- ตัวเลขติดหน่วยเป็น `11,840บาท`

ทั้งสองจุดไม่มีเทสต์ไหนจับได้ เห็นจากภาพหน้าจอเท่านั้น

## หก — คืนสภาพแวดล้อม

- **ปิดสวิตช์ ESTIMETR คืนแล้ว** ผ่านหน้าหลังบ้านเดิม พร้อมเหตุผล
- **ลบโครงการทดสอบ ชุดราคา บรรทัด และตะกร้าออกหมดแล้ว**
- ตรวจซ้ำ ทะเบียนแอปปิดครบทั้งเจ็ดเหมือนเดิม เหลือเฉพาะโครงการตัวอย่างเดิมสองรายการ
- ล้าง emulation คืนขนาดปกติแล้ว

## เจ็ด — เทสต์
