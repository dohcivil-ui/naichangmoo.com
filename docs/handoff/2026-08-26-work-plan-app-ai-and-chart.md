**AI จริง (ต่อ OpenAI/DeepSeek สำเร็จ ทดสอบด้วยโจทย์จริงแล้ว):**
- `src/server/ai/provider.ts` — รอยต่อ 10 รุ่นจาก 4 ค่าย (Anthropic/OpenAI/DeepSeek/Moonshot)
  ผ่าน adapter สองตัว เลือกด้วย env `WORK_PLAN_MODEL` **ค่าเริ่มต้น gpt-5.4-mini**
  (วัดแล้วเร็วสุด 8.9 วิ ถูกสุด 0.22 บาท/ครั้ง ดูเหตุผลใน comment ของไฟล์)
- `src/server/ai/work-plan-prompt.ts` — prompt+schema ของทั้ง "ร่าง/แก้" และ "ตรวจแผน"
- `src/server/actions/work-plan-assistant.ts` — สอง action: `askWorkPlanAssistant` (ร่าง/แก้)
  และ `reviewWorkPlan` (ตรวจแผน) **ตัวเลขเสี่ยงคำนวณฝั่งเราจาก BigInt AI แค่เรียบเรียง**
- หลักการที่ห้ามพัง: **แบบจำลองคืนแค่ ppm+วัน ห้ามคืนเป็นบาท** โค้ดเราคิดเงินเองเสมอ
- ปิดตัวเองเมื่อ `NODE_ENV=production` เพราะหน้าต้นแบบเปิดได้โดยไม่ต้องล็อกอิน

**หน้าจอ (`src/components/prototype/work-plan-workspace.tsx`, สี่แท็บ):**
1. โครงการ+เงื่อนไขสัญญา (ป้อน 5 ค่า) 2. รายการงาน 3. งวดงาน-งวดเงิน 4. เส้นสะสม

  ไฮไลต์คอลัมน์ตารางตาม hover, ปุ่มครึ่งเดือน/รายเดือนทำงานจริง
- **AI ตรวจแผน** (ปุ่มในแท็บงวดงาน) ทัก 5 จุดเป็นภาษาวิศวกร คู่แข่งไม่มี AI

`scripts/compare-work-plan-models.ts` (เทียบแบบจำลองด้วยโจทย์จริง)

## สิ่งที่ยังจำลอง ไม่ใช่ข้อมูลจริง (งานหลักรอบหน้า)

เส้น "มูลค่างานที่ตรวจรับสะสม" และ "เงินรับจริงสะสม" บนกราฟ **สร้างจากแผน ไม่ใช่บันทึกจริง**
(มีป้ายเตือนบนกราฟบอกตรง ๆ แล้ว) งานหลักถัดไปคือ **บันทึกจริงต่องวด — สามยอดสามวัน + Data Date**
(ยอดขอเบิก/ยอดรับรอง/เงินเข้าจริง + วันที่ของแต่ละยอด + เส้นตัดข้อมูล) ให้เส้นเงินเป็นข้อมูลจริง
ตัดที่ Data Date ไม่ลากต่อเป็นแผน — เก็บใน localStorage ก่อน ยังไม่ต่อ DB

## คำสั่งยืนของเจ้าของงาน (ห้ามฝ่าฝืน)

1. **ใช้ Microsoft Edge เท่านั้น ห้าม Chrome** — MCP chrome-devtools ตั้งเป็น Edge แล้ว
   profile ย้ายไป `~/.cache/chrome-devtools-mcp/edge-mcp-profile` (มี junction จาก path เดิม)
2. **ห้าม emoji ทุกที่** ใช้ SVG icon จาก `src/components/icons/platform-icons.tsx`
3. **สีล็อกธีมเว็บ** ตัวแปรจาก `globals.css` — **ยกเว้นในกราฟ อนุโลมเพิ่มสีได้** (ธีมหลักยังต้องเป็นของเรา)
4. **ห้ามก๊อป source code ของคู่แข่ง** เข้าใจกลไกแล้วเขียนเอง — เส้นนี้ยืนมาตลอดทั้งงาน
5. **ตั้งชื่อเองใหม่** ไม่ใช้ชื่อเมนู/โครงการตัวอย่างของเขา
6. **จบงานเป็นแท็บ · เรียบง่าย · ตัวเลขตรวจย้อนได้ · ห้าม AI slop**
7. **ทุกแอปต้องมี AI ที่ร่างจากไม่กี่ค่า → user ตรวจ → AI คำนวณใหม่ทั้งสาย**
