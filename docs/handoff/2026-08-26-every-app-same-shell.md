### สิ่งที่พบ: แอปของเรามีเปลือกสามแบบที่ไม่เหมือนกันเลย

| แอป | เส้นทาง | เปลือกที่ใช้ | ทางกลับหน้าหลัก |
|---|---|---|---|
| ESTIMETR และแอปที่ประกาศแล้ว | `/apps/*` | `AppShell` ของกลาง | มี |
| PRICEMETR | `/prototype/price-check` | แถบที่เขียนเอง `gl-platbar` | มี แต่คนละคำคนละหน้าตา |
| แอปผู้ช่วยสร้างแผนงาน | `/prototype/work-plan` | **ไม่มีเลย** | **ไม่มี** |

`AppShell` อยู่ที่ `src/components/platform/app-shell.tsx` ให้สี่ชั้นคือแถบนำทาง แถบบริบท
ชื่อแอป และท้ายเว็บ ถูกใช้แค่สองที่คือ `src/app/apps/estimeter/layout.tsx` กับ
`src/app/apps/[slug]/page.tsx`

แถบที่ PRICEMETR เขียนเองอยู่ใน `src/components/prototype/price-workspace.tsx` ราวบรรทัด 520
**ไฟล์นี้เป็นของอีกเซสชัน อย่าแก้โดยไม่คุยกับเขาก่อน**

### ข้อจำกัดที่ทำให้แก้ตรง ๆ ไม่ได้

ต้นแบบอยู่นอก `/apps` **โดยตั้งใจ** คอมเมนต์หัวไฟล์ `src/app/prototype/work-plan/page.tsx`
เขียนเหตุผลไว้ชัด: ADR 0014 กำหนดว่าแอปเป็นแอปที่ประกาศแล้วเพราะผู้ดูแลกดประกาศ
ไม่ใช่เพราะมีคนเขียนหน้าเว็บหน้าหนึ่ง

**การย้ายต้นแบบเข้า `/apps` เพื่อให้ได้เปลือก จึงเป็นทางที่ผิด** เพราะกลายเป็นการอ้างว่า
ประกาศแล้วทั้งที่ยังไม่ได้ประกาศ ซึ่ง ADR 0015 ห้ามไว้อีกชั้น

### สิ่งที่ต้องซักให้ได้คำตอบก่อนเขียนโค้ด

| คำถาม | ทำไมต้องตอบก่อน |

## ห้า — ความผิดพลาดของเซสชันนี้ที่ต้องบอก

**หนึ่ง — แผนแรกของผมผิด และจะทำโรดแมปหายซ้ำรอย v0.50.0** เสนอไว้ว่า merge แล้วเก็บ
roadmap ของ main ทั้งไฟล์ แต่สาขามี 8 รายการที่ main ไม่มี จับได้ตอนเปิด merge จริง
จึงยกเลิกแล้วกลับมาซักใหม่ นี่คือเหตุผลตรง ๆ ที่ `/grill-with-docs` กลายเป็นกฎ

**สอง — วัดด้วยเครื่องมือผิดสามครั้ง** ใช้ `getBoundingClientRect` วัดของที่อยู่ใต้
`transform: scale` แล้วรายงานเลขผิดให้เจ้าของงาน ต้องใช้ `offsetTop` และ `offsetHeight`
ซึ่งเป็นค่าตามการจัดวางจริง **ถ้าวัดอะไรในตัวอย่างเอกสาร ให้ใช้ offset เสมอ**

**สาม — เขียนเทสต์ที่ความคาดหวังผิดสองครั้ง** ทั้งสองครั้งโค้ดถูก เทสต์ผิด
ตรวจสมมติฐานของเทสต์ก่อนสรุปว่าโค้ดพัง

**สี่ — `git pull --rebase` รันไม่ผ่าน** เพราะอีกเซสชันมีไฟล์ค้าง ตรวจแทนด้วย
`git rev-list --count` ทั้งสองทางแล้วพบว่าตรงกันอยู่แล้ว ถ้ารอบหน้าอีกเซสชันดันขึ้นไปก่อน
ต้องรอให้เขา commit ก่อนถึงจะ pull ได้
