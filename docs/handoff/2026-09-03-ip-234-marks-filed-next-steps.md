## หก — วิธีที่ลองแล้วไม่ได้ผล (อย่าเดินซ้ำ)

- **dispatch PointerEvent เองบน `.mk__stage`** state ของ React เพี้ยนหนึ่งจังหวะ (จุดแรกหาย จุดสองกลายเป็นจุดแรก) → ใช้ปุ่มเล็ง `#aim-box` (`position:fixed; pointer-events:none`) วางที่พิกัดแล้วให้ MCP `click` ที่ uid ของมัน ได้คลิกจริงผ่าน CDP
- **คำนวณพิกัดทันทีหลัง dispatch wheel** ได้ rect เก่า ซูมยังไม่ลง → ต้องเรียก evaluate แยกรอบเพื่ออ่าน rect หลังซูม
- **การหาตำแหน่งเส้นแนวเสา** อย่ากะจากภาพ อ่านพิกเซลจาก canvas (`getImageData`) นับคอลัมน์มืดในแถบใต้วงกลมหมายเลขเสา ได้ตำแหน่งระดับครึ่งพิกเซล (`step6` ใช้วิธีนี้ได้ 113.2 pt = 5.00 ม.)
- **emulate มือถือแบบ `mobile,touch` บนหน้าวาดขณะถือเครื่องมือห้อง** ทำให้เกิด tap ปลอมแล้วไล่ห้องทั้งอาคาร (265 ตร.ม.) ค้างรอยืนยัน → เปลี่ยนเครื่องมือเป็น "เลือก" ก่อน emulate หรือกดยกเลิกหลังจากนั้น
- **`pdftotext`/`pypdf` กับ PDF หลักเกณฑ์กรมบัญชีกลาง** อักขระไทยเพี้ยนทั้งไฟล์ เครื่องนี้ไม่มี tesseract → ต้องเจ้าของงานเปิดอ่านเอง
- **shell เขียนไฟล์ไทย** ยังห้ามเหมือนเดิม ใช้ Write/Edit เท่านั้น (สคริปต์ตรวจฐานเขียน ASCII ล้วนผ่าน `node --input-type=module -e` ได้)
