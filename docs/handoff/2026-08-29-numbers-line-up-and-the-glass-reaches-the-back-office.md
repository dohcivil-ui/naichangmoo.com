## สอง — คำวินิจฉัยของเจ้าของงานในเซสชันนี้

1. **ฟอนต์ตัวเลขใช้เฉพาะคอลัมน์ตัวเลข ห้ามเปลี่ยนฟอนต์ทั้งระบบเพราะเรื่อง `tnum` อย่างเดียว** — และคำไทยที่หลุดไปอยู่ในช่องตัวเลขต้องดึงกลับเป็น Prompt เสมอ ฟอนต์ตัวเลขมีไว้ให้ตัวเลข
2. **ด่านตรวจห้ามเฝ้าของว่าง** — ตัวเลือกที่ไม่มีหน้าไหนเรนเดอร์ต้องตัดออกจากทั้งกฎและด่าน ไม่ใช่เก็บไว้เผื่ออนาคต เพราะมันทำให้นับผิดว่าครอบคลุมกว่าที่เป็น
3. **แผงผู้ช่วยคงกว้าง 380px** — ตัวเลขที่ขอบกราฟถูกตัดไม่ได้มาจากแผงกว้างไป (SVG มี viewBox ตายตัว ย่อแผงแล้วสัดส่วนที่ถูกตัดเท่าเดิม) จึงไม่ต้องย่อ
4. **แผงผู้ช่วยต้องจบเสมอกับการ์ดสุดท้ายฝั่งซ้าย** ไม่ใช่ยาวลงไปทับท้ายเว็บ และของข้างในต้องขยับตามเมื่อแผงเตี้ยลง
5. **ธีมหลังบ้าน: พื้นหลัง + การ์ดกระจก + reaction ครบ** แต่แถบข้าง แถบบน และตารางคงพื้นทึบ · **หลังบ้านไม่ต้องมีท้ายเว็บ** เพราะเป็นเครื่องมือทำงาน
6. **สีต้องเก็บค่าจริงมาใช้ ไม่ใช่ไล่เอาเอง** — คำสั่งตรงตัวหลังผมทำจางไปห้าเท่า: "เข้าไปหน้า price เก็บค่าสีจริงมาเลย แล้วค่อยเอามาใช้"

## สี่ — สามตระกูลของบั๊ก "ประกาศแล้วแต่เป็นหมัน" ที่เจอในเซสชันเดียว

1. **`tabular-nums` บนฟอนต์ที่ไม่มี `tnum`** — CSS อ่านว่าสั่งครบ 44 จุด ไม่มี error ไม่มีอะไรเตือน ตัวเลขก็แค่ไม่ตรงหลัก
2. **`animation-fill-mode: both` ฆ่า `:hover { transform }`** — เฟรมสุดท้ายของ `gl-rise` เขียนว่า `transform: none` เมื่อใช้ `both` มันค้างตลอดชีวิต element และ animation ชนะ declaration ธรรมดาในลำดับ cascade **คำสั่งยกการ์ดตอนชี้ของ PRICEMETR จึงไม่เคยทำงานเลยสักครั้งตั้งแต่เขียนมา** เห็นแต่แสงกวาดกับเงาที่เปลี่ยน · แก้เป็น `backwards` ทั้งห้าจุด (`.gl-cat`, `.gl-slab`, `.gl-card`, `.gl-item`, การ์ดหลังบ้าน) — **กฎบ้านใหม่: ใช้ `gl-rise` คู่กับ `backwards` เท่านั้น ห้ามใช้ `both`**
3. **ฉากหลัง `position: fixed` ทาทับท้ายเว็บที่เป็น flow เปล่า ๆ** — `.gl-scope` เป็น `position: relative` จึงเป็น stacking context ที่วาดทีหลังกว่า block ปกติ ไม่ว่า DOM จะมาก่อนหรือหลัง · หน้า price-check จึง "ไม่มี footer" ทั้งที่มันอยู่ในหน้าและอยู่ในจอ · เคสเดียวกันนี้เคยแก้ให้ `.app-shell__context` ไปแล้วครั้งหนึ่ง แต่ท้ายเว็บไม่ได้รับการแก้ตามเพราะไม่มีใครเลื่อนลงไปสุดหน้าที่มีฉากหลังตรึงจอ

## ห้า — เรื่องที่เจ็บแล้วต้องจำ (เครื่องมือและวิธีทำงาน)

1. **SVG ที่มี viewBox ตายตัวยืดทั้งใบ** — ช่องกว้างขึ้น ส่วนที่ล้นออกไปก็ขยายตาม สัดส่วนที่ถูกตัดเท่าเดิม · แก้ที่ที่ว่างริมกราฟเท่านั้น ย่อแผงข้าง ๆ ไม่ช่วย
2. **อย่าเดาสี ให้อ่านพิกเซล** — วิธีที่ใช้ได้จริงในเซสชันนี้: ซ่อนทุกอย่างที่ไม่ใช่ฉากหลังด้วย `visibility: hidden` → `take_screenshot` ลงไฟล์ → อ่านค่าด้วย `@napi-rs/canvas` ที่โปรเจกต์มีอยู่แล้ว → เทียบ "ความห่างจากขาว" · สคริปต์ต้องรันจาก root ของโปรเจกต์ ไม่งั้นหา `@napi-rs/canvas` ไม่เจอ
3. **ภาพหน้าจอที่กว้างเกิน ~2000px ส่งกลับมาให้ดูไม่ได้** — ย่อหน้าต่างก่อน หรือถ่ายลงไฟล์แล้ววัดด้วยสคริปต์แทนการดูด้วยตา (ซึ่งแม่นกว่าอยู่แล้ว)
4. **`scroll-behavior: smooth` ทำให้ `window.scrollTo` แล้ววัดทันทีได้ค่าผิด** — ตั้ง `document.documentElement.style.scrollBehavior = "auto"` ก่อนวัดเสมอ (บทเรียนเดิมจากเซสชันก่อน ยังใช้ได้)
5. **`src/architecture-fence.test.ts` timeout 5 วินาที แพ้เครื่องที่ทำงานหนัก** — รันพร้อม dev server จะแดงเป็นบางครั้ง รันเดี่ยวผ่านตลอด (2.16 วิ) ไม่ใช่บั๊กของโค้ด แต่ควรขยาย timeout สักวัน
6. **skill เอกสาร Word ของ Anthropic ก๊อปเข้า repo ไม่ได้** — `LICENSE.txt` ห้ามเก็บสำเนาไว้นอกบริการตรง ๆ ต้องติดตั้งผ่านระบบ plugin เท่านั้น (ดูข้อหก)
