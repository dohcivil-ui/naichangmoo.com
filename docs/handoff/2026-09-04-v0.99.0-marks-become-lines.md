## Description

รุ่นก่อนทำให้วัดบนแบบได้แม่น แต่สิ่งที่วัดได้ยังอยู่ในหน่วยความจำของแท็บเดียว ปิดหน้าเว็บแล้วหายหมด และตัวเลขที่ได้ยังไม่มีที่ให้บอกว่ามันมาจากไหน รุ่นนี้ปิดสองช่องนั้นพร้อมกัน แบบหนึ่งใบรู้จักตัวเองด้วย checksum ของเนื้อไฟล์ ไม่ใช่ชื่อไฟล์ซึ่งเปลี่ยนได้ สเกล แนวเสา ระยะที่แบบเขียน จุดที่ค้าง ระดับซูมและตำแหน่ง จึงกลับมาที่จุดเดิมเมื่อเปิดไฟล์เดิมอีกครั้ง พร้อมชื่อคนที่ยืนยันสเกล รอยวัดทุกรอยลงตาราง `drawing_marks` ของหน้านั้น และส่งเข้าถอดปริมาณได้จากหน้าวาดโดยตรง โดยเซิร์ฟเวอร์อ่านจุดจากฐานเองไม่รับพิกัดจากเบราว์เซอร์ คำนวณปริมาณ ก๊อปสเกลของหน้า ณ วินาทีนั้นลงหลักฐาน และประทับว่ารอยถูกส่งแล้ว ทั้งหมดในธุรกรรมเดียว รองด้วย ADR 0024 ที่ตัดสินว่าปริมาณเก็บว่า**ได้มาอย่างไร** ไม่ใช่เก็บว่าแม่นหรือไม่แม่น พร้อม CHECK สองทิศที่บังคับว่าค่าจากแบบจำลองต้องมีทั้งรุ่นที่ตอบและคนที่กดรับ

## Security and data impact

- **migration สองใบ** 0015 (ที่มาของปริมาณ ตารางสเกล ตารางจุดที่ค้าง) และ 0016 (`drawing_marks`) — **เพิ่มตารางและคอลัมน์ล้วน ไม่ลบ ไม่แปลงข้อมูลเดิม** รันกับฐาน dev แล้ว ยังไม่มีข้อมูลลูกค้าจริงในตารางเหล่านี้
- ด่านสิทธิ์แก้ไขย้ายมาเป็น `edit-access.ts` และตรวจฝั่งเซิร์ฟเวอร์ทุกเส้นทาง ไม่ได้ซ่อนแค่ปุ่มบน UI
- `saveDrawingMarks` และ `fileDrawingMark` **ไม่รับพิกัดจากเบราว์เซอร์ตอนส่งเข้าถอดปริมาณ** เซิร์ฟเวอร์อ่านจุดจากฐานเอง จึงปลอมปริมาณด้วยการแก้ payload ไม่ได้
- ไม่แตะ secret ไม่แตะ Stripe ไม่แตะ R2 ไม่แตะ policy ของผู้ช่วย AI
- `closed-tables.test.ts` อัปเดตให้ครอบตารางใหม่ทั้งสาม (ตารางใหม่ต้องปิดโดยปริยาย)

### โจทย์ใหม่ที่เจ้าของงานส่งมา 2026-09-04 — รูปทรงที่การคลิกเลือกพื้นที่ห้องต้องได้

เจ้าของงานส่งภาพแบบที่ระบายไว้ว่ารูปทรงที่ถูกต้องคืออะไร พร้อมประโยค
**"รูปแบบการคิดพื้นที่ห้อง ถ้าใช้คลิ้กเลือกพื้นที่ห้อง ต้องให้ได้รูปแบบนี้ บางพื้นที่ห้องไม่มีเส้นตัดแบ่ง"**

สิ่งที่อ่านได้จากภาพ (ห้องเก็บตัวกรอง แบบเดียวกับที่ใช้ทดสอบ):

- ขอบเขตสีแดงเดินตาม **ผิวในของผนัง** ทุกด้าน ไม่ใช่กึ่งกลางผนังและไม่ใช่ผิวนอก
- มุมล่างซ้ายมี **รอยเว้าเป็นขั้น** ตรงช่องเปิด ขอบเขตต้องเดินตามขั้นนั้น ไม่ใช่ลากตรงข้ามไป
- ในห้องมีป้ายกำกับสองชนิดที่เจ้าของงานวงไว้ **`F1+0.60` = พื้น1** และ **`C1` = ฝ้าเพดาน1** ซึ่งบอกว่าห้องเดียวกันแตกเป็นวัสดุคนละชนิดตามป้ายที่แบบเขียนไว้แล้ว — ต่อกับสเปกแตกห้องเป็นวัสดุโดยตรง
- ประโยคท้าย **"บางพื้นที่ห้องไม่มีเส้นตัดแบ่ง"** คือเงื่อนที่ต้องถามให้ชัดก่อนลงมือ

**คำถามที่ต้องให้เจ้าของงานเคาะก่อนแตะอัลกอริทึม** (ยังไม่ได้ถาม เพราะรุ่นกำลังถูกตัด):

1. "ไม่มีเส้นตัดแบ่ง" หมายถึงห้องที่**ขอบเปิดอยู่** เช่นช่องประตูที่ไม่มีเส้นปิด ทำให้การไล่ขอบทะลุออกไปนอกห้องใช่หรือไม่ ถ้าใช่ ทางแก้ที่ต้องการคือให้คนลากเส้นปิดช่องเองก่อนไล่ หรือให้ระบบปิดช่องแคบให้อัตโนมัติแล้วให้คนดูก่อนรับ
2. รอยเว้าที่มุมล่างซ้ายในภาพนี้ ต้อง**นับเข้า**พื้นที่ห้องหรือ**ตัดออก**
3. ป้าย `F1` และ `C1` ให้คนกดเลือกจากรายการเอง หรือให้ผู้ช่วย AI อ่านจากแบบมาเสนอแล้วคนกดรับ (ตามคำตัดสินเดิม "ผู้ช่วยเสนอ คนกดรับ")

ข้อจำกัดที่ยังจริงอยู่จากรุ่นนี้ (อย่าเดินซ้ำ): เพดานสีของการไล่ขอบทะลุ 25% เป็นแค่ตาข่ายชั้นล่าง ด่านจริงคือคนดูรูปก่อนเข้าตาราง (memory `room-fill-needs-human-confirm`) · การดูดจุด "กึ่งกลาง" ยังทำให้เส้นที่ตั้งใจลาก 3.00 กลายเป็น 2.93 (memory `snap-must-match-the-owners-own-app`)
