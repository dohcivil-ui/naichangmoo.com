## สี่ — เรื่องที่เจ็บแล้วต้องจำของเซสชันนี้

1. **chrome-devtools MCP ค้างถาวร ("Target closed")** — ทางออกที่ใช้ได้จริง: คุม Edge ตรงผ่าน
   DevTools Protocol ด้วย Node (มี WebSocket ในตัว): เปิด `msedge.exe --user-data-dir=C:/Users/moosu/.cache/chrome-devtools-mcp/edge-mcp-profile --remote-debugging-port=9223` แล้วต่อ ws ที่ `/json/list`
   สคริปต์ตัวอย่างอยู่ใน scratchpad ของ session เก่า (หายแล้ว) แต่โครงคือ send({method,params}) ตรงๆ
2. **หน้าต่างถูกบัง = นาฬิกาอนิเมชันหยุด** — เปิด Edge ด้วย `--disable-backgrounding-occluded-windows --disable-renderer-backgrounding` ไม่งั้น transition ค้างที่ 0ms ทั้งที่ state "running"
3. **ถอนโหมดจำลองจอทุกครั้งหลังทดสอบ** (`Emulation.clearDeviceMetricsOverride`) — เจ้าของงานเปิดหน้าต่างทดสอบดูเองแล้วเจอ "เว็บพัง" ที่ไม่มีจริงมาแล้วสองรอบ
4. **ห้ามแก้ไฟล์โค้ดผ่าน PowerShell** — profile ของเครื่องนี้ shadow คำสั่ง Get-Content/Set-Content
   (ไม่มี -Raw/-Encoding), path ที่มี `[slug]` โดนตีความเป็น wildcard เงียบๆ และการเขียนทิ้ง BOM — ใช้เครื่องมือ Edit/Write เท่านั้น
5. **`pnpm release` ปฏิเสธเมื่อมีไฟล์รุ่นถัดไปค้าง** — ปักธงมือ 4 ขั้น: `git tag -a v<เลข>-<slug>` (slug = 5 คำแรกของ title ตัดคำ a/an/the/and/of/that/is/to/in) → push สาขา → push ธง → `gh release create`
6. **ผืนฉากหลัง fixed ทึบทาสีทับเส้นทางนำทางได้ทั้งที่ hit-test เจอ** — จดไว้ใน SKILL.md ของ app-shell แล้ว (`.app-shell__context` ต้องมี position relative + z-index 1)
