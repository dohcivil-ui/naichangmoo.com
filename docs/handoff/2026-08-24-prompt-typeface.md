# Handoff — `v0.29.0: The Heavy Weights Stop Being Faked`

ข้าม `/grill-with-docs` ตาม AGENTS.md ข้อ 1 เพราะเป็นการเปลี่ยนค่าที่มีอยู่แล้วในระบบการนำเสนอ ไม่มีศัพท์ใหม่และไม่มีการตัดสินใจเชิงโครงสร้าง

## Description

เจ้าของงานรู้สึกว่าตัวอักษรบนเว็บดูไม่ดีและเสนอให้เปลี่ยนฟอนต์ ตรวจแล้วพบว่าสาเหตุไม่ใช่ตัวฟอนต์

`globals.css` สั่ง `font-weight: 800` อยู่ **23 จุด**, `900` อยู่ **11 จุด** และ `850/750/650` อีก 8 จุด แต่ `layout.tsx` โหลดฟอนต์มาเพียง `400, 500, 600, 700` ทุกน้ำหนักที่เกิน 700 จึงไม่มีไฟล์รองรับ และเบราว์เซอร์สังเคราะห์ให้ด้วยการยืดเส้น (faux bold) ซึ่งคือความเละที่เห็น การเปลี่ยนฟอนต์เฉย ๆ โดยไม่แก้รายการน้ำหนัก จะได้ผลลัพธ์เดิม

รอบนี้เปลี่ยนเป็น **Prompt** ซึ่งมีเก้าน้ำหนักจริง และโหลดหกน้ำหนักที่สเปคใช้จริง

## เรื่องที่สองที่เจอระหว่างทาง

`globals.css` เริ่มด้วย `@import "tailwindcss"` ซึ่ง Preflight ของ Tailwind รีเซ็ต `h1`–`h6` เป็น `font-weight: inherit` และไม่มีกฎไหนตั้งกลับ ผลคือ **หัวข้อทุกอันบนเว็บเป็น 400 มาตลอด** เท่ากับเนื้อความ ลำดับความสำคัญมาจากขนาดล้วน ๆ เรื่องนี้มีมาก่อนเวอร์ชันนี้และไม่เกี่ยวกับการเปลี่ยนฟอนต์ แต่ตอนนี้มีไฟล์ 600–900 จริงแล้วจึงตั้งกลับได้

เลือก **600 ไม่ใช่ 700 หรือ 800** เพราะภาษาไทยวางสระและวรรณยุกต์ทั้งบนและล่างบรรทัด hero อยู่ที่ 72px พร้อม `letter-spacing: -.05em` ถ้าน้ำหนักหนากว่านี้ ช่องว่างที่รูปสระต้องใช้จะตัน ส่วนป้ายเล็กยังหนาเท่าเดิม (`.eyebrow` 800, ปุ่ม 700) เพราะที่ 12 และ 16px กติกากลับด้าน — **ยิ่งใหญ่ยิ่งเบา ยิ่งเล็กยิ่งหนา**

## Security and data impact

ไม่มี เป็นการเปลี่ยนชั้นการนำเสนออย่างเดียว ไม่มี migration ไม่แตะสิทธิ์หรือข้อมูล

`next/font/google` ดาวน์โหลดไฟล์ตอน build แล้วเสิร์ฟจาก origin ของเราเอง เบราว์เซอร์ผู้ใช้ไม่ได้ส่งคำขอไปยังโดเมนของผู้ให้บริการฟอนต์ จึงไม่มีการรั่วของ referrer หรือ IP ไปยังบุคคลที่สาม

## Risk

เจ้าของงานดาวน์โหลด Prompt ครบ 18 น้ำหนักพร้อมไฟล์สัญญาอนุญาตไว้ที่ `km/fonts/` แต่ **ไฟล์ชุดนั้นไม่ได้ถูกใช้** เพราะ `km/` อยู่ใน `.gitignore` บรรทัด 21 ถ้าชี้ `next/font/local` ไปที่นั่น โปรเจกต์จะ build ได้เฉพาะเครื่องที่มีโฟลเดอร์นั้น ส่วน CI และ Vercel จะพัง ถ้าต้องการ self-host จากไฟล์ในเครื่องจริง ๆ ต้องย้ายเฉพาะน้ำหนักที่ใช้เข้ามาในพื้นที่ที่ git ติดตาม และแปลงเป็น `.woff2` ก่อน ไม่ใช่เอา TTF ทั้ง 18 ไฟล์เข้าไป

ข้อผูกพันที่เกิดขึ้น: รายการน้ำหนักใน `layout.tsx` ต้องครอบคลุมทุกน้ำหนักที่ `globals.css` ประกาศ ถ้าวันหน้ามีใครเขียน `font-weight: 300` เพิ่ม โดยไม่เติมลงรายการ ปัญหา faux bold จะกลับมาเงียบ ๆ ตรงจุดนั้น
