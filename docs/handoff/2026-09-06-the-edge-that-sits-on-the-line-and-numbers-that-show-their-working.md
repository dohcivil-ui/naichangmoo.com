## แปด — บั๊กที่เจอ ยังไม่ได้แก้

### 1. `.hero__note` ตายทั้งกฎ — บั๊กจริงในเว็บ

`globals.css:319-321` · `.hero p` มีความจำเพาะ (0,1,1) ชนะ `.hero__note` (0,1,0)
**ทั้งขนาด สีและระยะบนของ `.hero__note` จึงไม่มีผลเลย** · วัดด้วย `getComputedStyle`
ได้ `17.92px` สี `#d6e3e4` `margin-top 0` เท่ากับย่อหน้าเหนือมันทุกประการ
ทั้งที่ตั้งใจให้เป็น `.87rem` สี `#a9c4c7` เว้นบน 18px

**แก้ได้ด้วย** เปลี่ยนตัวเลือกเป็น `.hero .hero__note` หรือย้ายกฎให้จำเพาะขึ้น
· **ยังไม่แก้เพราะเป็นเรื่องหน้าตาที่เจ้าของงานควรเห็นก่อน**

### 2. ปุ่มอีกสองที่ที่ยังไม่ผ่าน `<Button>`

- **`.account-trigger`** ปุ่มบัญชีมุมขวาบน มุม 999px สูง 41px เงาฟุ้ง
- **`.markup-register__actions button`** ปุ่มในแผงรายการวัด สูง 32px

### 3. แถบนำทางตกบรรทัดที่แท็บเล็ตกับมือถือ

ที่ 820 และ 390 ปุ่ม "ขอใบเสนอราคา" ตกไปอยู่บรรทัดที่สองคนเดียว แถบจึงสูงขึ้นหนึ่งแถว
· เป็นของเดิม ไม่ได้เกิดจากการแก้ทรงปุ่ม

### 4. `collapseStaircases` สร้างเส้นเฉียงได้

ระหว่างทดลองเรื่องเสาเจอรูปที่มีด้าน `1231,1043 → 1180,1029` ซึ่งเฉียง
ทั้งที่ skill บอกว่าขอบต้องเป็นแนวนอนแนวตั้งล้วนโดยโครงสร้าง
· เกิดเฉพาะตอนใส่การแก้ที่ถอยออกไปแล้ว **ยังไม่ยืนยันว่าเกิดกับโค้ดปัจจุบันได้ไหม**

## สิบเอ็ด — บทเรียนของเซสชันนี้

**ผมไล่เรื่องเสาสามรอบและถอยทั้งสามรอบ** เจ้าของงานทักตรง ๆ ว่ากิน context เปล่า
ซึ่งถูกในส่วนนั้น · รากของมันคือ

- **หยุดไม่เป็นหลังรอบแรกที่ล้ม** ควรถอยแล้วไปทำงานที่สองที่เขาสั่งไว้ตั้งแต่ต้น
  แทนที่จะลองวิธีที่สองและสามในเรื่องเดียวกัน
- **ทดสอบบนภาพผิดผืน** เสียไปหนึ่งรอบเต็มเพราะดึงผืนที่เห็นบนจอมาแทนผืนวิเคราะห์
  ทั้งที่ skill เขียนไว้ชัดว่า "อ่านจากสิ่งที่อัลกอริทึมเห็น"
- **เชื่อเทสต์เขียวเกินไป** 1,204 ข้อเขียวหมดในขณะที่ห้องจริงพัง 34%
  ตอนนี้มี `sweep-region-fill.mts` แล้ว **ต้องรันทุกครั้งที่แตะกติกาเสา**

**อีกข้อ** ไม้ต่อฉบับก่อนบอกว่าเพดานความหนาเส้น "ราวสามพิกเซล" ซึ่งกว้างเกินจริง
· ตัวเลขในไม้ต่อเป็นการประเมิน ไม่ใช่การวัด **ต้องวัดซ้ำเองก่อนใช้เสมอ**

## สิบสอง — ของที่ตรวจแล้ว จดไว้กันทำซ้ำ

- **MCP คลิกตรงเป้าแล้ว ไม่คลาด 46 พิกเซลเหมือนที่ skill จด** วัดซ้ำได้ตรงเป๊ะ
  แต่ยังต้องใช้กล่องเล็ง `#aim-box` แบบ `pointer-events:none` เหมือนเดิม
- **มุมมองเปลี่ยนเองระหว่างวัดกับคลิก** ต้องอ่าน `getBoundingClientRect` ของผืนใหม่
  ทันทีก่อนวางกล่องเล็ง แล้วคลิกต่อเลย ห้ามเว้นจังหวะ
- **Edge ล่มเมื่อผืนถูกซูมลึกมาก** (rect กว้าง 4456px) เกิดหลังกดยกเลิกห้องที่ค้าง
- **Edge ของ MCP เป็นคนละโปรไฟล์กับของเจ้าของงาน** ไม่ทับกัน ใช้ได้โดยไม่รบกวนเขา
  · ถ้าต่อไม่ติดให้สตาร์ทเองด้วยคำสั่งใน `~/.claude/edge-mcp.cmd`
- **HMR ล้างไฟล์ PDF ที่เปิดไว้** ทุกครั้งที่แก้ source ต้องอัปโหลดใหม่
- **`git add -p` ใช้ไม่ได้** ในสภาพแวดล้อมนี้ ไฟล์ที่มีงานสองเรื่องปนกันจึงต้อง commit ทั้งไฟล์
- **รั้วสี ADR 0021 กินถึงไฟล์เทสต์ด้วย** ห้ามฝังเลขสีดิบแม้ในข้อมูลจำลอง
