# Handoff — `v0.23.0: The Latest Circular Wins, and the Dataset Says Which One It Is`

## Description

เจ้าของงานตัดสินว่า **หนังสือเวียนกรมบัญชีกลางต้องใช้ฉบับล่าสุดเสมอ** ทั้งบัญชีค่าแรงงานสำหรับถอดแบบ
และตาราง Factor F คำตัดสินนี้ถูกบันทึกเป็นกฎของโปรเจกต์ และเปลี่ยนงานที่ค้างอยู่หนึ่งข้อ:
การตามหาตาราง 6% ฉบับก่อน ว481 ไม่ใช่เงื่อนไขของการคำนวณอีกต่อไป สิ่งที่ต้องมีแทนคือกลไกที่บอกได้ว่า
ฉบับที่ระบบถืออยู่ยังเป็นฉบับล่าสุดหรือไม่

## Changed Scope

## Verification

- `docs/rules/engineering.md` มีกฎและระบุคู่ที่ถูกแทนไว้ตรงตัว
- `docs/research/factor-f-provenance-2026-08-24.md` มีหนังสือเวียนทั้งสองฉบับ เส้นเวลา และคำถามที่ยังเปิดอยู่
- `node scripts/check-roadmap.mjs` ผ่าน pointer ตรงกับไฟล์เวอร์ชัน
- ไม่มีการเปลี่ยนโค้ด schema หรือชุดข้อมูล จึงไม่มีผลต่อ gate อื่น

## Security and data impact

ไม่มี เป็นเอกสารและแผนงานล้วน

## Rollback

Revert commit นี้ กฎกลับไปไม่มีข้อกำหนดเรื่องฉบับล่าสุด และ roadmap กลับไปเป็น v0.22.0

## สิ่งที่คำตัดสินนี้เปลี่ยน

1. **ค่าแรงต้องมาจาก ว480 ไม่ใช่ ว809** — `harness-audit-2026-08-23.md` และ ADR 0007 อ้าง ว809 (14 พ.ย. 2568)
   ซึ่งเก่ากว่า ว480 (26 มิ.ย. 2569) เจ็ดเดือน เอกสารเก่าสองฉบับนั้นไม่ได้แก้ เพราะเป็นบันทึก ณ เวลาที่เขียน
   กฎใหม่อยู่ที่ `docs/rules/engineering.md` ซึ่งเป็นที่ที่คนอ่านก่อนลงมือ
2. **IP-068 ถูกแทนด้วย IP-072** — เดิมคือ "ตามหาหนังสือเวียนฉบับ 6% ก่อน ว481 เพื่อปิดช่วงวันที่บังคับใช้"
   ตอนนี้คือ "ทำให้ระบบบอกได้ว่าฉบับที่ถืออยู่ยังล่าสุดหรือไม่" ซึ่งเป็นสิ่งที่กฎใหม่ต้องการจริง
3. **IP-051 ได้ต้นทางที่ชัดแล้ว** — เดิมเขียนลอย ๆ ว่า price observations ต้องมี unit และแยกวัสดุ/ค่าแรง
   ตอนนี้ระบุว่าต้นทางคือ ว480 และเงื่อนไขที่ทำให้อัตราต่างกัน (ช่วงจำนวน เขตพื้นที่ วิธีทำงาน)
   ต้องเก็บเป็นข้อมูล ไม่ใช่หมายเหตุข้อความ

## คำถามที่ยังเปิดอยู่

1. **ราคากลางย้อนหลัง** — คำตัดสิน "ใช้ฉบับล่าสุด" ตอบว่าผลิตภัณฑ์ใช้ฉบับไหนในการตั้งราคาวันนี้
   แต่ยังไม่ได้ตอบว่า ถ้าต้องตรวจหรือทำซ้ำราคากลางของโครงการที่ตั้งราคาไปแล้วก่อนหน้าฉบับล่าสุด
   ระบบควรใช้ฉบับที่บังคับใช้ ณ วันนั้น หรือฉบับล่าสุดเสมอ — บันทึกไว้ใน constraints ของ v0.23.0
2. **ค่างานอยู่ระหว่างสองแถว** (IP-069) — เทียบอัตราส่วนตามหมายเหตุ หรือใช้ค่าแถวที่ต่ำกว่าตามที่ ปร.4 จริงทำ
   ต่างกัน 1,400 บาท ยังรอผู้มีคุณวุฒิตัดสิน
3. **ยังไม่มีผู้รับรองชุดข้อมูล Factor F** (IP-070)

## Next action
