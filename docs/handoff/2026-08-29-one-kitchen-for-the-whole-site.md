## สี่ — บั๊กตระกูล "ประกาศแล้วแต่เป็นหมัน" ตัวที่สี่

**ตัวแปลง CSS ของ Next ย่อ `color-mix()` ที่ผสมตัวแปรสองตัว ให้เหลือแค่สีแรก**

```
เขียนไว้   color-mix(in srgb, var(--teal) 88%, var(--ink))
ที่เบราว์เซอร์  var(--teal)
```

ไม่มี error ไม่มีคำเตือน สีก็แค่ไม่เปลี่ยน · **ผสมตัวแปรกับค่าคงที่ยังทำงานปกติ**
เช่นเงาตอนชี้ของการ์ดที่ผสม `var(--price-lead)` กับ `rgba(...)` ยังผสมจริง
ที่พังคือตัวแปรผสมตัวแปร · ตรวจจากสไตล์ชีตที่หน้าโหลดจริง ไม่ใช่จากไฟล์ต้นทาง

**ยังเหลืออีกแปดจุดที่เขียนไว้ก่อนหน้านี้และไม่เคยผสมจริง** รวมถึงสีขอบตอนชี้ของ PRICEMETR เอง
และป้ายเตือนสีส้ม บันทึกเป็น IP-209

นี่คือตัวที่สี่ต่อจาก `tabular-nums` บนฟอนต์ที่ไม่มี `tnum` · `animation-fill-mode: both`
ที่ฆ่า `:hover { transform }` · และฉากหลัง `position: fixed` ที่ทาทับท้ายเว็บ
**สี่ตัวนี้มีรูปแบบเดียวกันหมด คือ CSS อ่านแล้วเหมือนสั่งครบ แต่ผลจริงไม่เกิด
และจับได้ด้วยการเปิดของจริงหรือวัดเท่านั้น ไม่มีทางจับได้จากการอ่านโค้ด**

## ห้า — เรื่องที่เจ็บแล้วต้องจำ

1. **ผมประกาศว่า "ครัวกลางเสร็จแล้ว" ทั้งที่ยังไม่เปิดดูของจริงสักหน้า** แล้วต้องกลับไปแก้ที่เดิม
   สามรอบ เจ้าของงานทักตรง ๆ ว่า "ไหนว่าแก้แล้ว" · **เขียนเสร็จไม่ใช่เสร็จ วัดแล้วถึงเสร็จ**
2. **การ์ดที่เข้มขึ้นแค่สิบหน่วยผลักสีที่เคยผ่านแบบเฉียดฉิวให้ตก** teal ของแบรนด์อยู่ที่ 4.55:1
   บนพื้นขาวมาตลอด พอการ์ดเป็นกระจกก็เหลือ 4.37:1 ทั้งเว็บ · **ขยับความทึบเมื่อไร
   ต้องวัดสีที่เคยผ่านเฉียดฉิวใหม่ทุกครั้ง**
3. **กฎที่วางผิดที่จะแพ้เงียบ ๆ** เขียนกฎธีมไว้กลางไฟล์ แล้วกฎรายหน้าที่อยู่ล่างกว่าทับหมด
   และกฎที่เจาะจงกว่า (`.market-category__apps .app-card`) ก็ทับได้แม้ธีมจะอยู่ท้ายไฟล์
   **แก้ด้วย `!important` คือการทิ้งปัญหาไว้ให้คนถัดไป ทางที่ถูกคือไปแก้ที่กฎเดิม**
4. **ครัวกลางเกือบฆ่าของดีที่มีอยู่** การ์ดแอปมีปฏิกิริยาที่ดีกว่าอยู่แล้ว ถ้าปล่อยให้ของกลางทับ
   จะเป็นการรื้อของดีทิ้งในนามของความเหมือนกัน · **รวมพื้นผิว ไม่จำเป็นต้องรวมปฏิกิริยา**
5. **สำเนาที่ถูกถอดออกต้องถอดให้หมด** ตอนถอดผืนฉากหลังของหลังบ้าน ผมถอดการปรับตำแหน่ง
   ที่เคยแก้ไว้ในรุ่นก่อนไปด้วย หลังบ้านเลยจางจนแทบขาว · เจอเพราะเปิดดู ไม่ใช่เพราะอ่านโค้ด
6. **`resize_page` ย่อหน้าต่างต่ำกว่าราว 478px ไม่ได้** ต้องใช้ `emulate` ถึงจะได้ 390px จริง
7. **สคริปต์ที่ใช้ `@napi-rs/canvas` ต้องวางไว้ในโปรเจกต์** Node หาโมดูลจากที่อยู่ของไฟล์สคริปต์
   ไม่ใช่จาก cwd
