## Description

สามรุ่นที่ไม่เกี่ยวกัน ปิดทีละก้อนตามที่เจ้าของงานเลือกไว้ รุ่นแรกนำงานที่นอนอยู่บนสาขาที่ตามหลัง
สายหลักกลับเข้ามา คือแกนคำนวณค่า K ที่แพลตฟอร์มประกาศแอปไว้แล้วแต่ไม่มีโค้ดอยู่บนสายที่ปล่อยรุ่น
กับภาษาการออกแบบที่เคยเป็นความรู้กระจายอยู่ในหัวคน พร้อมกันนั้นโรดแมปได้ 8 รายการที่หายไปกลับคืน
ภายใต้เลขเดิม และ CHANGELOG ได้ entry ที่ขาดไปสามรุ่น รุ่นที่สองทำให้ระยะเวลาที่ผู้ใช้กรอกนับเป็น
วันทำงานได้ โดยเลือกได้ต่อโครงการและไม่ย้ายแกนเวลาของแผน รุ่นที่สามให้เอกสารแนบสัญญามีตราตั้งต้น
ที่อ่านออกว่าเป็นช่องรอใส่ตราจริง
