## ส่วนที่ 1 — v0.33.0

ADR 0013 ปิดตารางงานของลูกค้าไม่ให้ผู้ดูแลเข้าถึง แต่จนถึง v0.32.0 มันจริงเพียงเพราะยังไม่มีใครเขียน query นั้น ไม่มีอะไรกันคนเพิ่มเข้ามาวันหลัง

`src/server/admin/closed-tables.test.ts` สแกน source ของหลังบ้านทั้งหมด แล้วแดงถ้าพบการอ่านคอลัมน์จากตารางที่ปิดไว้ เลือกทำที่ระดับ source ไม่ใช่ runtime เพราะสิ่งที่ต้องรับประกันคือ **เส้นทางนั้นไม่มีอยู่** ไม่ใช่ **เรียกแล้วถูกปฏิเสธ** — เทสต์ runtime ต้องมี session และฐานข้อมูล และพิสูจน์ได้แค่เส้นทางเดียวที่มันเรียก

สามอย่างที่ทำให้เทสต์นี้ใช้ได้จริง:

- **ตัดคอมเมนต์ก่อนสแกน** ทุกไฟล์ในหลังบ้านอธิบายไว้ในคอมเมนต์ว่าห้ามแตะตารางไหน สแกนเนอร์ที่แยกคอมเมนต์จากโค้ดไม่ได้จะแดงใส่เอกสารที่อธิบายกฎนั้นเอง
- **แยก `metrics.projects` ออกจากตาราง `projects`** ตัวแรกเป็นตัวนับบนอ็อบเจกต์ผลลัพธ์ ไม่เกี่ยวกับตาราง ใช้ negative lookbehind กันไว้
- **พิสูจน์ว่ามันแดงเป็น** แอบใส่ `projects.name` เข้าไปใน `entitlement-admin.ts` จริง ยืนยันว่า 2 assertion แดง แล้วคืนไฟล์และยืนยัน 23 เขียวพร้อม `git diff` สะอาด guard ที่ล้มไม่เป็นคือ guard ที่ไร้ค่า

ข้อยกเว้นเดียวคือ `platform-admin-metrics.ts` ที่พูดชื่อ `projects` ได้เพื่อ **นับ** และมีเทสต์แยกที่ยืนยันว่ามันไม่เคยอ่านคอลัมน์จากตารางนั้น

**Verification:** `pnpm test` 220 passed, 33 skipped · `typecheck` ผ่าน · `lint` 0 error · `check-roadmap` 19 items

**Rollback:** ลบไฟล์เทสต์ ไม่มี production code เปลี่ยน

## ส่วนที่ 2 — สถานะสำหรับเซสชันถัดไป

### ที่อยู่ของงาน

Branch ที่ทำงานอยู่คือ **`feature/pricing-page-and-access-copy`** ซึ่งสะสมงานตั้งแต่ v0.27.0 ถึง v0.33.0 ไว้ทั้งหมด **ยังไม่ได้ merge เข้า main** และมีอีกสอง branch ที่แตกไปก่อนหน้าและ push แล้ว: `feature/estimeter-measurement-breakdown` (งาน CSS hero กับโลโก้) และ `feature/trial-seven-days` (v0.26.0)

> **กับดักที่เจอจริงในเซสชันนี้:** `git push` รายงาน `Everything up-to-date` ทั้งที่ branch บน remote ยังค้างอยู่ที่ commit เก่า ตรวจพบเพราะ `git ls-remote` ไม่ตรงกับ local HEAD แก้ด้วย `git push origin HEAD:refs/heads/<branch>` **ยืนยันด้วย `git ls-remote` เสมอ อย่าเชื่อข้อความจาก push**

### ยังไม่ได้ทำ และเป็นเงื่อนไขของการใช้งานจริง

### ข้อตกลงที่ตัดสินไปแล้วในเซสชันนี้ อย่ารื้อโดยไม่อ่าน ADR ก่อน

- **ADR 0009** ทดลองใช้ 7 วัน · **ADR 0010** ข้อความก่อนเข้าใช้งานเป็นประโยคเดียวทุกพื้นผิว เพดาน 1 โครงการยังบังคับใช้แต่บอกเฉพาะตอนกดเริ่มและตัวนับในแอป
- **ADR 0011** ราคาประกาศได้ VIP 1,170/เดือน หรือ 10,440/ปี รวม VAT · บัตรรายวัน 49 บาทเป็นสินค้าคนละตัว **ราคาแพงต่อวันโดยตั้งใจ** เป็นกลไกผลักให้สมัคร ลดไม่ได้ · จุดคุ้มทุน 24 วัน ซึ่งสูงกว่าเดือนทำงาน 22 วัน เจ้าของงานรับทราบและเลือก 49
- **ADR 0012** สิทธิ์ผู้ดูแลเป็นแถวที่ถูกมอบให้ ถอนได้ มีร่องรอย ตรวจ fail closed รวมตอนอ่าน DB ไม่ได้
- **ADR 0013** ผู้ดูแลจัดการ *สิทธิ์การใช้งาน* ได้ แต่แตะ *ตัวงาน* ของลูกค้าไม่ได้ และ **การนับไม่ใช่การอ่าน**

### กติกาของโค้ดที่เทสต์บังคับไว้แล้ว

- ราคาทุกตัวอยู่ใน `src/lib/pricing.ts` ที่เดียว ข้อความในการ์ดห้ามมีรูปแบบ `ตัวเลข + บาท`
- ตารางความสามารถบนหน้า `/pricing` derive จาก `listCapabilities()` ห้ามพิมพ์เครื่องหมายถูกเอง
- หน้าหลังบ้านทุกหน้าประกอบจากการ์ดใน `src/components/admin/admin-card.tsx` เท่านั้น ห้ามเขียน markup เอง
- `layout.tsx` ต้องโหลดทุก `font-weight` ที่ `globals.css` ประกาศ ไม่งั้น faux bold กลับมาเงียบ ๆ
- server action ทุกตัวในหลังบ้านต้องเรียก `resolvePlatformAdmin()` เอง ไม่พึ่ง layout
