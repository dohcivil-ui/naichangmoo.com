## เจ็ด — ADR 0025 เขียนแล้ว ยังไม่มีโค้ดสักบรรทัด

`docs/adr/0025-an-expected-month-is-a-claim-that-expires-by-itself.md` · **amends §5 ของ ADR 0015**

**ตอบ 0011 ด้วยย่อหน้าของ 0011 เอง** ADR 0015 อ้างว่า 0011 ห้ามคำสัญญาเรื่องอนาคต
อ่านทั้งฉบับแล้ว **มันไม่ได้ห้ามเรื่องนั้น** สิ่งที่มันห้ามคือตัวเลขที่ยังไม่อนุมัติ กับตัวเลข
ที่กระจายหลายที่ · และมันมีย่อหน้า "ช่วงลดราคามีได้ และมีวันสิ้นสุด" ที่จบด้วยประโยคว่า
**"เมื่อพ้นกำหนด ราคากลับเป็นราคาปกติเองโดยไม่ต้องมีใครไปแก้"** — นั่นคือรูปของคำแถลง
ที่ 0011 รับได้อยู่แล้ว เดือนคาดเข้ารูปเดียวกันได้ทุกข้อ

ส่วนคำเทียบเรื่องปุ่มชำระเงินนั้นเทียบคนละอย่าง ปุ่มชำระเงินสัญญาว่า*กดแล้วจะเกิดอะไรเดี๋ยวนี้*
แล้วมันไม่เกิด ซึ่งพิสูจน์ว่าเท็จได้ทันทีที่กด · เดือนคาดไม่ได้สัญญาว่ากดแล้วเข้าได้

**ข้อแลกเปลี่ยนที่ทำให้คอลัมน์นี้ได้รับอนุญาต** ทุกครั้งที่เดือนถูกแก้ ต้องลง `auditEvents`
ว่าใครแก้ เมื่อไร จากเดือนไหนเป็นเดือนไหน · **คอลัมน์นี้ได้รับอนุญาตเพราะมันเลื่อนเงียบไม่ได้**
ถ้าวันหนึ่งมีคนถอดการลงบันทึกออก ข้ออนุญาตหมดอายุพร้อมกัน

**คำตัดสินที่ ADR ตัดสินเอง ตามที่เจ้าของงานมอบให้** เดือนที่เลยมาแล้ว การ์ดเลิกพูดถึงมันเอง
และแอป**ตกกลับไปขั้นที่หนึ่ง** ไม่ใช่ค้างแสดงตุลาคมในเดือนธันวาคม และไม่ใช่เลื่อนให้เอง
ซึ่งเป็นเปอร์เซ็นต์ที่ค้างที่ 90 พอดี เพียงเปลี่ยนหน่วย · **แถบที่ถอยหนึ่งขั้นเป็นข้อมูล ไม่ใช่บั๊ก**

**ยังไม่แตะ `roadmap.json`** ตามขั้นที่ 5 ของคำสั่ง `adr` เพราะกฎข้อ 4 กับ 8 ของ `AGENTS.md`
ที่เขียนใหม่ 2026-08-30 สั่งว่าไฟล์ roadmap เขียนตอนปักธง ไม่ใช่ตอนเริ่มงาน · ใส่พร้อมกัน
ทีเดียวตอนปักธง
