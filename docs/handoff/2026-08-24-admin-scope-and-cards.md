# Handoff — `v0.31.0: The Right To Use, Not The Work`

ข้าม `/grill-with-docs` ตาม AGENTS.md ข้อ 1 การตัดสินใจเรื่องขอบเขตถูกซักและบันทึกใน ADR 0013 พร้อมตารางทางเลือกสี่ข้อ ส่วนระบบการ์ดเป็นข้อกำหนดที่เจ้าของงานสั่งตรง ๆ ว่าต้องตรึงไว้เป็นแนวทาง

## Description

ADR 0012 เขียนขอบเขตผู้ดูแลไว้ว่า "เนื้อหาของแพลตฟอร์มและตัวเลขสรุปเชิงรวม" ซึ่งแคบเกินกว่างานจริง เจ้าของงานระบุว่าผู้ดูแลต้องจัดการสิทธิ์การใช้งานได้ด้วย ซึ่งหมายถึงการเขียนแถวใน `app_entitlements` ที่มี `organization_id` คือผูกกับลูกค้ารายหนึ่ง

ADR 0013 ตอบว่าไม่ละเมิดหลักเดิม เพราะ **เส้นแบ่งที่แท้จริงไม่ใช่ "ข้อมูลของลูกค้า" กับ "ข้อมูลของแพลตฟอร์ม" แต่คือ สิทธิ์การใช้งาน กับ ตัวงาน**

สิทธิ์คือความสัมพันธ์ที่แพลตฟอร์มเป็นคู่สัญญาและเป็นผู้ออกเอง เป็นฝ่ายที่ต้องแก้เมื่อมีคนจ่ายเงินแล้วสิทธิ์ไม่ขึ้น ส่วนตัวงานคือสิ่งที่ลูกค้าถอดจากแบบและคำนวณเอง แพลตฟอร์มเก็บให้แต่ไม่ได้เป็นเจ้าของ

ADR 0013 ระบุตารางที่ปิดตายไว้เป็นชื่อ: `projects`, `drawing_documents`, `takeoff_runs`, `takeoff_groups`, `takeoff_items`, `takeoff_measurements`, `evidence_references`, `price_sets`, `price_observations`, `estimate_revisions` — ทั้งอ่านและเขียน

**และยึดเส้นที่ดูเล็กแต่สำคัญ: การนับไม่ใช่การอ่าน** หน้าแรกนับจำนวนโครงการได้ แต่แสดงชื่อโครงการไม่ได้ เพราะชื่อโครงการงานราชการมักมีชื่อหน่วยงานและสถานที่อยู่ในนั้น ทุกการขยาย "ขอแค่ชื่อ" คือขั้นแรกของการเปิดทั้งตาราง

## ระบบการ์ด

เจ้าของงานสั่งให้ตรึง UI ไว้ที่แนวการ์ด เพื่อให้แก้ไขง่ายแบบ CMS รุ่นเก่า ผลคือ `src/components/admin/admin-card.tsx` เป็น markup ชุดเดียวที่หน้าหลังบ้านใช้ได้ — `AdminCard`, `AdminGrid`, `AdminStat`, `AdminStatRow`, `AdminEmpty`, `AdminTable`

เหตุผลคือการบำรุงรักษา ไม่ใช่ความสวย หน้าที่เขียน markup เอง จะเพี้ยนไปเรื่อย: หัวข้อที่สามขนาดต่างนิดหน่อย หัวข้อที่ห้าลืม empty state และการแก้ padding ทั้งระบบกลายเป็นการไล่แก้ทีละไฟล์ พอทุกส่วนเป็นการ์ด การเพิ่มส่วนใหม่คือไม่กี่บรรทัด และการ์ดทุกใบขยับพร้อมกัน

`AdminStat` บังคับให้ส่ง `empty` เสมอ จึงไม่มีทางเรนเดอร์เลขศูนย์ที่ดูเหมือนค่าที่วัดมา และ `AdminTable` รับ columns กับ rows โดยที่ผู้เรียกไม่เคยเขียน `<table>` เอง การจัดหัวตาราง การชิดขวาของตัวเลข และกรณีไม่มีแถว จึงเพี้ยนรายหน้าไม่ได้

## Security and data impact

ไม่มี migration ในรอบนี้ ADR 0013 ขยายขอบเขตบนกระดาษ แต่ **ยังไม่มีหน้าจอใดที่เขียนสิทธิ์ได้จริง** — งานนั้นคือ IP-087

ขอบเขตที่กว้างขึ้นมีต้นทุนที่ต้องรับรู้: บัญชีผู้ดูแลที่ถูกยึดจะแจกสิทธิ์ใช้งานฟรีให้ตัวเองได้เมื่อ IP-087 เสร็จ สิ่งที่จำกัดความเสียหายคือ audit event ทุกรายการมี actor และเหตุผลที่บังคับกรอก ไม่ใช่การหวังว่าจะไม่เกิด

## Risk

**ADR 0013 ยังไม่ถูกบังคับใช้ด้วยเทสต์** เอกสารบอกว่าผู้ดูแลอ่าน `projects` ไม่ได้ แต่ยังไม่มีเทสต์ที่พิสูจน์ บันทึกเป็น **IP-088** และต้องเป็นเทสต์ที่เรียกเส้นทางข้อมูลจริง ไม่ใช่เทสต์ที่ยืนยันว่าหน้าจอไม่มีปุ่ม ซึ่งขัดกับกฎ prefer server-side authorization checks over hiding UI controls
