## เจ็ด — สี่ข้อที่ตัดสินไปแล้ว อย่าถามซ้ำ อย่าทำใหม่

1. **`BaseIcon` ไม่ต้องแก้สักบรรทัด** `platform-icons.tsx:7` วาง `{...props}` ท้ายสุดหลัง
   `viewBox` และ `strokeWidth` แล้ว คนเรียกทับได้อยู่แล้ววันนี้ · ถ้ากำลังจะเพิ่ม prop ให้มัน
   คืองานเปล่า **หยุด** · ผืนออกแบบวาดที่กริด 24 ความหนา 1.5 (สัดส่วน 0.0625) ของเรา
   คือ 2.4 บนกริด 48 (0.05) เส้นเราบางกว่าเล็กน้อย อยากได้เท่าผืนส่ง `strokeWidth={3}` ตอนเรียก
2. **`hero-slider.tsx` เป็น `'use client'`** → **ห้าม import `@/server/app-registry` เข้าไปเอง**
   ให้ `page.tsx` ฝั่ง server เรียก `readCatalogueClaims()` แล้วส่ง `describeCardClaims(claim)`
   ลงมาเป็น prop · `architecture-fence` ห้ามแค่ `@/db` `drizzle-orm` `@/server/project-status`
   **ด่านจะไม่แดงแต่ build พัง** ตรงนี้ต้องคุมด้วยการออกแบบ
3. **`visualAssetUrl()` ไม่ต้องแก้** มันคืน `/brand/${file}` อยู่แล้ว **ห้ามเพิ่มฟิลด์ `dir`
   หรือฟังก์ชันที่สอง**
4. **แถบความพร้อมทำสองขั้น** `--announced` 50% กับ `--open` 100% · ไม่มีขั้นสาม
   **ห้ามเสนอเพิ่มคอลัมน์ในทะเบียน** ADR 0015 ปฏิเสธ "คาดว่าเปิดเมื่อ" ไว้แล้ว เพราะมันจะ
   กลายเป็นเปอร์เซ็นต์ความคืบหน้าในรูปแบบวันที่ · `describeCardClaims(claim).readiness`
   คืน `available` กับ `coming_soon` ซึ่งแมปเข้าสองคลาสนี้พอดี และคืน `cta` ที่เป็นถ้อยคำปุ่ม
   ตามทะเบียนมาให้ด้วย ไม่ต้องคิดถ้อยคำเอง
