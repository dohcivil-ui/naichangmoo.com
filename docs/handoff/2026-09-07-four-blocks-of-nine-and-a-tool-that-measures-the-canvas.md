## สาม — สมุดข้อยกเว้น เล่มที่ต้องรู้จักก่อนทำงาน

`docs/design/v3-deliberate-differences.json` — **สิบสี่ข้อ** เก็บความต่างที่ตั้งใจ
พร้อมเหตุผลและวันที่ตัดสิน · อยู่ในเรพอเพราะเป็นคำตัดสิน ไม่ใช่เครื่องมือ

**อะไรที่ไม่อยู่ในสมุดและไม่ตรงผืน = บั๊ก** ไม่ต้องเถียงกันใหม่ทุกรอบ

**ทุกข้อต้องพิสูจน์ตัวเองได้ ห้ามยืนยันด้วยประโยค** — ประโยคยังยืนยันต่อไปในวันที่
สิ่งที่มันอ้างถึงหายไปแล้ว

| ทาง | ตัวเทียบล้มเมื่อ |
|---|---|
| ชื่ออยู่ใน `MAP` ของ `compare.mjs` | วัดแล้วไม่ต่างอีกแล้ว = เหตุผลตายไปแล้ว |
| `checkedBy` | ไฟล์ที่อ้างหายไป หรือตัวตรวจในตัวไม่ผ่าน |
| `effectOf` | ชื่อที่อ้างไม่อยู่ในสมุดแล้ว หรือข้อนั้นไม่ต่างแล้ว |
| `dueWith` + `dueWhen` | selector โผล่ในหน้าแล้ว = ครบกำหนดต้องมีตัวตรวจ |
| `unmeasured: true` | ไม่มี `unmeasuredWhy` กำกับ |

**`dueWith` ทวงจริง** พอบล็อกโปรโมชั่นลง ตัวเทียบขึ้น "ครบกำหนดแล้ว แท็บโปรโมชั่น"
ทันที จึงเอาข้อนั้นออกจากสมุดเพราะแท็บกลับมาแล้ว

**`hitTarget` พิสูจน์แล้วว่าจับได้จริง** ถอย `inset` ของขีดสไลด์กลับไปค่าที่เคยพลาด
มันตกทันทีว่ากดไม่โดน 2 มุมจาก 4 แล้วคืนค่าและผ่านอีกครั้ง

## สี่ — คำตัดสินใหม่ที่ทับของเดิม อ่านก่อนแตะปุ่ม

**ขนาดและทรงทุกค่ายึดผืน V3 · กฎ 48px ไม่ชนะผืนอีกต่อไป** (เจ้าของงาน 2026-09-07)

หัว `button.tsx` เขียนใหม่แล้วพร้อมวันที่ · **ไม่ส่ง `size` = 48 เหมือนเดิม**

**ผืนไม่ผูกความสูงกับระดับปุ่ม** `.btn` ในผืนไม่ประกาศ `height` เลยสักบรรทัด ความสูงเป็น
inline ต่อจุด มีห้าค่า 32 36 40 44 และ 44 เต็มกว้าง · `btn-primary` เป็นทั้ง 40 และ 44
ความสูงจึงเป็น **มิติที่สอง** ชื่อ `size` ไม่ใช่ส่วนหนึ่งของ tone

```
tone บอกหน้าที่ · size บอกขนาด · ทั้งคู่แปลงเป็นคลาสที่ globals.css
Size = 36 | 40 | 44 | "fit"     (32 เติมตอนที่มีคนเรียกจริง ยังไม่มี)
Tone = ...เดิมเจ็ด + slideNav + slideDot
```

**ห้ามเขียน CSS ทับขนาดปุ่มด้วย selector ลูกหลาน** `button-fence` มองไม่เห็น
รูนี้เคยเปิดอยู่สองจุดและปิดไปแล้ว
