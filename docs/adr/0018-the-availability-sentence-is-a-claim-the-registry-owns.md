# ADR 0018: ประโยคความพร้อมเป็นคำแถลงที่ทะเบียนเป็นเจ้าของ และการ์ดพูดหมวดสิทธิ์ ไม่พูดตัวเลขเงิน

**Status:** Accepted — amends ADR 0010 (the sentence's public copy moves into the registry) · closes IP-122 and IP-148

## Context

ADR 0015 แบ่งข้อมูลแอปเป็นสองชั้น: คำแนะนำตัว (ชื่อ ไอคอน คำอธิบาย) อยู่ในซอร์ส และคำแถลง
(สิทธิ์ ราคา ความพร้อม) ต้องมาจากทะเบียนที่ผู้ดูแลประกาศเท่านั้น แต่ `marketDetail.availabilityNote`
— ประโยคเดียวก่อนเข้าใช้งานที่ ADR 0010 กำหนด — ยังพิมพ์ตายตัวอยู่ในซอร์ส

ผลคือเหตุการณ์จริงบน `/market/estimeter` ตอน estimeter ถูกถอนคำประกาศเพื่อทดสอบ:
หัวข้อจากทะเบียนบอก "ยังไม่เปิดให้เข้าใช้" แต่ประโยคจากซอร์สใต้หัวข้อยังบอก "ทดลองใช้งานฟรี 7 วัน"
สองบรรทัดขัดกันเองบนหน้าเดียว เพราะประโยคนั้นพูดเรื่องราคาและความพร้อม — มันคือคำแถลง —
แต่ไม่มีผู้ดูแลคนไหนเป็นเจ้าของ

คำถามพ่วงจาก IP-148: การ์ดควรตอบคำถามเรื่องราคาด้วยตัวเลขเงินหรือไม่ ในเมื่อทะเบียนไม่มีคอลัมน์ราคา

## Decision

เจ้าของงานวินิจฉัยเมื่อ 2026-08-26:

1. **ประโยคความพร้อมเป็นคำแถลง** ย้ายบ้านเข้าทะเบียน: ตาราง `apps` ได้คอลัมน์ `availability_note`
   ผู้ดูแลพิมพ์หรือแก้ได้ที่หน้า admin panel ที่เดียว พร้อมคำประกาศ และบันทึกลง audit ทั้งค่าก่อนและหลัง
2. **ค่าในซอร์สลดชั้นเป็นคำแนะนำ** `marketDetail.availabilityNote` ยังอยู่ แต่เป็นแค่ค่าแนะนำ
   ที่ผู้ดูแลเห็นในฟอร์มหลังบ้าน แบบเดียวกับ `seededAccess` — หน้าเว็บสาธารณะไม่อ่านมันอีกเลย
3. **ยังไม่ประกาศ = เงียบ** หน้ารายละเอียดแอปแสดงประโยคนี้เฉพาะเมื่อทะเบียนประกาศแล้วและมีประโยค
   ช่องว่างคือการประกาศแบบหนึ่ง ไม่ใช่ validation error และฐานข้อมูลอ่านไม่ได้ให้ผลเหมือนไม่ประกาศ
   ตามกติกา fail-closed เดิมของ ADR 0015
4. **การ์ดพูดหมวดสิทธิ์ ไม่พูดตัวเลขเงิน** (ปิด IP-148) ทะเบียนไม่เก็บราคาเป็นตัวเลข การ์ดตอบคำถามราคา
   ด้วยหมวดสิทธิ์ที่ประกาศ (สมาชิกใช้ฟรี · ฟรีทดลองใช้ 7 วัน · เฉพาะบุคลากรกรมทางหลวง) ตัวเลขเงินอยู่ที่
   `/pricing` ที่เดียวตาม ADR 0011 การเพิ่มคอลัมน์ราคาในทะเบียนจะสร้างเลขซ้ำสองที่ซึ่งวันหนึ่งต้องขัดกันเอง

สิ่งที่ **ไม่เปลี่ยน** จาก ADR 0010: ประโยคก่อนเข้าใช้งานยังเป็นประโยคเดียว ไม่บอกเพดานโครงการ
หน้าจอกดเริ่มทดลองใช้ยังบอกเงื่อนไขครบ และการบังคับใช้ฝั่งเซิร์ฟเวอร์ไม่ถูกแตะ

## Alternatives considered

| Alternative | Why not selected |
|---|---|
| ซ่อนประโยคซอร์สเมื่อยังไม่ประกาศ โดยไม่ย้ายเข้าทะเบียน | ปิดอาการแต่ไม่ปิดเหตุ ประโยคยังเป็นคำแถลงไร้เจ้าของ และผู้ดูแลแก้ข้อความไม่ได้โดยไม่แก้โค้ด ขัดกับหลักที่เจ้าของงานวางให้ admin บริหารเองจากหลังบ้าน |
| ใช้ป้ายหมวดสิทธิ์ (`accessLabel`) แทนประโยค ไม่เพิ่มคอลัมน์ | เสียประโยคเฉพาะแอปอย่าง "สมาชิกใช้ได้ฟรีเมื่อแอปที่ปรับโครงสร้างใหม่พร้อมเปิดใช้งาน" ซึ่งบอกมากกว่าหมวด |
| เพิ่มคอลัมน์ราคาในทะเบียนให้การ์ดพูดตัวเลขได้ | ตัวเลขจะซ้ำกับ `/pricing` สองที่ และ ADR 0011 วางให้หน้าราคาเป็นที่เดียวที่แถลงตัวเลข เจ้าของงานเลือกให้หมวดคือคำตอบของการ์ด |

## Consequences

- migration `0008`: `ALTER TABLE apps ADD COLUMN availability_note text` (nullable ไม่มี backfill —
  ค่าเริ่มของทุกแอปคือเงียบ จนกว่าผู้ดูแลจะประกาศพร้อมประโยค)
- `AppClaim` และ `RegistryEntry` ได้ช่อง `availabilityNote` และฟอร์มหลังบ้านได้ช่องกรอกพร้อมค่าแนะนำจากซอร์ส
- เทสต์ของ `platform.test.ts` ที่กันคำว่า "โครงการ" ในประโยคซอร์สยังอยู่ เพราะค่าแนะนำที่ผู้ดูแลจะกดใช้
  ก็ต้องเคารพ ADR 0010 เช่นกัน
- ผู้อ่าน ADR 0010 จะเห็นหมายเหตุชี้มาที่ฉบับนี้ว่าสำเนาสาธารณะของประโยคย้ายไปทะเบียนแล้ว
