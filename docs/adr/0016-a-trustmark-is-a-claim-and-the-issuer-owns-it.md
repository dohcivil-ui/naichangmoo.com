# ADR 0016: เครื่องหมายรับรองคือคำแถลง และเจ้าของคำแถลงคือผู้ออกให้

**Status:** Accepted — applies the rule of ADR 0015 to an authority outside the platform

## Context

เจ้าของผลิตภัณฑ์ขอให้เพิ่มแถวใน footer สำหรับเครื่องหมายร้านค้าออนไลน์ โดยระบุว่า **หจก.ไทสกลวิศวกรรม** เป็นผู้รับเงิน แต่ในข้อความเดียวกันก็ระบุว่า **ยังไม่ได้จดทะเบียน** และกำลังพิจารณาว่าจะจดบริษัทใหม่หรือใช้บุคคลธรรมดาไปก่อน

อ่านรวมกันแล้วได้ความว่า ห้างหุ้นส่วนมีอยู่จริงและรับเงินจริง แต่ **การจดทะเบียนพาณิชย์อิเล็กทรอนิกส์ซึ่งเป็นสิ่งที่ทำให้ได้เครื่องหมาย DBD Registered ยังไม่ได้ทำ**

การติดเครื่องหมายนั้นวันนี้จึงเป็นการอ้างว่ามีทะเบียนที่ยังไม่มี ซึ่งเป็นเรื่องกฎหมาย ไม่ใช่เรื่องการออกแบบ และไม่ใช่สิ่งที่แก้ทีหลังได้ด้วยการถอดรูปออก เพราะความเสียหายเกิดตั้งแต่มีคนเห็นและเชื่อ

และมันคือรูปเดียวกับที่ ADR 0014 และ 0015 ว่าไว้ทั้งฉบับ เพียงเปลี่ยนผู้มีอำนาจ — จากผู้ดูแลแพลตฟอร์มที่ประกาศสิทธิ์ของแอป เป็นกรมพัฒนาธุรกิจการค้าที่ออกทะเบียนให้ร้าน ป้ายสิทธิ์บนการ์ดกับตราบน footer เป็นคำแถลงเหมือนกัน ต่างกันแค่ว่าใครเป็นคนพูด

ทางเลือกที่ง่ายที่สุดคือยังไม่ทำอะไรเลยจนกว่าจะจดเสร็จ แต่เจ้าของขอให้ **เตรียมโครงไว้ให้เติมได้ในอนาคต** ซึ่งเป็นคำขอที่ถูก เพราะของแบบนี้มักถูกยัดเข้ามาตอนรีบ และตอนรีบคือตอนที่คนตัดสินใจแย่ที่สุด

## Decision

**เครื่องหมายรับรองแสดงได้ก็ต่อเมื่อผู้ออกได้ออกให้จริงแล้ว และหลักฐานต้องครบสองอย่าง**

**1. โมดูลถูกสร้างไว้แล้ว และว่างเปล่าโดยตั้งใจ** `src/lib/business-identity.ts` เก็บรายการเครื่องหมายเป็นข้อมูล ไม่ใช่ JSX ที่กระจายอยู่ใน footer แต่ละที่ วันนี้มีหนึ่งรายการคือทะเบียนพาณิชย์อิเล็กทรอนิกส์ และ `registrationNumber` เป็น null

**2. เครื่องหมายขึ้นเมื่อมีครบสองอย่างเท่านั้น คือเลขทะเบียนจากผู้ออก และรูปจากผู้ออก** ขาดอย่างใดอย่างหนึ่งไม่ขึ้น เพราะการมีอย่างเดียวแปลว่าเราจะต้องเติมอีกอย่างเอง — และการวาดตราที่หน้าตาเหมือนของราชการขึ้นมาเอง คือคำอ้างเท็จอันเดิมที่เดินอ้อมไปอีกทาง

**3. ไม่มีอะไรให้แสดง แปลว่าไม่มีแถว** `describeTrustRow()` คืน `visible: false` และ footer ไม่เรนเดอร์ `<div>` นั้นเลย ไม่ใช่แถวเปล่าที่มีเส้นคั่นรออยู่ แถบว่างที่มีขอบบอกคนอ่านว่ามีบางอย่างโหลดไม่ขึ้น ซึ่งแย่กว่าไม่มีอะไร

**4. เพิ่มเครื่องหมายใหม่ = เพิ่มหนึ่งรายการในอาร์เรย์ ไม่ต้องแก้โค้ด** ทะเบียนบริษัทที่จดใหม่ ตราของผู้ให้บริการชำระเงิน หรืออะไรก็ตามที่มาทีหลัง เข้าโครงเดียวกันหมด นี่คือสิ่งที่เจ้าของขอเมื่อบอกว่าให้ทำเป็นโมดูลเปิดไว้

**5. ชื่อนิติบุคคลถูกบันทึกไว้ แต่ยังไม่ขึ้นหน้าเว็บ** `businessOperator.publish` เป็น false การเอาชื่อทางกฎหมายขึ้นหน้าเว็บเป็นการตัดสินใจของเจ้าของที่ยังไม่ได้ทำ และวันนี้ยังไม่มีการรับชำระเงินที่ไหนเลย (IP-081 ยัง planned) บันทึกข้อเท็จจริงไว้เพื่อให้การตัดสินใจมีสวิตช์ให้กด ไม่ใช่ให้ต้องไปค้นใหม่

## Alternatives considered

| Alternative | Why not selected |
|---|---|
| ยังไม่ทำอะไรจนกว่าจะจดทะเบียนเสร็จ | ตรงไปตรงมาที่สุด แต่ของแบบนี้จะถูกเพิ่มตอนรีบ และตอนนั้นจะไม่มีใครถามว่าตราที่กำลังจะติดนั้นมีคนออกให้แล้วหรือยัง โครงที่ปฏิเสธเองได้ถูกกว่าการหวังว่าจะมีคนจำ |
| ติดตราไว้ก่อนแล้วค่อยเอาออกถ้ามีปัญหา | เป็นการแถลงเท็จเรื่องการจดทะเบียน ความเสียหายเกิดตั้งแต่มีคนเห็นและเชื่อ การถอดออกทีหลังไม่ได้ย้อนสิ่งนั้น |
| ใส่ตราจาง ๆ หรือ placeholder ไว้ก่อน | คนอ่านไม่ได้แยกว่าอะไรจาง ๆ แปลว่ายังไม่จริง ตราที่มองเห็นได้คือตราที่ถูกเชื่อ |
| วาดตราเองให้คล้ายของกรม | คำอ้างเท็จเดิม บวกการใช้เครื่องหมายที่ไม่ใช่ของเรา |
| แสดงชื่อ หจก. เป็นข้อความไปก่อน | เป็นความจริง แต่เป็นการตัดสินใจของเจ้าของที่ยังไม่ได้ทำ และวันนี้ยังไม่มีการรับเงินที่ไหน จึงตอบคำถามที่ยังไม่มีใครถาม |
| เขียนเงื่อนไขการจดทะเบียนของกรมลงเอกสารนี้ | จะเป็นการยืนยันกฎจากความจำ เงื่อนไขการจดทะเบียนต้องมาจากแหล่งปฐมภูมิ และการเลือกระหว่างจดบริษัทใหม่กับบุคคลธรรมดาเป็นเรื่องภาษีและธุรกิจของเจ้าของกับนักบัญชี |

## Consequences

**วันนี้ footer ไม่มีแถวเครื่องหมาย** และนั่นคือผลลัพธ์ที่ถูก มีเทสต์ยืนยันไว้ว่าไม่มี เพื่อไม่ให้ "ว่าง" ถูกอ่านว่า "พัง"

**วันที่ได้ทะเบียนจริง งานที่เหลือคือเติมเลขและวางไฟล์รูปที่กรมให้มา** ไม่ต้องแตะ footer ไม่ต้องแตะ CSS

**ยังไม่ตัดสิน** ว่าจะจดบริษัทใหม่หรือใช้บุคคลธรรมดา และเอกสารฉบับนี้ไม่ได้ตัดสินให้ ถ้าต้องการเงื่อนไขของกรม ให้ทำเป็นงานค้นคว้าแยกจากแหล่งปฐมภูมิ

**Testing** ต้องมีเทสต์ยืนยันว่า เครื่องหมายที่ไม่มีเลขทะเบียนไม่ขึ้น, ที่ไม่มีรูปจากผู้ออกไม่ขึ้น, ไม่มีอะไรผ่านแปลว่าไม่มีแถว, และรายการ DBD วันนี้ยังไม่ผ่านเกณฑ์ใดเลย
