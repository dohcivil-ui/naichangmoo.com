# ADR 0021: สีทุกค่าประกาศที่ครัวกลางที่เดียว และรั้วสีต้องพิสูจน์ได้ว่ายังกัด

**Status:** Accepted — เจ้าของงานสั่ง 2026-08-28 "เปิดหน้าไหนสีก็จะไม่เพี้ยน" ผ่านการกริลครบ

## Context

ทั้งเว็บใช้วิธีครัวกลางอยู่แล้ว: ค่าสีจริงเป็นกระปุก `--teal --paper --ink ...` ใน `globals.css`
แล้วทุกหน้าตักไปใช้ เจ้าของงานถามว่าจะล็อกให้ทั้งเว็บหน้าตาเดียวกันโดยยึด landing เป็นหลัก
ได้อย่างไร คำตอบที่ตกผลึกคือส่วนที่ต้องล็อกไม่ใช่เครื่องมือเขียนสไตล์ แต่คือ**ที่อยู่ของค่าสี** —
และเช่นเดียวกับรั้ว import (ADR 0020) กติกาที่เป็นข้อความจะถูกเผลอละเมิดโดย AI หลายเซสชัน
ที่เขียนโค้ดคู่ขนานกัน หลักฐานคือไฟล์ workspace ของ PRICEMETR ที่พกเลขสีดิบสองค่า
(`#3aa8a8`, `#e6f3f3`) มาตั้งแต่เกิดโดยไม่มีใครเห็น

## Decision

1. **ค่าสีจริงประกาศได้ที่ `src/app/globals.css` ที่เดียว** ไฟล์อื่นทั้ง `src` อ้างสีผ่าน
   `var(--...)` เท่านั้น เลขสีดิบทุกรูปแบบ (hex, `rgb()`, `hsl()`, `oklch()`, ฯลฯ) คือการละเมิด
2. **ข้อยกเว้นมีสามประเภท ระบุเป็นรายไฟล์พร้อมเหตุผลเสมอ:** ครัวกลางเอง ·
   `document-print.css` ที่อิงระเบียบงานสารบรรณไม่ใช่ธีมเว็บ · และไฟล์กราฟ/จานสี
   ตามคำวินิจฉัย "กราฟฟรีจริง" ของเจ้าของงาน — วันนี้มีรายการเดียวคือจานสีหมวดวัสดุ
   21 เนื้อสีของ PRICEMETR ซึ่งคุมความอิ่มและความสว่างร่วมกับธีมไว้ในสูตรเดียว
3. **รั้วเป็นเทสต์ที่เดินอ่านไฟล์จริง** (`src/palette-fence.test.ts`) ไม่ใช่เช็กลิสต์:
   เพิ่มไฟล์ใหม่แล้วฝังสี เทสต์แดงทันทีโดยไม่ต้องมีใครจำได้ว่ามีรั้วอยู่ พร้อมเทสต์พิสูจน์
   ว่าตัวตรวจจับสีทุกรูปแบบได้จริง และบัญชียกเว้นชี้ไฟล์ที่ยังมีอยู่จริงเสมอ
4. **ห้ามผู้เขียนโค้ด — คนหรือ AI — เพิ่มข้อยกเว้นเพื่อให้งานของตัวเองผ่าน**
   การเพิ่มรายการยกเว้นโดยชอบต้องเป็นไฟล์กราฟ/จานสีตามข้อ 2 จริง ไม่ใช่ที่ซ่อนของสีดิบ

## Alternatives considered

| Alternative | Why not selected |
|---|---|
| ล็อกด้วย Tailwind ทั้งเว็บ | ต้องรื้อโค้ดทั้งหมดเพื่อให้ได้หน้าตาเท่าเดิม แลกความเสี่ยงพังกับศูนย์ประโยชน์ที่ลูกค้ามองเห็น |
| กฎ stylelint | เพิ่ม dependency ใหม่ และไม่ครอบไฟล์ .tsx ที่สีแอบมากับ inline style ซึ่งเป็นที่ที่ผู้ละเมิดตัวจริงอยู่ |
| ห้ามในเอกสารอย่างเดียว | คือสภาพเดิมที่ทำให้สีดิบสองค่าอยู่ในไฟล์มาหลายรุ่นโดยไม่มีใครเห็น |
| ยกเว้นทั้งโฟลเดอร์ prototype | กว้างเกิน — ต้นแบบคือที่ที่โค้ดถูกเขียนเร็วที่สุดและหลุดง่ายที่สุด ยกเว้นรายไฟล์พร้อมเหตุผลเท่านั้น |

## Consequences

- กระปุกใหม่สองใบ `--teal-soft` `--teal-wash` รับสีที่เคยฝังดิบใน `price-workspace.tsx`
- `pre-commit` ที่รันเทสต์อยู่แล้วบังคับรั้วนี้อัตโนมัติ เช่นเดียวกับรั้ว import
- mockup ใน `.design/` อยู่นอกรั้ว (ไม่ใช่ `src`) — ของทดลองวาดสีได้อิสระ แต่ตอนยกเข้าโค้ดจริง
  ต้องแปลงเป็นกระปุกเสมอ ตามที่ IP-197 ระบุไว้แล้ว
- พิสูจน์รั้วกัดจริงแล้วหนึ่งครั้ง: ฝัง `#ff0000` ในคอมโพเนนต์จริง เทสต์แดงทันที ถอนแล้วเขียวคืน
