# 2026-09-05 — ทุกตัวเลขต้องกางวิธีคิดของตัวเองได้ ไม่ใช่แค่บอกผลลัพธ์

**สถานะ** เจ้าของงานสั่งเป็นหลักการถาวร ยังไม่ลงโค้ด รอเคาะสามทางแยกท้ายเอกสาร

---

## หนึ่ง — คำสั่งของเจ้าของงาน

> "ทำเป็นหลักฐานการคิดคำนวณไว้ในแอป ฝังไว้เลยนะวิธีการคิดคำนวณแบบนี้ **ไม่ว่าจะเป็นงานไหน
> ก็ให้ใช้หลักการนี้** ลากเส้นทาบวัด เทียบบัญญัติไตรยางศ์ เทียบสเกล มีข้อมูลที่ตอบได้จริง
> แบบนี้ user ก็จะได้คำตอบ ไม่คาใจ ทำเป็น Tips ในแอปไว้เลย"

**นี่ไม่ใช่ฟีเจอร์ของหน้าใดหน้าหนึ่ง** เขาสั่งเป็นกติกาของทั้งแอป · ตัวเลขทุกตัวที่แอปตอบ
ต้องกางออกมาให้เห็นได้ว่าได้มาอย่างไร ในภาษาเดียวกับที่วิศวกรใช้เถียงกันหน้างาน

**ที่มาของคำสั่ง** เขาถามว่า "แบบเขียน 2.50 × 2.00 ทำไมแอปตอบ 3.98" แล้วเซสชันนี้ตอบผิด
สองรอบก่อนจะตอบถูก · สิ่งที่ปิดเรื่องได้จริงคือการลากเส้นจากหมุดของเส้นบอกระยะเข้ามาทับผนัง
แล้ววัดทีละช่วง · เขาเห็นแล้วสั่งทันทีว่า **"ถ้า user ท้วงมาต้องมีคำตอบให้เขาได้"**

## สอง — สี่อย่างที่หลักฐานต้องตอบได้เสมอ

เรียงตามลำดับที่คนอ่านจะถาม ไม่ใช่ตามลำดับที่โปรแกรมคำนวณ

| # | คำถามของผู้ใช้ | หลักฐานที่ต้องกางให้ดู |
|---|---|---|
| 1 | **"เส้นที่วัดอยู่ตรงไหนของแบบ"** | รูปทรงที่วัดได้ ทาบบนแบบตรงตำแหน่งจริง ซูมเข้าไปดูได้ |
| 2 | **"พิกเซลกลายเป็นเมตรได้ยังไง"** | บัญญัติไตรยางศ์เต็มบรรทัด — กี่จุดบนกระดาษ คูณเมตรต่อจุด ได้กี่เมตร |
| 3 | **"สเกลที่ใช้เชื่อได้แค่ไหน"** | สเกลนี้ตั้งมาจากอะไร และเทียบกับระยะที่แบบเขียนแล้วคลาดกี่เปอร์เซ็นต์ |
| 4 | **"ตัวเลขนี้วัดถึงตรงไหน"** | ผิวใน กึ่งกลางผนัง หรือหมุดเส้นบอกระยะ — สามอย่างนี้ให้คนละคำตอบ |

**ข้อสี่คือข้อที่ทำให้เรื่องวันนี้ยาว** ห้องเดียวกันตอบได้สี่ค่า และทุกค่าถูกในนิยามของมันเอง

| วิธีวัด ห้องน้ำผู้ป่วยชาย หน้า 7 | ได้ |
|---|---|
| หมุดถึงหมุด ตามที่แบบเขียน | 2.50 × 2.00 = 5.00 |
| กึ่งกลางผนังถึงกึ่งกลางผนัง | 2.404 × 1.897 = 4.56 |
| **ผิวในถึงผิวใน คือพื้นที่ปูกระเบื้อง** | **2.305 × 1.809 = 4.17** |
| ที่แอปตอบตอนนี้ | 2.264 × 1.758 = 3.98 |

## สาม — ของที่มีอยู่แล้ว อย่าสร้างซ้อน

เกินครึ่งของงานนี้ลงไปแล้วตั้งแต่ IP-232 ถึง IP-234 · ที่ขาดคือ**หน้าจอที่กางมันออกมาให้คนดู**

| มีแล้ว | ไฟล์ | ทำอะไร |
|---|---|---|
| รูปทรงที่วัดได้ พร้อมสเกล ณ ตอนส่ง | `src/lib/drawing-evidence.ts` | `EvidenceGeometry` เก็บจุดที่คนชี้กับ `metresPerPoint` **ก๊อปไว้ตอนส่ง** ไม่ได้อ้างแถวสเกลที่แก้ทีหลังได้ |
| ทะเบียนวิธีที่มาของปริมาณ | `src/lib/quantity-provenance.ts` | `QuantityMethod` บอกว่าปริมาณนี้ได้มาอย่างไร ตาม ADR 0024 |
| วิธีตั้งสเกล | `src/lib/drawing-calibration-method.ts` | `two_point` กับ `stated_dimension` |
| กว้าง × ยาว ของห้อง | `src/lib/room-area-explained.ts` | คืนกรอบเป็นหน่วยจุดมาด้วย ตัววาดกับตัวเลขจึงมาจากการไล่ครั้งเดียวกัน |
| เทียบระยะที่แบบเขียน | `dimensionDisagreement` | บอกว่าสเกลปัจจุบันกับเลขที่แบบเขียนต่างกันเท่าไร |
| เส้นบอกระยะทาบบนแบบ | `drawing-markup.tsx` | วาดเส้นแดงคร่อมรูปที่ไล่ได้ พร้อม `กว้าง × ยาว = พื้นที่` |

| ยังไม่มี | ทำไมต้องมี |
|---|---|
| **แผงกางหลักฐานต่อหนึ่งรายการ** | ตอนนี้หลักฐานถูกเก็บลงฐานแล้วแต่ไม่มีหน้าจอไหนอ่านมันออกมาให้คนดูเลย |
| **บรรทัดบัญญัติไตรยางศ์** | ตัวเลขจุด คูณ เมตรต่อจุด เท่ากับ เมตร — เขียนเป็นบรรทัดเดียวที่คนตรวจตามได้ |
| **บรรทัดเทียบสเกล** | สเกลที่ตั้งไว้เทียบกับหัวแบบและกับระยะที่แบบเขียน คลาดกี่เปอร์เซ็นต์ |
| **ป้ายบอกว่าวัดถึงตรงไหน** | ผิวใน กึ่งกลาง หรือหมุด · ตอนนี้เขียนไว้เป็นข้อความตายตัวว่า "วัดถึงผิวผนังด้านใน" |
| **Tips อธิบายวิธีคิด** | คนที่เพิ่งเข้ามาต้องรู้ว่าแอปคิดยังไง ก่อนจะเชื่อตัวเลข |
| **ที่ตารางถอดปริมาณ** | คอลัมน์ "หลักฐานจากแบบ" ยังเป็นข้อความตัวอย่าง ไม่ได้ต่อกับหลักฐานจริง |

## สี่ — บทเรียนของวันนี้ที่ต้องกลายเป็นกฎ ไม่ใช่แค่เรื่องเล่า

1. **อ่านจากสิ่งที่อัลกอริทึมเห็น ไม่ใช่จากต้นฉบับ** — เรื่องนี้ปิดได้เพราะอ่านหมึกจากผืนที่แอป
   เรนเดอร์เอง · ตอนไปสู้กับพิกัดใน PDF เสียเวลาไปมากและได้คำตอบผิด
2. **ตัวเลขเดียวไม่พอ ต้องมีตัวเลขที่ไม่เกี่ยวกันมายืน** — สเกลยืนยันด้วยช่วงยาวห้าช่วงที่เป็นอิสระ
   ต่อกัน ได้ค่าตรงกันในช่วง ±0.13% · ถ้าวัดช่วงเดียวคงเชื่อค่าที่ผิดไปแล้ว
3. **ความรู้วิชาชีพของเจ้าของงานคือข้อมูลเข้า ไม่ใช่ความเห็น** — เขาบอกว่าผนังหนา 0.10
   แล้วทุกอย่างลงล็อกทันที · แอปควรมีที่ให้กรอกของแบบนี้ แล้วเอาไปตรวจกับที่วัดได้
4. **บอกด้วยว่าอะไรที่ยังไม่รู้** — หมุดสองตัวอ้างอิงอะไรยังตอบไม่ได้ และเอกสารนี้เขียนไว้ตรง ๆ
   ว่ายังไม่รู้ · หลักฐานที่แสร้งว่ารู้ทุกอย่างคือหลักฐานที่เชื่อไม่ได้

## ห้า — ทางแยกที่ยังไม่ตัดสิน ห้ามเดาแทน

1. **แผงหลักฐานอยู่ที่ไหน** — กางจากแถวในแผงรายการวัด · หรือเป็นหน้าเต็มต่อโครงการที่พิมพ์ออกได้
   · หรือทั้งสองที่
2. **ตอนแบบยังไม่มีเส้นบอกระยะให้เทียบ จะบอกอย่างไร** — ขึ้นป้ายว่า "ยังไม่ได้เทียบ" ทุกครั้ง
   หรือกันไม่ให้ส่งเข้าถอดปริมาณจนกว่าจะเทียบ
3. **ค่าที่แอปตอบควรเป็นค่าไหน** — ผิวในเหมือนตอนนี้ หรือให้เลือกได้ต่อรายการว่าจะเอาผิวใน
   กึ่งกลางผนัง หรือหมุด · เรื่องนี้กระทบตัวเลขเงินโดยตรง

## หก — งานที่ต้องทำก่อน ไม่เกี่ยวกับหน้าจอ

**ขอบห้องยังขาดไปราว 4%** การไล่สีหยุดที่ขอบนอกของหมึก แต่ผิวผนังจริงอยู่ที่กึ่งกลางเส้น
ขอบจึงร่นเข้ามาครึ่งความหนาเส้น ด้านละราว 1.7–2.2 ซม. · **ต้องแก้ก่อนกางหลักฐาน**
ไม่งั้นแอปจะกางวิธีคิดที่สวยงามของตัวเลขที่ยังผิดอยู่
