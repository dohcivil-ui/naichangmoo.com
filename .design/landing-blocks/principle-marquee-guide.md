# แถบข้อความวิ่ง — เอาออกแล้ว และวิธีเอากลับมา

เจ้าของงานเคาะเมื่อ 2026-08-31 ว่า **เอาแถบวิ่งออกจากหน้าแรกก่อน แต่ไม่ลบทิ้ง**
เพราะยังไม่ตัดสินว่าจะไม่ใช้อีกเลย ไฟล์นี้บอกว่าอะไรถูกเอาออก อะไรยังอยู่
และถ้าจะเอากลับมาต้องทำอะไรบ้าง เพื่อไม่ให้ใครมาเจอสไตล์ที่ไม่มีคนใช้แล้วเข้าใจผิดว่าเป็นของตกค้าง

## ทำไมถึงเอาออก

แถบวิ่งตั้ง `aria-hidden="true"` ไว้ แปลว่าโปรแกรมอ่านหน้าจอกับเครื่องมือค้นหา
มองไม่เห็นข้อความข้างในเลย ห้าประโยคหลักการซึ่งเป็นจุดที่คู่แข่งลอกไม่ได้
จึงถูกซ่อนจากทั้งคนที่ใช้โปรแกรมอ่านหน้าจอและจาก Google พร้อมกัน
ตอนนี้ห้าประโยคนั้นย้ายไปอยู่ที่ส่วน `.principle-list` ใต้ส่วนหัวหน้าแรก
ซึ่งเป็น `<ul>` จริงที่อ่านได้ทุกทาง

## อะไรถูกเอาออก อะไรยังอยู่

| ของ | สถานะตอนนี้ | ที่อยู่ |
|---|---|---|
| JSX ของแถบวิ่ง | **ลบแล้ว** | เคยอยู่ที่ `src/app/page.tsx` ท้ายส่วนหัวหน้าแรก |
| สไตล์ `.principle-marquee*` และ `@keyframes principle-mq` | **ยังอยู่ครบ** | `src/app/globals.css` ต่อจากสไตล์พาดหัว |
| ชื่อ `principle_marquee` ในสมุดชื่อ | **ยังอยู่** `lockedReason: null` แปลว่าปิดได้ | `src/lib/landing-blocks.ts` |

## ถ้าจะเอากลับมา

ทำสามอย่างนี้ ไม่ต้องเขียน CSS ใหม่

1. ใส่ JSX กลับเข้าไปท้ายส่วนหัวหน้าแรกใน `src/app/page.tsx` โครงเดิมคือ
   `div.principle-marquee > div.principle-marquee__track > div.principle-marquee__half` สองชุดเหมือนกัน
   (ต้องสองชุดเพราะภาพเคลื่อนไหวเลื่อนไป 50% แล้ววนกลับ ถ้ามีชุดเดียวจะเห็นรอยต่อ)
2. **หาเนื้อหาใหม่ให้มัน** ห้ามเอาห้าประโยคหลักการกลับมาใส่ เพราะจะกลายเป็นพูดซ้ำ
   กับส่วน `.principle-list` ที่อยู่ถัดลงไปไม่กี่บรรทัด
3. ถ้าใส่เนื้อหาที่คนต้องอ่านจริง ให้เอา `aria-hidden="true"` ออก แล้วหาวิธีอื่น
   ไม่ให้ข้อความซ้ำสองชุดถูกอ่านสองรอบ เช่นทำชุดที่สองเป็น `aria-hidden` ชุดเดียว

## ข้อจำกัดที่ต้องรู้ก่อนคิดเรื่องหน้า admin

เจ้าของงานอยากให้เปิดปิดบล็อกได้จากหน้า admin ซึ่งยังทำไม่ได้ในตอนนี้
`src/lib/landing-blocks.ts` เป็นแค่**สมุดชื่อ** ยังไม่มีใครเรียกใช้ และ `src/app/page.tsx`
ยังวาดทุกบล็อกเรียงกันตายตัว การทำสวิตช์เปิดปิดจริงต้องมีตารางในฐานข้อมูล (มี migration)
มีหน้า admin และต้องรื้อ `page.tsx` ให้ประกอบหน้าจากสมุดชื่อ เป็นงานคนละก้อนที่ต้องวางแผนก่อน
