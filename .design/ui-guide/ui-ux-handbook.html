๑๐ กับดักรวม ที่เจอมาแล้วจริงในงานนี้

กับดักอาการทางแก้
ลืม min-width:0ผังพัง แบบโดนบีบใส่ที่ทุกช่องของ grid และ flex
ลืม {passive:false}ล้อเมาส์ซูมไม่ได้ หน้าเลื่อนแทนChrome ตั้ง wheel เป็น passive ให้เอง preventDefault จะถูกเมิน
ลืม transform-origin:0 0ซูมแล้วภาพกระโดดค่าเริ่มต้นคือกึ่งกลาง ทำให้สูตรผิดทั้งชุด
ปุ่มอยู่ในกรอบที่รับการลากกดปุ่มแล้วภาพเลื่อน เหมือนปุ่มเสียเช็ค e.target.closest() ก่อนเริ่มลาก
ใส่ tooltip สองแหล่งป้ายซ้อนกันอ่านไม่ออกเลือกอย่างใดอย่างหนึ่ง
นับถอยหลังทีละวินาทีเวลาเพี้ยนเมื่อสลับแท็บคำนวณจากเวลาหมดอายุเสมอ
ตัด focus-visible ทิ้งเพราะไม่สวยคนใช้คีย์บอร์ดใช้งานไม่ได้เลยห้ามตัด ให้ออกแบบให้สวยแทน
ไม่ clamp scaleซูมออกจนภาพหายMath.min(max, Math.max(min, s))
ลืม deltaModeFirefox ซูมเร็วผิดปกติFirefox ส่งหน่วยเป็นบรรทัด ไม่ใช่พิกเซล
ลืมว่าแทร็กแพดก็ส่ง wheelจีบนิ้วแล้วเพี้ยนการจีบนิ้วมาเป็น wheel ที่มี ctrlKey

ก๊อปไปใช้ได้เลย

ทำ workspace layout สี่ส่วน
  app bar + tool palette ด้านบน · thumbnail rail ซ้าย 150px
  canvas ตรงกลาง 1fr · inspector ขวา 330px · status bar ล่าง
  ใส่ splitter ลากปรับได้ ทุกแผงพับได้
  ทุกช่องใส่ min-width:0 หน้าทั้งหน้าห้ามเลื่อน

ตัด viewport controls ทิ้ง ให้เมาส์คุมทั้งหมด
  fit to view ตอนโหลด · zoom to cursor ด้วยล้อ · pan ด้วยคลิกซ้ายแช่
  clamp scale 0.05 ถึง 8 · ใส่ทางลัด + − 0 F ไว้ให้คีย์บอร์ด

tool palette แบบ icon-only ปุ่ม 32px ไอคอน 18px
  ขยาย hit area ด้วย ::before ไม่ขยายปุ่ม
  tooltip มีที่เดียว บอกชื่อ ทางลัด และหน้าที่
  ใช้ radiogroup semantics กับเครื่องมือ ใช้ aria-pressed กับสวิตช์
  เปลี่ยน cursor ตามเครื่องมือ

ทำ live countdown จาก expiry timestamp อย่านับถอยหลังเอง
  เปลี่ยนเป็น warning state เมื่อเหลือน้อยกว่าสามวัน
