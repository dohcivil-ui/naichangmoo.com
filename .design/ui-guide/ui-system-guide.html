สี

Colour · Contrast Ratio

เรื่องสีไม่ใช่เรื่องชอบไม่ชอบ ส่วนใหญ่วัดเป็นตัวเลขได้ หลักที่ใช้จริงคือ สีแต่ละตัวมีหน้าที่ ไม่ใช่มีไว้สวย และสีที่เอาไปเป็นตัวหนังสือ ต้องต่างจากพื้นหลังมากพอให้คนสายตาไม่ดีอ่านออก

สีของเรามีหน้าที่ประจำตัว

--ink
หมึก #073047 หัวข้อ เส้นขอบ พื้นเข้ม ไม่ใช้กับเนื้อความยาว
--teal
เขียวหัวเป็ด #0d8282 สีประจำแบรนด์ ใช้กับพื้น ป้าย และเส้นเน้น
--orange
ส้ม #f47721 ปุ่มหลักและจุดเน้น หนึ่งจุดต่อหนึ่งหน้าจอ
--canvas
พื้นหน้ากระดาษ #f4f7f7 พื้นหลังหลัก เทาที่เอียงไปทางเขียว ไม่ใช่เทากลาง

สังเกตว่าพื้นหลังของเราไม่ใช่เทากลาง แต่เป็นเทาที่เอียงไปทางเขียวนิดหนึ่ง เทากลางแท้ ๆ จะดูเหมือนไม่ได้เลือก ส่วนเทาที่เอียงไปทางสีแบรนด์จะดูเหมือนตั้งใจ

ตัวเลขที่ทำให้เถียงกันจบ

ค่าที่เรียกว่า อัตราส่วนความต่าง (Contrast Ratio) วัดว่าตัวหนังสือกับพื้นหลังต่างกันแค่ไหน มาตรฐานสากลกำหนดว่าตัวหนังสือขนาดปกติต้องได้อย่างน้อย 4.5 ตัวเลขข้างล่างนี้ ทีมเราวัดไว้แล้วและเขียนกำกับไว้ในไฟล์สีจริง

สีตัวหนังสือบนพื้นได้เท่าไรผลตัดสิน

นี่คือเหตุผลที่เรามีสีส้มสองตัวและเขียวสองตัว ไม่ใช่เพราะลังเล แต่เพราะสีสำหรับพื้นกับสีสำหรับตัวหนังสือเป็นคนละงาน ส้มสดสวยบนปุ่ม แต่พอเอามาเป็นตัวหนังสือบนพื้นขาวได้แค่ 2.80 ซึ่งอ่านไม่ออกสำหรับหลายคน

Software as a Service

SaaS คือการขายซอฟต์แวร์แบบให้ใช้ผ่านเว็บและจ่ายเป็นรอบ ไม่ใช่ขายขาด หน้าขายของ SaaS จึงมีงานเดียว คือทำให้คนที่ยังไม่รู้จัก เข้าใจภายในหนึ่งจอ ว่าเราแก้ปัญหาอะไรให้เขา แล้วพาไปทดลองใช้

หน้าแรกของคุณมีครบทุกชั้นแล้ว ไม่ได้ขาด สิ่งที่ยังขาดคือปุ่มเปิดปิดแต่ละชั้นจากหลังบ้าน ซึ่งเป็นงานที่วางแผนไว้แล้ว

หกข้อที่ทำให้หน้า SaaS ต่างจากเว็บบริษัททั่วไป

  • หนึ่งจอ หนึ่งงาน แต่ละส่วนมีปุ่มหลักได้หนึ่งปุ่ม ถ้ามีปุ่มเด่นสามปุ่มแข่งกัน คนจะไม่กดสักปุ่ม
  • ให้ลองก่อนจ่าย ทดลองใช้ฟรีมีน้ำหนักกว่าคำโฆษณาทุกประโยค ของเราคือ ทดลองใช้ฟรี 7 วัน
  • ราคาต้องหาเจอ ซ่อนราคาแล้วคนไม่ติดต่อ แต่จะปิดแท็บ ของเราแยกไปหน้า /pricing ที่เดียว
  • พูดภาษาลูกค้า ไม่ใช่ภาษาระบบ ผู้รับเหมาพูดว่า ถอดแบบ ไม่ได้พูดว่า quantity extraction module
  • อย่าสัญญาสิ่งที่ยังทำไม่ได้ ป้ายว่าพร้อมใช้ต้องมาจากทะเบียนที่มีคนรับผิดชอบ ไม่ใช่พิมพ์เอง
  • เร็วคือฟีเจอร์ หน้าที่โหลดช้าคือหน้าที่คนกดปิดก่อนอ่าน ภาพใหญ่เกินจำเป็นคือสาเหตุอันดับหนึ่ง

UX — ธรรมเนียม กับ บริบท

Nielsen Norman Group

มีคนพูดว่า UI ให้ AI ทำได้ แต่ UX ต้องมาจากประสบการณ์ตัวเอง คำนั้นถูกครึ่งเดียว เส้นแบ่งจริงไม่ได้อยู่ที่ UI กับ UX แต่อยู่ที่ธรรมเนียมกับบริบท บทนี้แยกสองอย่างนั้นให้ชัด เพราะมันบอกว่าเรื่องไหนสั่ง AI ทำได้ และเรื่องไหนต้องมาจากคุณเท่านั้น

สิบข้อของ Nielsen — นี่คือธรรมเนียม

เขียนไว้ตั้งแต่ปี 1994 และยังเป็นมาตรฐานที่ทั้งวงการใช้ตรวจงานกันอยู่ เป็นความรู้ที่ท่องได้ ไม่ต้องมีประสบการณ์ก็เรียนได้ ช่องขวาคือสภาพของเราเทียบกับแต่ละข้อ ซึ่งผมตรวจจากโค้ดจริง

01
บอกสถานะระบบตลอดเวลาVisibility of System Status

ยังขาด ไม่มี Toast เลยสักตัว งานที่สำเร็จแล้วไม่มีอะไรยืนยันให้เห็น

02
พูดภาษาเดียวกับโลกจริงของผู้ใช้Match Between System and the Real World

แข็งแรงที่สุดของเรา copy-th.md บังคับให้หยิบคำจากฟอร์ม ปร.4 จริง ไม่ใช่แปลจากชื่อคอลัมน์

03
ให้ผู้ใช้ควบคุมและถอยกลับได้User Control and Freedom

ยังขาด ไม่มีเลิกทำ ประมาณราคาที่ออกแล้วแก้ไม่ได้ ต้องออกครั้งใหม่

04
สม่ำเสมอและทำตามมาตรฐานConsistency and Standards

ดี ทุกแอปใช้โครงหน้าร่วมเดียวกัน และมีรั้วเทสต์คุมสีกับไอคอน

05
กันพลาดตั้งแต่ต้นError Prevention

แข็งแรงมาก ค่าเผื่อที่ไม่ระบุที่มาถูกปฏิเสธตั้งแต่ตอนบันทึก ไม่ใช่แค่เตือนแล้วกดข้ามได้

06

07

09

ข้อความเล็กที่สำคัญMicrocopy

คำบนปุ่ม ข้อความใต้ช่องกรอก ข้อความผิดพลาด ส่งผลต่อการใช้งานมากกว่าภาพสวย

ลวดลายมืดDark Pattern

การออกแบบที่หลอกให้กดสิ่งที่ไม่ตั้งใจ เช่นปุ่มยกเลิกที่จางจนหาไม่เจอ ห้ามทำ

กระปุกค่าออกแบบDesign Token

ค่าสี ระยะ ขนาด ที่ประกาศไว้ที่เดียวแล้วทุกที่ตักไปใช้ ของเราอยู่ที่ globals.css

มาตรฐานการเข้าถึงWCAG · ARIA

WCAG คือเกณฑ์ เช่นคอนทราสต์ 4.5 · ARIA คือป้ายบอกโปรแกรมอ่านหน้าจอว่าของชิ้นนี้คืออะไร

ตัวชี้วัดความเร็วของเว็บCore Web Vitals

LCP เนื้อหาหลักขึ้นเมื่อไร · CLS หน้ากระโดดแค่ไหน · INP กดแล้วตอบสนองเร็วไหม Google ใช้จัดอันดับด้วย

ส่วนที่ AI ทำแทนไม่ได้ — นี่คือบริบท

ทั้งหมดข้างบนผมเรียนมาได้ แต่สี่ข้อข้างล่างนี้ไม่มีทางรู้เอง มันมาจากการที่คุณเคยยืนอยู่ในห้องประชุมตอนตัวเลขถูกซัก

ตัวเลขต้องชี้ต้นทางได้ADR 0015 · กฎค่าเผื่อ

ไม่มีตำรา UX เล่มไหนเขียนว่า “ค่าเผื่อที่ไม่ระบุที่มาต้องถูกปฏิเสธตั้งแต่ตอนบันทึก” คุณรู้ข้อนี้เพราะเคยถูกถามว่าเลข 7% มาจากไหน แล้วตอบไม่ได้

ใช้คำของฟอร์ม ไม่ใช่คำของฐานข้อมูลcopy-th.md

AI จะแปล price_set ว่าชุดราคาซึ่งฟังดูสมเหตุสมผล แต่คุณรู้ว่า ว809 เรียกของตัวเองว่าบัญชี และคำว่าชุดไม่เคยปรากฏในเอกสารราชการเลย

รู้ว่าใครจะถูกซักและซักเรื่องอะไรลำดับความสำคัญของหน้าจอ

AI จัดหน้าจอตามความสวย คุณจัดตามลำดับที่ผู้ตรวจจะไล่ถาม สองอย่างนี้ไม่เหมือนกัน

รู้ว่าอะไรผิดแล้วเสียเงินจริงความเสี่ยงที่ไม่สมมาตร

พิมพ์ 1.25 แทน 12.5 หน้าตาเหมือนกันในตาราง แต่ผลต่างคือประมูลได้กับประมูลพลาด AI ไม่รู้ว่าช่องไหนพลาดแล้วเจ็บกว่ากัน จึงป้องกันให้เท่ากันหมด ซึ่งผิด

ข้อสรุปที่ใช้ได้จริง — สั่งผมทำเรื่องธรรมเนียมให้หมด แล้วเก็บแรงคุณไว้ตัดสินเรื่องบริบท ถ้าสลับกัน จะได้เว็บที่ถูกตำราแต่ผิดงาน

เวลาจะสั่งแก้ ให้สั่งที่ไหน
