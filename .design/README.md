# ไฟล์ต้นทางของผืนออกแบบ

โฟลเดอร์นี้เก็บ **ไฟล์ต้นทาง** ของผืนออกแบบที่เผยแพร่เป็น Artifact ไม่ใช่ตัวหน้าเว็บที่เผยแพร่แล้ว

## ทำไมต้องเก็บ

ผืนที่เผยแพร่แล้วแก้จากตัวมันเองไม่ได้ ทุกการแก้คือการ **seed ใหม่จากไฟล์ในนี้** แล้วเผยแพร่ทับ
URL เดิม · ถ้าไฟล์พวกนี้หาย เซสชันถัดไปจะแก้ผืนต่อไม่ได้ ต้องวาดใหม่ทั้งหมด

## วิธีแก้แล้วอัปเดตผืน

1. แก้ไฟล์ `.dc.html` หรือ `canvas.json` ในโฟลเดอร์ของผืนนั้น
2. เรียก skill `design` แล้ว seed ใหม่จากไฟล์ทั้งชุด
3. เผยแพร่ทับ URL เดิมด้วย Artifact tool โดยส่ง `url` ของผืนนั้นไปด้วย

**ห้ามแก้ไฟล์ `.html` ที่ seed ออกมาแล้วโดยตรง** มันมีตัวแก้ไขฝังอยู่ข้างในสองเมกะไบต์

## ผืนที่มีอยู่ (2026-09-05)

| โฟลเดอร์ | เรื่อง | URL |
|---|---|---|
| `shared-components/` | ชิ้นส่วนกลาง ปุ่มสี่แนว การ์ด ป้ายสถานะ ช่องกรอก ตาราง | https://claude.ai/code/artifact/b289a257-70fa-49c2-8bd3-52bb49d99e8e |
| `landing-v2/` | หน้าแรกแนวใหม่ เดสก์ท็อปและมือถือ | https://claude.ai/code/artifact/9d396d98-11cb-4969-9fa6-44c3d3c00959 |

**สถานะของ `shared-components`** เจ้าของงานเลือกแนว ก "กดได้" แล้ว และลงโค้ดจริงไปแล้ว
กระดานอื่นในผืน (การ์ด ป้ายสถานะ ช่องกรอก ตาราง) **ยังไม่ได้ลงโค้ด**

**สถานะของ `landing-v2`** ยังไม่ได้ลงโค้ด รอเจ้าของงานเคาะ

## โฟลเดอร์อื่นในนี้

ไฟล์ HTML เดี่ยว ๆ ที่ค้างมาจากเซสชันเก่าเป็นต้นแบบที่เปิดดูด้วยเบราว์เซอร์ตรง ๆ
ไม่ใช่ผืนออกแบบ และไม่มีไฟล์ต้นทางแยก
